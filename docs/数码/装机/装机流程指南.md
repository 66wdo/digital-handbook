# 装机流程指南

!!! todo "草稿框架，内容待我们一起填充"

## 阶段一：装机前准备

- [ ] 配件齐套核对（CPU、主板、内存、显卡、硬盘、电源、散热、机箱）
- [ ] 工具：十字螺丝刀、扎带、（可选）防静电措施
- [ ] 在主板官网确认 CPU 兼容性与 BIOS 版本
- 待补充：收货验货、二手配件检查要点

## 阶段二：主板外预装（推荐顺序）

1. CPU 安装（注意三角标记、针脚保护）
2. M.2 固态安装
3. 内存插槽（双通道优先 2/4 槽）
4. CPU 散热扣具与硅脂
- 待补充：每步配图与易错点

## 阶段三：进箱与接线

1. 主板铜柱对位、I/O 挡板
2. 电源安装与走线
3. 前置面板跳线（开关/重启/灯/USB/Type-C）
4. 风扇接线与 ARGB 集线器
5. 显卡最后装
- 待补充：背线思路、各接口防呆说明

## 阶段四：点亮与 BIOS

- 通电第一次点亮看什么（Debug 灯 / 故障码）
- 开启 XMP/EXPO、启动顺序、风扇曲线
- 点不亮的最小系统排查法
- 待补充：常见黑屏排查决策树

## 阶段五：装系统与驱动

- U 盘启动盘制作、分区（ESP/MSR/数据盘）
- 驱动安装顺序：芯片组 → 显卡 → 其他
- 待补充：系统优化、关闭不必要服务的取舍

## 阶段六：稳定性验证

- [ ] 烤机测试（CPU/GPU 双烤温度与功耗）
- [ ] 内存稳定性测试
- [ ] 游戏实测与噪音体感
- 待补充：各项测试工具与「正常范围」参考值

# 装机流程指南

本篇按真实装机顺序组织：**先在主板外预装（好操作）→ 进箱 → 接线 → 点亮 → 装系统 → 用软件验证**。每一步都讲「为什么这么做」和「容易错在哪」，而不是只给一张插线图。

!!! tip "总流程速览"
    **开箱核对 → 主板上装 CPU / M.2 / 内存 / 散热 → 主板进箱 → 装电源走线 → 接主板与 CPU 供电 → 插跳线与风扇 → 最后装显卡 → 通电进 BIOS → 装系统驱动 → 软件验证。**

---

## 阶段一 · 装机前准备

### 先把所有配件摊在桌上核对

- [ ] CPU、主板、内存、显卡、固态、电源、散热、机箱、机箱风扇、显示器及视频线齐备；
- [ ] **CPU 型号与主板插槽兼容**，且主板 BIOS 支持（新 CPU 配老主板可能要先升级 BIOS）；
- [ ] **内存代数正确**：DDR4 / DDR5 与主板一致；
- [ ] **电源额定功率足够**，显卡供电接口齐全；
- [ ] **显卡长度、厚度能装进机箱**，不和水冷排 / 硬盘位打架；
- [ ] **风冷或水冷扣具支持当前 CPU 平台**；
- [ ] **M.2 规格、协议正确**，长度（2242/2260/2280）与主板一致；
- [ ] 机箱风扇位、主板接口数量满足全部设备。

工具：一把尺寸合适的十字螺丝刀、扎带、（可选）防静电手环；在干净、光线好的桌面上操作。

### 总原则：防呆不是让你「硬怼」

现代硬件到处是**防呆设计**——方向对了轻松进，方向错了就挡住。CPU 插座、内存、PCIe 插槽、M.2、SATA、USB、显卡供电都有缺口或定位结构。

!!! warning "插不进去时，第一反应是「检查方向」，不是「再加把劲」"
    金手指、插槽触点、CPU 插座触点、M.2 接口都极其脆弱，**绝大多数硬件不需要暴力安装**。左右摇晃、用力下压，往往是在损坏触点。

## 阶段二 · 主板外预装（进箱前，先在桌面上装好）

主板平放、垫在包装盒上操作，空间大、看得清，是最舒服的顺序。

### 安装 CPU：先分清你是哪种平台

这是最容易「想当然」出错的地方，**针脚/触点到底在 CPU 上还是主板上，取决于平台**：

| 平台 | 封装 | 针脚 / 触点在哪 | 最需要保护的是 |
| --- | --- | --- | --- |
| Intel 主流桌面 | LGA | **主板插座内**（CPU 底面是平的触点） | 主板插座里的细触点 |
| AMD AM4 | PGA | **CPU 底面**（一根根细针脚） | CPU 上的细针脚 |
| AMD AM5 | LGA | **主板插座内**（和 Intel 一样） | 主板插座里的细触点 |

!!! danger "别一句话概括「AMD 针脚在 CPU 上」"
    那是老 AM4 的情况；**AM5 已改成 LGA，触点在主板**。动手前先确认插槽型号（LGA1700/1851、AM4、AM5 会印在插座或主板盒上）。

**通用正确流程**：

1. 抬起/打开插座固定机构（Intel 是压杆+金属盖，AMD 是压杆）；
2. 找主板插座上的**方向标记（小三角）**，再找 CPU 上对应的**三角标记 / 缺口定位**；
3. 三角对三角，**水平、平稳地放下去，让它自然落入定位，不需要按压**；
4. 确认已经落平，再扣回固定机构。

- **Intel LGA / AMD AM5（触点在主板）**：最大禁忌是触碰主板插座里那排又细又密的触点——不要用手摸、不要用纸擦、不要用螺丝刀拨、不要让 CPU 在里面摩擦。
- **AMD AM4（针脚在 CPU）**：拿起 CPU 只碰边缘，别让底面针脚蹭桌面，不要斜着压、不要旋转着就位。

!!! question "放下去落不到位怎么办？"
    **立刻停手，抬起来重新对方向，绝对不要压。** 方向对了它会自己落平。

!!! warning "万一针脚 / 触点弯了"
    第一原则是**先别动、先拍照放大看清是哪根、弯向哪**。AM4 CPU 上轻微弯的针脚，在强光 + 放大镜/手机微距下，用极细工具**极小幅度、一次一点**地修正，反复弯折会金属疲劳甚至断裂；严重交叉/断裂，或 Intel/AM5 主板插座触点弯了，**优先找专业维修，不要拿针、镊子、刀片往插座里捅**——一个触点异常可能导致点不亮、内存通道缺失、PCIe 或 USB/SATA 异常。

### 安装 CPU 散热器

**第一件事不是拧螺丝，而是确认平台扣具**：LGA1700、LGA1851、AM4、AM5 的扣具可能完全不同，别看着差不多就混用，以散热附带的扣具说明为准。

**硅脂涂多少？** 硅脂是用来**填补 CPU 顶盖和散热底座之间微观凹凸**的，不是刷油漆：

- 太少覆盖不全，太多会被挤得溢出，**靠散热器压上去自然铺开**即可；
- 普通桌面 CPU 用「中间一点（约豌豆大小）」或适当多点都可以，具体随顶盖大小、底座结构、硅脂粘度调整；
- 不必迷信「越薄越好」，**稳定、均匀、完整覆盖**比追求极限薄涂更实际。

**塔式风冷**注意：塔体方向、风扇进风方向（风扇标签面通常是出风侧）、是否挡内存、是否碰显卡、是否超机箱限高。主流风道是**风扇从机箱前方吸冷风、吹过塔体，再由机箱后/上方排出**，别为了「看起来整齐」装反风向。最后把 CPU 风扇线接到主板 **CPU_FAN**。

**一体式水冷（AIO）**涉及冷头、冷排、水泵、冷排风扇，以及一堆线：风扇供电、水泵供电、RGB/ARGB 灯效线、USB 控制线、SATA 供电、PWM/DC 调速、转速检测等。

!!! example "真实案例：这款水冷「偏偏要」插 CPU_FAN"
    遇到过一款一体式水冷，由于它的水泵控制方式和转速检测比较特殊，**说明书要求把水泵接到主板 CPU_FAN**，而不是按「常识」接 AIO_PUMP。按想当然接到别的口，结果水泵不转，主板还因为检测不到 CPU_FAN 转速而卡在自检。

!!! tip "水冷接线的最高原则：看厂家说明书"
    不存在「水泵必须插 AIO_PUMP、冷排风扇必须插 CPU_FAN」的铁律，不同厂家、型号接法可能完全不同。**装过几十台也要看说明书，这不是新手行为，恰恰是有经验的表现。**

### 安装内存：为什么不是「有空槽就插」

主板会根据插槽、CPU 内存控制器和板上布线决定双通道怎么组成，所以**插槽位置有讲究**：

- **两条内存（最常见）**：四槽主板优先 **A2 + B2**，也就是通常说的**第 2、第 4 槽（离 CPU 数第二远的布局）**，以组成双通道、兼容性最好；
- **单条内存**：一般优先 **A2**；
- 以上是「常见布局」，**最终一律以主板说明书和板面丝印为准**，不同主板编号可能不同。

安装：内存金手指上有**防呆缺口**，对准插槽凸起；有些主板只有一侧卡扣能活动（另一侧是固定的），属正常。**垂直、均匀施力下压，直到两端卡扣扣合**。「咔」的一声不是唯一标准，要确认金手指完全没入、两端卡扣都到位。插不进先看缺口方向，别硬压。

### 安装 M.2 固态硬盘

M.2「看起来最简单」，反而容易在**槽位选择**上吃亏。先确认：M.2 的 **Key（缺口类型）**、固态协议（NVMe/SATA）、主板该槽支持的协议、长度，以及主板手册里的通道说明。

!!! warning "主板上的 M.2 槽不是「长得一样就一样快」"
    - 有的 M.2 **CPU 直连**，有的走**芯片组**，带宽和延迟不同；
    - 有的槽之间、或 M.2 与某些 SATA 口**共享 PCIe 通道**，插上 M.2 可能让某个 SATA 口失效或降速；
    - 不同槽还可能支持不同 PCIe 代际。

**装哪个槽**：做系统盘时，**优先用主板手册推荐的「第一 M.2 槽」**（通常是 CPU 直连、离 CPU 最近的那个），但别绝对化，以手册的通道说明为准。

**安装步骤**：

1. 先拧下主板 M.2 散热片/装甲；
2. **如果有导热垫，务必撕掉导热垫上的透明保护膜**（最容易忘，不撕等于隔着一层塑料，散热大打折扣）；
3. 固态以约 **20~30° 斜插**进 M.2 槽，插到底后轻轻按下；
4. 用小螺丝或免工具卡扣固定尾部；
5. 装回散热片/装甲。

## 阶段三 · 进箱与接线

### 主板进箱

先确认机箱铜柱位置与主板孔位一一对应（多一颗铜柱顶着主板背面可能造成短路）；装好 I/O 挡板（很多新主板是一体式挡板，随主板直接放入）；主板平稳落位、对角顺序拧紧螺丝，不要一颗拧到底。

### 电源与走线

电源固定到位（风扇侧朝向进风网孔），先规划主线走向再插。模组电源只接当前需要的线，更整洁。

!!! danger "模组线只使用该电源原配 / 官方明确兼容的线"
    不同电源即使接口外观相同，**针脚定义也可能不同，混用模组线有烧毁硬件的风险**，不要拿别的电源的线凑。

### 主板 24-pin 主供电

主板最宽的那排供电口。对准卡扣和方向、**垂直均匀压入直到卡扣扣住**。它本来就比较紧，第一次装会觉得「怎么都插不进」——正确方向 + 垂直下压确实需要一定力道，但**不是左右摇晃硬塞**。

### CPU 供电（EPS）

主板靠近 CPU 的位置有 4-pin / 8-pin / 8+4 / 8+8 的 **CPU EPS 供电**，必须接上。

!!! danger "CPU 供电线 ≠ 显卡 PCIe 供电线"
    **CPU EPS 线插主板 CPU 供电口，显卡 PCIe 线插显卡。** 哪怕「看起来能插」也绝不能混用。高功耗平台该插满的 8+4 / 8+8 要插满，具体看主板说明。

### 安装显卡（建议最后装，给走线留空间）

**插哪根槽**：优先**离 CPU 最近、主板手册指定的主 PCIe x16 长槽**（通常 CPU 直连、满速 x16）。第二根长槽即使带金属加固、看着更高级，也可能只分到 x8 / x4。

!!! example "真实案例：为了好理线，显卡插错槽掉帧"
    一次装大显卡，第一根 x16 槽附近被水冷和线材挤得满满当当，于是把显卡挪到「看起来更高级、还带金属加固」的第二根长槽。机器正常开机进系统，但游戏帧数明显偏低。用 GPU-Z 一看：物理上是 x16 的槽，**实际协商链路只有 x8 / x4**——典型的「能用，但性能没发挥」。插回第一根满速槽后问题解决。

**怎么用 GPU-Z 确认显卡跑在满速（重点）**：打开 GPU-Z，找到 **Bus Interface（总线接口）** 一栏，形如：

- `PCIe x16 4.0 @ x16 4.0`：插槽能力 x16，**当前实际也跑在 x16，正常**；
- `PCIe x16 4.0 @ x8 4.0` / `@ x4 3.0`：当前只协商到 x8 / x4，**值得排查**。

!!! question "前后两个 x16 是什么意思？"
    **@ 前面**是设备/插槽「支持的能力」，**@ 后面**才是「当前真实协商出来的链路」。看到 `x16 @ x4` 就要查：是不是插错槽、是否通道共享、有没有插到底、插槽是否受主板设计限制。

!!! tip "待机显示「跑不满」很多时候是正常省电，别误判"
    PCIe 会按负载动态调速，**桌面待机、笔记本低功耗状态下，链路会主动降到 x8 / x4 甚至 x1 省电**。正确做法：GPU-Z 停在 Bus Interface，点上方的 **Render Test（渲染测试）按钮，让显卡进入满载工作状态**，再看链路是否回升到 x16。**不能只看刚开机/待机那一个数字就断定显卡或插槽有问题**——笔记本尤其常见这种「看着没满、其实是省电」。

**显卡供电**：现代显卡可能是 6-pin、8-pin、多个 8-pin，或新一代 **12VHPWR / 12V-2x6** 接口，不存在「显卡都是 12 针」这种说法，具体看显卡和电源。四条铁律：

1. **插到底**；
2. **确认卡扣完全锁住**（12V-2x6 要插到几乎看不到金属引脚）；
3. **接口附近不要过度弯折**，尤其新接口根部要留平缓弯弧；
4. 用转接线时只用显卡/电源厂家**明确支持**的方案，不要自创接法。

**物理安装**：先拆掉机箱对应 PCIe 挡片，显卡金手指对准主 x16 槽、确认插槽卡扣处于打开位置，**垂直均匀按下直到卡扣卡住、显卡挡板贴齐机箱**，上紧固定螺丝，最后插好供电。

### SATA 硬盘：数据线和电源线是两根

用 SATA 硬盘时要接两条线，缺一不可：**硬盘 → SATA 数据线 → 主板 SATA 口**，同时 **硬盘 → SATA 电源线 → 电源**。别把扁平的 SATA 电源口当成数据线口。

### 机箱前面板跳线（新手最容易接错）

常见跳线：**Power SW（开机）、Reset SW（重启）、HDD LED（硬盘灯）、Power LED（电源灯）、HD AUDIO（前置音频）、USB 2.0、USB 3.x、USB Type-C**。对照**主板针脚丝印 + 说明书**插，不要靠猜。

- **Power SW / Reset SW 不分正负极**，插反也能用；
- **LED 灯（Power/HDD LED）分正负极**，接反了只是灯不亮，**不代表电脑坏了**，断电反过来即可；
- **USB / HD AUDIO / Type-C 都有防呆和固定方向**，尤其前置 **Type-C 插口针脚较密，最忌蛮力**，方向不对硬插会损坏针脚。

### 风扇接口与调速：认功能，别死记名字

不同主板厂商对风扇插针的命名不一样：

| 用途 | 微星（MSI） | 华硕（ASUS） | 技嘉（GIGABYTE） |
| --- | --- | --- | --- |
| CPU 风扇（必接） | CPU_FAN | CPU_FAN | CPU_FAN |
| 水冷泵 / 大电流 | PUMP_FAN | AIO_PUMP / CPU_OPT | PUMP / SYS 系列 |
| 机箱 / 系统风扇 | SYS_FAN | CHA_FAN | SYS_FAN |

**PWM 与 DC 是两种调速方式**：PWM（多为四针）靠专门的调速信号精细控速，DC（三针也能四针模式）靠改变供电电压调速。一个风扇/水冷到底用哪种、是否满速、是否需要 SATA 供电或 USB 控制，**以设备说明书和 BIOS 设置为准**。CPU 风扇一定接到 CPU_FAN（或说明书指定口），否则主板可能因检测不到 CPU 风扇转速而卡自检。

### 背插式（背线）整机：走线在背面

如果用的是《[硬件 · 背插式主板](硬件怎么选.md#背插式背线主板与背插整机)》那一套——背插主板配专用背插机箱，装机顺序和普通机略有不同：

1. **先确认成套兼容**：背插主板必须配对应背面开孔的背插机箱，显卡要用背插显卡或背插连接套件，普通机箱做不出背插效果；
2. **进箱前先在桌面装好 CPU、内存、M.2**，这一步和普通流程完全一样；
3. **主板固定进箱后，主要线材从主板「背面」的接口接出**：24-pin、CPU 供电、风扇、前面板、USB 都在背面理线仓里走，正面只看到显卡、内存这些部件；
4. **背插显卡**：按套件说明把显卡供电转到背面，显卡本身仍插在正面第一根满速 PCIe ×16 槽，通道规则不变；
5. 背面线材顺理线仓的扎带位走，别挡住背面 M.2、散热孔和背板卡扣，最后再扣背板。

!!! tip "背插只是把线换了个面，原理不变"
    防呆方向、供电必须插到底、CPU 风扇接 CPU_FAN、显卡插满速槽、跳线正负极——这些规则和普通装机完全一致，区别只是线材从背面走、正面更整洁。

## 阶段四 · 通电点亮：第一次开机先别装系统

开机前最后扫一眼：机箱内没有遗留螺丝/工具、各供电插到底、显卡供电已接、风扇没有线挡住扇叶、显示器线插在**独立显卡**输出口上。

第一次通电只确认这些（详细排查见《[点亮与故障排查](点亮与故障排查.md)》）：电源通电、风扇转、显示器有画面、**能进 BIOS**，且 BIOS 里 CPU 型号正确、**内存容量/双通道正确**、SSD 被识别、CPU 温度正常、风扇/水泵转速能读到。

!!! warning "不要一上来就双烤 + 开游戏 + 跑内存测试"
    先确认硬件都被正确识别 → 再装系统 → 再装驱动 → **再逐步加压测试**。一次性全上，出了问题反而不知道是哪一环。

## 阶段五 · 安装系统与驱动

1. 用 U 盘制作系统启动盘，引导安装；系统盘选那块第一 M.2 NVMe，分区按安装程序默认即可（会自动建立 ESP 等必要分区）。
2. **驱动顺序：先主板芯片组（Chipset）→ 再显卡驱动 → 最后网卡/声卡/无线等其他驱动**，优先去主板和显卡官网下载对应型号版本。
3. 装好后打开设备管理器，确认没有带感叹号的未知设备。

## 阶段六 · 进系统后，第一批检测软件

软件不是「装了看参数」，而是**把主观感觉变成客观证据**：

| 软件 | 用来验证什么 |
| --- | --- |
| **CPU-Z** | CPU、主板、内存代数/频率、SPD 颗粒信息、内存是否双通道 |
| **GPU-Z** | 显卡型号、显存、**PCIe 实际链路（配合 Render Test）**、显卡传感器 |
| **HWiNFO** | 各部件温度、电压、功耗、风扇转速等详细传感器 |

!!! tip "三个典型用法"
    - 「显卡性能不对劲」→ GPU-Z 看 PCIe，若是 `x16 @ x4` 就有明确方向；
    - 「32GB 怎么只认到 16GB」→ CPU-Z + BIOS 查内存是否插好/是否双通道；
    - 「CPU 怎么这么烫」→ HWiNFO 依次看温度、功耗、风扇/水泵转速，判断是散热没装好还是风扇策略问题。

这三款只负责「识别和看传感器」。烤机、内存稳定性测试（TM5/MemTest86）、显卡调校和游戏内监控（微星小飞机）、以及一整套验证顺序，统一放在《[软件调试与测试](软件调试与测试.md)》。

# 软件调试与测试

装好机、装完系统，下一步不是急着开游戏，而是用几款小软件把「我感觉没问题」变成「数据证明没问题」。这一页按用途分层介绍常用工具：**先识别硬件对不对，再看传感器，再做稳定性测试，最后才是调校和跑分**。所有软件都只是辅助，一次只改变一个变量，才好定位问题。

!!! tip "一条主线"
    **识别型号 → 看传感器温度 → 单烤 CPU / 测内存 → 单烤显卡 → 双烤 → 回到真实游戏验证。** 别一上来就 CPU、显卡、内存一起拉满，那样一旦出错不知道是谁的问题。

## :material-card-search: 硬件信息识别

这类软件只读信息、不施加负载，用来核对「商家给我的、系统认到的、我以为买的」是不是同一件东西。

### CPU-Z：核对 CPU 与内存

**CPU-Z 是一款免费的 CPU/主板/内存信息软件（Windows）**，重点看：

- **CPU 页**：名字、核心/线程、核心电压、当前频率，确认型号和标称一致；
- **Mainboard 页**：主板型号、芯片组、BIOS 版本（判断要不要刷 BIOS）；
- **Memory 页**：内存当前是否**双通道（Dual Channel）**、实际运行频率；
- **SPD 页**：每条内存插在哪个槽、颗粒厂、XMP/EXPO 预设参数。

!!! note "内存频率的「一半」错觉"
    DDR 是双倍速率，CPU-Z 里看到的 DRAM Frequency 约等于等效频率的一半（例如显示 3000MHz 上下，对应 DDR5-6000）。这是正常的，别误以为内存没跑满。

### GPU-Z：核对显卡与 PCIe 链路

**GPU-Z 是一款免费的显卡信息与状态检测软件（Windows）**，重点：

- **Name / 显存 / 着色器数量**：对照官方规格，二手卡用来识别假卡、刷 BIOS 改名卡；
- **Bus Interface（总线接口）**：显示 PCIe 协商状态，形如 `PCIe x16 4.0 @ x16 4.0`；
- **Sensors 传感器页**：核心/显存频率、温度、功耗、风扇转速。

判断显卡是不是跑在满速槽，要配合 **Render Test（渲染测试，点 Bus Interface 旁的问号按钮，让显卡短暂满载）**：桌面待机时链路会自动降速省电，满载后仍停在 `@ x4 / x8`，才需要去查是不是插错槽、通道共享或没插到底，详见《[硬件 · M.2 与 PCIe 通道布局](硬件怎么选.md#m2-与-pcie-通道布局)》。

## :material-chart-line: 传感器与实时监控

### HWiNFO：最全的硬件传感器

**HWiNFO（免费，选 Sensors-only）**能读到几乎所有传感器：每个核心的温度/频率/电压、CPU 封装功耗、显卡热点（Hot Spot）与显存温度、主板各路电压、风扇转速、硬盘 SMART。排查「为什么卡、为什么热、为什么掉频」时，它比「娱乐跑分」类软件可信得多。新手只需要关注：CPU 封装温度与功耗、GPU 核心/热点温度、+12V 电压、各盘温度。

### 微星小飞机的 OSD：游戏里实时看数据

**MSI Afterburner（微星小飞机，免费，A/N 卡通用）**自带 RivaTuner Statistics Server，可以在游戏画面角落叠加显示**帧率、CPU/显卡占用与频率温度、显存和内存占用、帧时间**。判断「游戏掉帧到底怪 CPU 还是显卡」时，看 OSD 里谁先占满即可：显卡 99% 是显卡瓶颈，显卡没满而 CPU 某核顶满，是 CPU 瓶颈。

## :material-stability: 稳定性与烤机测试

烤机是让硬件短时间高负载，以暴露散热、供电、内存、超频的不稳定。**烤机功耗/温度高于日常，属于「压力测试」而非使用常态，不要 24 小时烤。**

### CPU 稳定性

- **Cinebench（R23 / 2024）**：用渲染测单核、多核分数，跑一圈十几分钟，既能对比性能，也能看温度是否稳定、会不会中途报错，是最温和常用的一关；
- **Prime95（Small FFTs）/ OCCT**：更极端的 CPU 烤机，Small FFT 发热最猛，用来快速验证超频/降压是否稳定，**一般跑 10～30 分钟足够**，温度秒撞墙就说明散热或电压要调整；OCCT 还带电源测试、数据完整性校验。

### 内存稳定性

内存不稳的表现很隐蔽：随机蓝屏、程序闪退、游戏崩溃、文件损坏。

- **TestMem5（TM5）**：常用的内存压力测试，配合 anta777 等严格配置循环跑，**开了 XMP/EXPO 或手动超频后建议跑几轮，0 错误才算稳**；
- **MemTest86**：做成 U 盘启动盘、在进 Windows 之前裸机测内存，最彻底，排查疑难蓝屏时用；
- 测出错误，先回默认频率，再逐步收紧，别一次同时改频率、时序、电压。

### 显卡稳定性

- **FurMark（甜甜圈）**：经典显卡烤机，让 GPU 长时间满载看温度和是否花屏，现代显卡有功耗/温度保护，**跑 10～15 分钟即可，没必要长时间折磨**；
- **3DMark（Time Spy / Steel Nomad 等）**：更接近真实游戏的基准跑分，**循环跑 Stress Test 能得到稳定性百分比**，分数也能和同型号横向对比，判断显卡是否正常发挥。

### 硬盘检测

- **CrystalDiskInfo**：看硬盘健康度、SMART 属性、**通电次数/时间（验二手）**、温度、传输模式；
- **CrystalDiskMark**：测顺序和 4K 随机读写，验证固态是不是跑在应有的通道速度上（若顺序速度异常低，回去查 M.2 通道和 PCIe 链路）。

## :material-tune: 显卡调校：微星小飞机

MSI Afterburner 除了监控，也是显卡微调工具：

- **Core Clock / Memory Clock**：核心、显存频率曲线，小步加，每步用 3DMark 或游戏验证；
- **Power Limit / Temp Limit**：功耗墙、温度墙，适当放开能让高端卡维持更久睿频；
- **Fan Curve 风扇曲线**：自定义「温度—转速」曲线，在噪音和温度间找平衡；
- 不稳定的表现是花屏、驱动重置、黑屏，退回默认即可。**不要盲目加电压，刷显卡 BIOS 不建议新手碰**，原理见《[硬件 · 显卡超频与调校](硬件怎么选.md#显卡超频与调校)》。

## :material-check-all: 新装机器的一套验证流程

!!! success "建议顺序（一次只加一个负载）"
    1. **识别**：CPU-Z / GPU-Z 核对型号、内存双通道与频率、硬盘容量和通道；
    2. **轻载观察**：HWiNFO 挂着，看待机温度、风扇是否被识别、电压是否正常；
    3. **单烤 CPU**：Cinebench 起步，必要时 OCCT/Prime95 短时验证，盯温度和降频；
    4. **测内存**：开 XMP/EXPO 后用 TM5 跑圈，0 错误；
    5. **单烤显卡**：FurMark / 3DMark 循环，盯核心、热点、显存温度和供电；
    6. **双烤**：CPU + 显卡同时满载，验证电源余量和机箱散热（这步最接近最坏情况）；
    7. **回到真实使用**：微星小飞机 OSD 进常玩的游戏，看帧时间、占用和温度。

!!! warning "几个要记住的边界"
    - 烤机通过 ≠ 永远稳定，但烤机必崩一定有问题；烤机温度高于游戏是正常的；
    - 跑分高低受驱动、室温、分辨率、后台程序影响，**和同型号比区间即可，别纠结一两百分**；
    - 任何超频/降压都以「长期稳定、温度可控」为前提，不稳就回默认，必要时清 CMOS，见《[点亮与故障排查](点亮与故障排查.md)》。

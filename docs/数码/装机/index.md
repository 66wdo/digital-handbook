## 硬件关系一图流（待补充示意图）

```text
需求与预算
   │
   ├─ CPU ←→ 主板（插槽/芯片组匹配）
   │            └─ 内存（代数/频率/插槽）
   ├─ 显卡（由游戏/生产力需求决定档位）
   ├─ 硬盘（主板接口匹配）
   ├─ 散热（压住 CPU 的功耗与温度墙）
   ├─ 电源（按整机峰值功耗留余量，决定稳定性底线）
   └─ 机箱（尺寸兼容：主板板型、显卡长度、散热高度、电源规格）
```

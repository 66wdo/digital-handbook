# 硬件怎么选

这页不按教科书讲原理，而是按**你要解决的问题**来组织：右边目录就是一个个部件，想了解谁点开它；每个部件下都是你大概率会问的问题，直接给判断和做法。

!!! tip "先对号入座，你属于哪种情况"
    - **我要配机、不知道钱怎么分、谁配谁** → 直接看文末《[搭配与平衡](#搭配与平衡钱和兼容怎么定)》。
    - **我就想定某个部件** → 点右侧目录里的 CPU / 显卡 / 内存……默认收起，点哪个展开哪个。
    - **机器已经出毛病、想知道是谁的锅** → 每个部件末尾都有「它可能造成的症状」，或直接去《[点亮与故障排查](点亮与故障排查.md)》。

## :material-chip: CPU

CPU 决定你电脑的「通用下限」——日常卡不卡、多开行不行、游戏最低帧稳不稳。下面是挑 CPU 时真正要回答的几个问题。

### 我该买什么档次？

别先看核心数，先看你拿它干什么：

=== "办公 / 影音 / 轻量网游"
    中端就够，省下的钱给固态、内存容量和显示器，体验提升更明显。

=== "主流网游、2K 以内高刷"
    选**单核强、缓存大**的型号，高刷网游更吃单核而不是核心数。

=== "3A 大作 / 4K"
    分辨率越高越吃[显卡](#显卡)，CPU 主流偏上即可，不用上旗舰。

=== "剪辑 / 渲染 / AI / 多开"
    优先多核多线程；同时看你的软件是不是主要靠显卡加速，决定钱往哪边偏。

### 游戏该把钱给 CPU 还是显卡？

看分辨率：**1080P 高刷更吃 CPU，2K/4K 更吃显卡**。高分辨率下中端 CPU 配高端显卡，比旗舰 CPU 配中端显卡帧数更高；反过来，1080P 高刷网游用弱 CPU，高端显卡会被拖住。

### 核心数越多越好吗？几核才够用？

不是越多越好，关键看软件能不能用满：日常、网游 6~8 核就富余；主流游戏 6~8 核足够、8 核以上提升很小；同时直播、多开、渲染、编译才真正吃 12 核以上。**多余的核心不会让游戏更快，钱要花在你的用途用得上的地方。**

### 型号后缀 F / K / X3D / G 都是什么意思？

后缀直接决定你要不要买独显、能不能超频：

| 后缀 | 常见平台 | 含义 | 对你的影响 |
| --- | --- | --- | --- |
| 无后缀 | Intel / AMD | 标准版 | 多数带核显，最省心 |
| F / KF | Intel | **没有核显** | 必须买独立显卡才能点亮 |
| K | Intel | 不锁倍频、可超频 | 要配可超频主板才有意义 |
| X | AMD | 高频率、可超频 | 性能释放更高，也更吃散热 |
| G | AMD | 带较强核显 | 不玩大游戏可暂时不买独显 |
| X3D | AMD | 带超大 3D 缓存 | 游戏帧数尤其网游很强 |

!!! tip "核显是一份「保险」"
    哪怕你有独显，**带核显的版本在显卡出问题、排查黑屏时能顶上当「亮机卡」**用（把视频线插主板就能测）。预算差不大时，留个核显更从容。

### 散片和盒装差在哪，能买吗？

CPU 本身几乎不会坏，区别主要在渠道和质保：**盒装**走官方质保、部分带原装散热器；**散片**通常是 OEM 流出、店铺质保、价格更低、不带风扇。找口碑好、支持验机的店买散片性价比很高，到手检查触点/针脚无使用痕迹即可。

### 功耗（TDP/PL）跟我有什么关系？

它不代表性能，代表**你要配多强的[散热](#散热)和[电源](#电源)、主板供电够不够**。选高功耗 CPU，就要同步把这三样提上去，否则满载会降频。

!!! warning "CPU 可能造成的症状（排查时从这个角度看）"
    - 高刷网游帧数上不去、最低帧频繁掉 → 可能是 CPU 单核不够，也可能是[内存单通道](#两条还是一条双通道到底差多少)；
    - 一满载就降频、温度撞墙 → 先查[散热](#解热能力怎么和-cpu-对上)和主板供电，别急着怪 CPU；
    - 点不亮、Debug 灯停在 CPU → 多数是插槽/供电/接触问题，见《[点亮与故障排查](点亮与故障排查.md)》。

## :material-expansion-card: 显卡

显卡（上面那颗核心芯片叫 GPU）管游戏画面和渲染、AI、视频编解码。挑显卡基本就是回答下面几问。

### 按什么定显卡档位？

| 你的目标 | 该怎么选 |
| --- | --- |
| 1080P 高刷网游 | 中端显卡即可，钱更多留给 CPU |
| 2K 中高画质 3A | 中高端，CPU 主流偏上搭配 |
| 4K / 光追 / 高材质 | 高端卡 + 大显存，CPU 反而不用最旗舰 |
| 剪辑 / AI / 生产力 | 先看显存容量和计算生态，别只看游戏跑分 |

### 显存多大才够？

显存装的是画面材质和计算数据：**1080P 8GB 起步、2K 建议 12GB 上下、4K / 高材质 / 本地 AI 直接奔着 16GB 以上**。显存不够的表现是高画质突然爆显存、掉帧或卡顿，这不是显卡核心慢，是显存被塞满。

### 同一颗芯片，不同品牌/非公版差在哪？

不同品牌用同一颗 GPU，**核心性能差距通常只有几个百分点**，差价主要买的是：散热规模（几风扇几热管）、出厂频率、供电用料、噪音、外观和售后。预算有限选靠谱品牌的入门非公即可，不必为「旗舰皮」多花一大笔；但要避开散热严重缩水、温度撞墙的型号。

### 光追、DLSS / FSR / 帧生成要为它加钱吗？

- **光追**让反射、阴影、全局光照更真实，但很吃性能，想开光追建议显卡档位往上提一级；
- **DLSS（N 卡）/ FSR（通用）**是超分辨率技术，用算法把低分辨率放大，能明显提帧；**帧生成**再插帧提流畅度，但会增加一点操作延迟，竞技网游不必依赖，单机大作很实用。
- 结论：主玩 3A 单机、想开光追和帧生成，优先支持这些技术且性能够的卡；纯竞技网游不必为此加钱。

### A 卡还是 N 卡怎么挑？

两家游戏都能玩，差异主要在生态：**N 卡（英伟达）**在 AI/深度学习、部分生产力加速、DLSS/光追生态、编码器上更普及；**A 卡（AMD）**同价位显存往往给得更大、传统光栅性价比高、部分开源/编解码场景友好。按你要用的具体软件和游戏来定，而不是只看品牌立场。

### 游戏掉帧，怎么判断是不是显卡没发挥？

先别急着换卡。有一个非常常见、且和显卡本身无关的原因：**显卡插错了 PCIe 槽，实际只跑在 x8 / x4 带宽**。用 GPU-Z 的 Bus Interface（总线接口）配合 Render Test（渲染测试）一测便知，操作和真实案例见《[装机流程指南 · 安装显卡](装机流程指南.md#安装显卡建议最后装给走线留空间)》。

### 买二手显卡要注意什么？

- 看金手指、挡板螺丝有无严重磨损，问清是否矿卡、是否维修过；
- 到手立刻跑压力测试/甜甜圈，看**核心温度、显存温度（尤其 GDDR6X）、有无花屏掉驱动**；
- 用 GPU-Z 核对型号、显存、PCIe 链路是否正常，具体见《[装机流程指南](装机流程指南.md#安装显卡建议最后装给走线留空间)》。

!!! warning "显卡可能造成的症状"
    - 游戏帧数明显偏低、跑分异常 → 先查 PCIe 带宽（x16@x4）、驱动、[电源功耗](#电源功率到底留多少余量)，再怀疑卡本身；
    - 通电但黑屏、Debug 灯停在 VGA → 先查**视频线是不是插在独显上**、显卡是否插到底，见《[点亮与故障排查](点亮与故障排查.md)》；
    - 高负载黑屏/重启/花屏/掉驱动 → 查[供电是否插到底](#模组线能不能和别的电源混用)、电源功率、温度和显存。

## :material-developer-board: 主板

主板不直接提高跑分，它决定你**能上什么 CPU 和内存、有几个 M.2、供电稳不稳、以后能不能扩展**。

### 主板要堆多好？是不是越贵越快？

同芯片组、供电够的前提下，贵主板主要给你更好的供电散热、更多 M.2/USB、更强扩展和超频能力，**不会把同一颗 CPU 跑出更高分**。按「能不能稳定喂饱你的 CPU + 接口够不够用」来选，而不是盲目追旗舰。

### 芯片组（B / H / Z、A / B / X）怎么选？

芯片组决定扩展上限和能否超频：主流的 **B 系列**（Intel B、AMD B）供电和接口对绝大多数人都够用、性价比最高；高端 **Z / X 系列**才支持给 CPU 超频、给更多 PCIe 通道和 M.2/USB；入门 **H / A 系列**适合不折腾的办公机。**不超频、不堆多盘多卡，中端芯片组就是甜点。**

### 「丐版」主板能带高端 CPU 吗？

能，但要同时满足两条：**插槽和 BIOS 支持这颗 CPU**，且**供电相数和供电散热压得住它的持续功耗**。满足就没问题；压不住的表现是高负载掉压降频。

### 供电怎么看够不够？

看 **VRM 供电相数、是不是 DrMOS、供电有没有散热片**。不用背参数，简单办法：查这块主板带同型号 CPU 的实测，看高负载下供电温度和 CPU 功耗能不能稳住。带 100W 以上的中高端 CPU，避开「几相裸电感、无散热片」的极端丐版即可。

### 板型 ATX / M-ATX / ITX 怎么定？

- **ATX**：扩展最全、插槽最多，适合大机箱和多硬盘/多扩展；
- **M-ATX**：紧凑、性价比高，绝大多数人够用，是最常见选择；
- **ITX**：最小，能塞进小机箱，但同芯片更贵、挑散热高度/显卡长度/电源规格。
先定机箱大小，再反过来定板型。

### 板载 Wi-Fi / 蓝牙要不要？

台式机**插网线最稳**；如果不方便布线、要连无线耳机/手柄，就选带 Wi-Fi 的版本，或之后加装一张 M.2 无线网卡（注意它可能占用某个 M.2/通道）。

### 新 CPU 配老主板点不亮怎么办？

这通常是**老主板出厂 BIOS 还不认识新 CPU**。要么借一颗兼容 CPU 先点亮升级 BIOS，要么选带 **USB Flashback（免 CPU 刷写）**的主板——不装 CPU、内存，只插电源和 U 盘、按个键就能更新 BIOS，买新平台时优先认这个功能。

### M.2 槽、PCIe 槽是不是随便插？

不是，这是最容易踩的坑：

- M.2 有的 **CPU 直连**、有的走芯片组，有的槽和某个 SATA / PCIe 口**共享通道**，插上会让另一个口降速或失效；
- 两根长 PCIe 槽「长得一样」，第二根可能只有 x8/x4，**主显卡永远插说明书指定的第一根满速槽**。

安装与验证看《[装机流程指南 · M.2 / 显卡](装机流程指南.md#安装-m2-固态硬盘)》，买前翻主板手册的「M.2 / PCIe 通道说明」。

!!! warning "主板可能造成的症状"
    - 某个 M.2/SATA 口突然不能用、固态跑不满速 → 多半是通道共享或插错槽，不是硬盘坏；
    - 超频/开 XMP 后无限重启 → 清 CMOS 恢复默认即可，见《[点亮与故障排查](点亮与故障排查.md)》；
    - Debug 灯轮流卡、部分 USB 失灵 → 从主板设置和接触排查，而不是先怀疑 CPU。

## :material-memory: 内存

内存是程序运行时的临时工作台。真正影响体验的优先级是：**容量 ＞ 双通道 ＞ 频率时序**。

### 买多大才够？

- 办公、轻度使用：**16GB** 起步；
- 游戏、多开、一堆浏览器标签：**32GB** 是当前最舒服的甜点；
- 剪辑、虚拟机、本地跑 AI：**64GB 起**，按需再加。

### 两条还是一条？双通道到底差多少？

**优先两条组成双通道，而不是单条大容量。** 双通道对游戏最低帧、尤其用核显的机器提升非常明显。双条插哪两个槽、单条插哪个槽，按主板手册的 A2+B2 / A2，安装细节见《[装机流程指南 · 安装内存](装机流程指南.md#安装内存为什么不是有空槽就插)》。

### DDR4 还是 DDR5？频率要追高吗？

- **代数由 CPU + 主板平台决定，两代互不兼容、缺口不同、不能混插**；
- 同代之内频率越高越好，但边际收益递减，不必为几百 MHz 加很多钱；
- 新平台直接上 DDR5，老平台升级没必要为换 DDR5 连主板 CPU 一起换。

### 时序（CL）和颗粒要不要纠结？

**CL 时序越小反应越快**，但同代同频下差距日常基本感知不到，不必盯着参数表焦虑。颗粒（海力士/三星/美光等）主要影响超频潜力，普通用户开 XMP/EXPO 稳定用就够了。

### 四根插满和两根哪个好？能混插吗？

- **优先两条大容量，而不是四条插满**：四条对内存控制器压力更大，高频时反而可能要降频才稳；
- 不同品牌/频率**可以混插**，但会统一按「最低频率、最松时序」运行，想要最佳性能和稳定，尽量买**同规格套条（两连包）**。

### 开了 XMP / EXPO 才算跑到标称频率

内存出厂默认跑在保守的标准频率，**要在 BIOS 打开 XMP（Intel 平台）/ EXPO（AMD 平台）才会跑到你买的标称频率**；打开后若黑屏重启，说明这档不稳，清 CMOS 后降一档，详见《[点亮与故障排查](点亮与故障排查.md#无限重启--卡自检先清-cmos)》。

!!! warning "内存可能造成的症状（特别容易「背锅」也容易被冤枉）"
    - **买 32GB 只认到 16GB、双通道没认到** → 先重插、换槽、看 CPU-Z，而不是认定内存坏；
    - 开机黑屏、Debug 灯停在 DRAM → 九成是没插到底或 XMP/EXPO 不稳，先清 CMOS、逐条测试；
    - 游戏偶发卡顿、帧数不稳 → 可能正是单通道或容量不足，不一定是[显卡](#游戏掉帧怎么判断是不是显卡没发挥)或 [CPU](#游戏该把钱给-cpu-还是显卡) 的问题。

## :material-database: 硬盘

硬盘决定你开机、开软件、读存档有多快。记住一句：**系统和常用软件一定上 NVMe 固态，机械盘只当仓库。**

### 固态到底怎么选？

- **接口/协议**：M.2 NVMe（走 PCIe，最快）＞ SATA 固态 ＞ 机械硬盘；注意 M.2 只是外形，跑多快取决于协议；
- **颗粒**：TLC 是当前主流、寿命和速度均衡；QLC 更便宜、缓外写入偏弱，更适合当仓库/只读盘；
- **独立缓存**：带独立缓存的重负载（持续大拷贝、专业读写）更稳，无缓存盘靠 HMB 借内存，日常游戏开机几乎无感；
- **缓外速度**才是超大文件持续拷贝时的真实下限，**TBW（写入寿命）**普通用户几年用不完，不必焦虑。

### PCIe 4.0 / 5.0 要不要追新？

日常开机、开软件、进游戏，**PCIe 3.0 到 4.0 的体感差距已经很小，5.0 更快但发热大、价格高**。性价比甜点是靠谱的 PCIe 4.0 盘；只有经常搬运超大文件、做专业素材读写，5.0 才值回票价，并要做好散热。

### 容量起步多大？系统盘和仓库盘怎么分？

**系统盘建议 1TB 起步**——512GB 在游戏体积越来越大的今天很快吃紧。一块 1TB NVMe 装系统 + 常用软件 + 常玩游戏；大容量固态或机械盘当素材、冷数据仓库。别把系统装机械盘上，那会让整台机器「看起来很慢」。

### M.2 固态装哪个槽？

做系统盘优先**主板手册推荐的第一 M.2 槽**（通常 CPU 直连、离 CPU 最近）。记得撕掉导热垫保护膜、斜插压下固定，完整步骤见《[装机流程指南 · 安装 M.2](装机流程指南.md#安装-m2-固态硬盘)》。

!!! warning "硬盘可能造成的症状"
    - 固态速度远低于标称 → 查是不是插了芯片组/共享通道槽、是否只跑在 PCIe x1/x2；
    - 插上 M.2 后某个 SATA 口消失 → 通道共享，正常现象，看手册换口；
    - 卡 BOOT 灯、找不到启动盘 → 查启动顺序和系统盘是否接好，见《[点亮与故障排查](点亮与故障排查.md)》。

## :material-power-plug: 电源

电源是整机稳定和硬件安全的**底线**，最不该省。你只需要算清功率、认准接口、别乱搭模组线。

### 电源功率到底留多少余量？

把 CPU + 显卡满载功耗加上其他部件得到整机峰值，**再留 30%~40% 余量**选额定功率。这样电源常年工作在高效、低温、低噪区间。比总瓦数更关键的是 **+12V 这一路的输出能力**（CPU、显卡都吃它）。

### 80PLUS 金牌铜牌重要吗？

它是**转换效率**认证，反映用电效率和用料水平，但要结合正规品牌型号一起看，不能只看牌级。一个靠谱品牌的铜牌/主流方案，远好于杂牌虚标的「金牌」。

### 非模组 / 半模组 / 全模组怎么选？

- **非模组**：线全焊死、最便宜，就是多余的线要藏好；
- **半模组**：主板/CPU 必备线焊死、其余可插拔，性价比和整洁度平衡；
- **全模组**：所有线可插拔，最好走线、价格更高。
性能上三者没有区别，按你对走线整洁度的要求和预算选。

### ATX 3.x 和 12V-2x6 是什么，新显卡必须吗？

**ATX 3.0/3.1** 是新电源规范，专门应对新显卡的瞬时功耗尖峰，并带原生 **12V-2x6（前身 12VHPWR）显卡供电口**。用 RTX 40/50 系或更高端新卡，优先选带原生 12V-2x6 的 ATX 3.x 电源；老电源用显卡附赠的转接线也能行，但务必把接口完全插到底、根部别死折。

### 模组线能不能和别的电源混用？

!!! danger "绝对不要混用不同电源的模组线"
    哪怕接口外观一模一样，不同电源的**针脚定义可能不同，混用有烧毁硬件的风险**。只用本电源原配、或厂家明确标注兼容的线。

### 电源能省吗？二手电源敢不敢用？

电源内部是电解电容，有寿命、会老化，而且它一旦失控可能连累其他硬件，**是最不建议买二手/杂牌的部件**。预算紧张可以在显卡、外观上让一步，电源选正规品牌、功率留足，这钱是给整机买保险。

!!! warning "电源可能造成的症状"
    - 一上负载就重启、黑屏、闪退 → 典型功率/12V 余量不足或电源老化；
    - 新显卡高负载黑屏 → 查供电是否插到底、功率够不够、12V-2x6 根部有没有死折；
    - 随机不稳、硬盘掉线、USB 掉设备 → 也可能是电源供电质量问题，别只盯着主板。

## :material-weather-windy: 散热

散热的任务就一个：**把 CPU（和显卡）的热量及时带走，让它不因过热降频**。

### 解热能力怎么和 CPU 对上？

看散热标称的**解热瓦数（TDP/解热功耗）是否 ≥ CPU 满载功耗并留点余量**，而不是数热管几根、外观多炫。功耗越高的 CPU，越要解热规格往上提一档。

### 风冷还是水冷？下压还是塔式？

- **下压式风冷**：矮、兼容小机箱，还能顺带给主板周边散热，解热上限较低，适合低功耗 ITX；
- **塔式风冷**：同价位解热强、寿命长、无漏液顾虑，是主流首选，要核对机箱**散热限高**和是否挡内存；
- **一体式水冷（AIO）**：解热上限高、机箱风道通透，要核对**冷排尺寸/安装位**，接线务必看说明书（水泵不一定插 AIO_PUMP，有反常识案例，见《[装机流程指南 · 散热](装机流程指南.md#安装-cpu-散热器)》）。

### 水冷会不会漏液？能用几年？

正规品牌一体式水冷是封闭回路，漏液概率很低，且多数提供「漏液包赔」；寿命主要看水泵，通常以多年计。如果你不追极限解热、也不想有任何顾虑，**高端塔式风冷更省心、几乎免维护**。

### 硅脂是不是越薄越好？

不是。硅脂用来填补金属接触面的微观空隙，**均匀完整覆盖即可**，豌豆大小一点、靠散热器压上去自然铺开，不用徒手刮成一层纸。几年后温度异常升高，也可能是硅脂干了，重新涂一次即可。

### 机箱风扇怎么配，看风量还是风压？

- **吹冷排/散热鳍片**（有阻力）优先看**风压**；
- **机箱进/出风**（开阔通道）优先看**风量**；
- 噪音看转速上限、轴承和扇叶设计，想安静选同风量下转速更低的。具体风道方向见[机箱](#风道怎么安排)。

!!! warning "散热可能造成的症状"
    - CPU 温度高、撞温度墙降频 → 查硅脂、扣具有没有压紧、风扇是否接到 CPU_FAN、风道；
    - 主板卡自检、报 CPU Fan 错误 → 多是水冷/风扇插错口，按说明书接回，见《[装机流程指南](装机流程指南.md#风扇接口与调速认功能别死记名字)》。

## :material-desktop-classic: 机箱

机箱不影响性能，但它是所有尺寸的「总容器」，买错任何一项都要返工。

### 买机箱要逐项核对哪些尺寸？

- [ ] 支持你的**主板板型**（ATX / M-ATX / ITX）；
- [ ] **显卡限长 / 厚度**装得下（三风扇厚卡、有水冷排挤时尤其注意）；
- [ ] **风冷限高**、**水冷冷排位**（240/280/360）对得上；
- [ ] 电源规格位（ATX/SFX）、硬盘位数量够；
- [ ] 前面板有没有你要的 Type-C / USB 数量。

### 网孔面板和玻璃侧透哪个好？

**前面板网孔**进风足、散热好、噪音略小，缺点是容易进灰、灯效看得少；**整块玻璃/封闭前面板**颜值高、RGB 好看，但进风受限，高功耗硬件容易闷罐。追求低温选大面积进风网孔，想要灯效再兼顾风道即可，侧板是不是玻璃不影响散热。

### 风道怎么安排？

**前面/下面进冷风，后面/上面排热风，进风略多于出风**形成正压差，灰尘也更少。别为了「好看」把风扇全装成出风或装反风向（风扇标签面一般是出风侧）。

### 装 ITX 小机箱要额外注意什么？

小机箱里所有尺寸都更苛刻：**先定机箱，再按它的显卡限长、风冷限高、电源规格（常要 SFX）、冷排位去反选其他部件**，并预留走线空间。ITX 装机顺序也更讲究，通常先把主板子模块装好再进箱。

!!! tip "机箱「可能造成的症状」"
    温度普遍偏高、显卡撞温度墙 → 先看是不是闷罐面板、风扇方向装反、进风不足；侧板盖不上 → 显卡太长/散热太高，属于尺寸没核对，下单前用上面清单逐项对。

## :material-vector-link: 搭配与平衡（钱和兼容怎么定）

如果你是从零配机，记住这条推导链，顺序别搞反：

!!! success "选件推导链"
    **用途和分辨率定显卡档位 → 显卡配门当户对的 CPU → CPU 决定主板平台和内存代数 → CPU/显卡功耗决定散热和电源 → 全部尺寸最后决定机箱。**

### 谁在拖谁的后腿（瓶颈）？

- **分辨率越高越吃显卡**：4K 下旗舰和中端 CPU 差距很小，钱给显卡；**1080P 高刷反过来更吃 CPU**；
- **单通道内存**是隐形短板，会同时拖累游戏帧和核显；
- **系统盘若不是 NVMe 固态**，整台机器都会显得迟钝；
- **电源和散热是地基**：它们不加分，但不够会让你直接翻车（降频、重启）。

### 「能插上」≠「该插」，「能用」≠「跑满」

PCIe / M.2 通道是有限且会共享的：第二根长 PCIe 槽可能只有 x4、某个 M.2 会占用 SATA 口。**装机前花十分钟看主板手册的通道说明，能避开绝大多数「能用但变慢」的坑**，验证方法见《[装机流程指南](装机流程指南.md)》和《[点亮与故障排查](点亮与故障排查.md)》。

### 下单前兼容性卡死清单

- [ ] CPU 插槽 = 主板插槽，且主板 BIOS 已支持该 CPU（新 U 配老板可能要先刷 BIOS）
- [ ] 内存代数（DDR4/DDR5）与主板一致，频率在平台支持范围内
- [ ] 主板供电规模压得住所选 CPU 的满载功耗
- [ ] 显卡长度 / 厚度装得进机箱，不与水冷排、硬盘位冲突
- [ ] 风冷限高 / 水冷冷排尺寸与机箱匹配，扣具支持 CPU 平台
- [ ] 电源对整机峰值留 30% 以上余量，+12V 能力足够
- [ ] 显卡供电接口齐全（8-pin 数量或 12V-2x6），只用原厂模组线
- [ ] M.2 / SATA 数量满足规划，已确认通道共享关系
- [ ] 机箱支持主板板型，风扇位与风道已规划
- [ ] 显示器接口 / 刷新率与显卡输出匹配（高刷要对应版本的 DP/HDMI 线）

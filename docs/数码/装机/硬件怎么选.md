# 硬件怎么选

这页不按教科书讲原理，而是按**你要解决的问题**来组织：右边目录就是一个个部件，想了解谁直接点过去；每个部件下都是你大概率会问的问题，直接给判断和做法。

!!! tip "先对号入座，你属于哪种情况"
    - **我要配机、不知道钱怎么分、谁配谁** → 直接看文末《[搭配与平衡](#搭配与平衡钱和兼容怎么定)》。
    - **我就想定某个部件** → 点右侧目录里的 CPU / 显卡 / 内存……
    - **机器已经出毛病、想知道是谁的锅** → 每个部件末尾都有「它可能造成的症状」，或直接去《[点亮与故障排查](点亮与故障排查.md)》。

## :material-chip: CPU

CPU 决定你电脑的「通用下限」——日常卡不卡、多开行不行、游戏最低帧稳不稳。你大概率只需要回答下面几个问题。

### 我该买什么档次？

别先看核心数，先看你拿它干什么：

=== "办公 / 影音 / 轻量网游"
    中端就够，省下的钱给固态、内存容量和显示器，体验提升更明显。

=== "主流网游、2K 以内高刷"
    选**单核强、缓存大**的型号，高刷网游更吃单核而不是核心数。

=== "3A 大作 / 4K"
    分辨率越高越吃[显卡](#显卡)，CPU 主流偏上即可，不用上旗舰。

=== "剪辑 / 渲染 / AI / 多开"
    优先多核多线程；同时看你的软件是不是主要靠显卡加速，决定钱往哪边偏。

### 游戏该把钱给 CPU 还是显卡？

看分辨率：**1080P 高刷更吃 CPU，2K/4K 更吃显卡**。高分辨率下中端 CPU 配高端显卡，比旗舰 CPU 配中端显卡帧数更高。反过来，1080P 高刷网游用弱 CPU，高端显卡会被拖住。

### 功耗（TDP/PL）跟我有什么关系？

它不代表性能，代表**你要配多强的[散热](#散热)和[电源](#电源)、主板供电够不够**。选高功耗 CPU，就要同步把这三样提上去，否则满载会降频。

!!! warning "CPU 可能造成的症状（排查时从这个角度看）"
    - 高刷网游帧数上不去、最低帧频繁掉 → 可能是 CPU 单核不够，也可能是[内存单通道](#两条还是一条双通道到底差多少)；
    - 一满载就降频、温度撞墙 → 先查[散热](#风冷还是水冷)和主板供电，别急着怪 CPU；
    - 点不亮、Debug 灯停在 CPU → 多数是插槽/供电/接触问题，见《[点亮与故障排查](点亮与故障排查.md)》。

## :material-expansion-card: 显卡

显卡（上面那颗核心芯片叫 GPU）管游戏画面和渲染、AI、视频编解码。挑显卡基本就是回答三问：**玩什么分辨率、要多大显存、电源机箱带不带得动**。

### 按什么定显卡档位？

| 你的目标 | 该怎么选 |
| --- | --- |
| 1080P 高刷网游 | 中端显卡即可，钱更多留给 CPU |
| 2K 中高画质 3A | 中高端，CPU 主流偏上搭配 |
| 4K / 光追 / 高材质 | 高端卡 + 大显存，CPU 反而不用最旗舰 |
| 剪辑 / AI / 生产力 | 先看显存容量和计算生态，别只看游戏跑分 |

### 显存多大才够？

显存装的是画面材质和计算数据：**1080P 8GB 起步、2K 建议 12GB 上下、4K / 高材质 / 本地 AI 直接奔着 16GB 以上**。显存不够的表现是高画质突然爆显存、掉帧或卡顿，这不是显卡核心慢，是显存被塞满。

### 游戏掉帧，怎么判断是不是显卡没发挥？

先别急着换卡。有一个非常常见、且和显卡本身无关的原因：**显卡插错了 PCIe 槽，实际只跑在 x8 / x4 带宽**。用 GPU-Z 的 Bus Interface（总线接口）配合 Render Test（渲染测试）一测便知，具体操作和真实案例见《[装机流程指南 · 显卡](装机流程指南.md#9-安装显卡建议最后装给走线留空间)》。

!!! warning "显卡可能造成的症状"
    - 游戏帧数明显偏低、跑分异常 → 先查 PCIe 带宽（x16@x4）、驱动、[电源功耗](#电源功率到底留多少余量)，再怀疑卡本身；
    - 通电但黑屏、Debug 灯停在 VGA → 先查**视频线是不是插在独显上**、显卡是否插到底，见《[点亮与故障排查](点亮与故障排查.md)》；
    - 高负载黑屏/重启/花屏 → 查[供电线是否插到底](#模组线能不能和别的电源混用)、电源功率是否够、温度。

## :material-developer-board: 主板

主板不直接提高跑分，它决定你**能上什么 CPU 和内存、有几个 M.2、供电稳不稳、以后能不能扩展**。挑主板其实就盯四件事。

### 主板要堆多好？是不是越贵越快？

同芯片组、供电够的前提下，贵主板主要给你更好的供电散热、更多 M.2/USB、更强扩展和超频能力，**不会把同一颗 CPU 跑出更高分**。所以按「能不能稳定喂饱你的 CPU + 接口够不够用」来选，而不是盲目追旗舰。

### 「丐版」主板能带高端 CPU 吗？

能，但要同时满足两条：**插槽和 BIOS 支持这颗 CPU**，且**供电相数和供电散热压得住它的持续功耗**。满足就没问题；压不住的表现是高负载掉压降频。

### M.2 槽、PCIe 槽是不是随便插？

不是，这是最容易踩的坑：

- M.2 有的 **CPU 直连**、有的走芯片组，有的槽和某个 SATA / PCIe 口**共享通道**，插上会让另一个口降速或失效；
- 两根长 PCIe 槽「长得一样」，第二根可能只有 x8/x4，**主显卡永远插说明书指定的第一根满速槽**。

具体到安装和验证，看《[装机流程指南 · M.2 / 显卡](装机流程指南.md)》。买之前翻主板手册的「M.2 / PCIe 通道说明」，一次把通道分配看明白。

!!! warning "主板可能造成的症状"
    - 某个 M.2/SATA 口突然不能用、固态跑不满速 → 多半是通道共享或插错槽，不是硬盘坏；
    - 超频/开 XMP 后无限重启 → 清 CMOS 恢复默认即可，见《[点亮与故障排查](点亮与故障排查.md)》；
    - Debug 灯轮流卡、USB 部分失灵 → 从主板设置和接触排查，而不是先怀疑 CPU。

## :material-memory: 内存

内存是程序运行时的临时工作台。真正影响你体验的优先级是：**容量 ＞ 双通道 ＞ 频率时序**。

### 买多大才够？

- 办公、轻度使用：**16GB** 起步；
- 游戏、多开、浏览器一堆标签：**32GB** 是当前最舒服的甜点；
- 剪辑、虚拟机、本地跑 AI：**64GB 起**，按需再加。

### 两条还是一条？双通道到底差多少？

**优先两条组成双通道，而不是单条大容量。** 双通道对游戏最低帧、尤其对用核显的机器提升非常明显。双条插哪两个槽、单条插哪个槽，按主板手册的 A2+B2 / A2，安装细节见《[装机流程指南 · 内存](装机流程指南.md#3-安装内存为什么不是有空槽就插)》。

### DDR4 还是 DDR5？频率要追高吗？

- **代数由 CPU + 主板平台决定，两代互不兼容、缺口不同、不能混插**；
- 同代之内，频率越高、时序越紧越好，但边际收益递减，不必为几百 MHz 加很多钱；
- 内存默认跑保守频率，**要在 BIOS 打开 XMP（Intel 平台）/ EXPO（AMD 平台）才会跑到你买的标称频率**。

!!! warning "内存可能造成的症状（它特别容易「背锅」也特别容易被冤枉）"
    - **买 32GB 只认到 16GB、双通道没认到** → 先重插、换槽、看 CPU-Z，而不是认定内存坏；
    - 开机黑屏、Debug 灯停在 DRAM → 九成是没插到底或 XMP/EXPO 不稳，先清 CMOS、逐条测试；
    - 游戏偶发卡顿、帧数不稳 → 可能正是单通道或容量不足，不一定是[显卡](#游戏掉帧怎么判断是不是显卡没发挥)或 [CPU](#游戏该把钱给-cpu-还是显卡) 的问题。

## :material-database: 硬盘

硬盘决定你开机、开软件、读存档有多快。记住一句：**系统和常用软件一定上 NVMe 固态，机械盘只当仓库。**

### 固态到底怎么选？

- **接口/协议**：M.2 NVMe（走 PCIe，最快）＞ SATA 固态 ＞ 机械硬盘；注意 M.2 只是外形，跑多快取决于协议；
- **缓外速度**：超大文件持续拷贝时，掉出缓存后的速度才是真实下限，重度拷贝再重点看；
- **TBW（写入寿命）**：普通用户几年都用不完，不必焦虑，重度写入/做素材盘再关注。

### M.2 固态装哪个槽？

做系统盘优先**主板手册推荐的第一 M.2 槽**（通常 CPU 直连、离 CPU 最近）。装的时候记得撕掉导热垫保护膜、斜插压下固定，完整步骤见《[装机流程指南 · M.2](装机流程指南.md#4-安装-m2-固态硬盘)》。

### 系统盘和仓库盘怎么分？

一块中等容量 NVMe 装系统 + 常用软件 + 常玩的游戏；大容量固态或机械盘当素材/冷数据仓库。别把系统装在机械盘上，那会让整台机器「看起来很慢」。

!!! warning "硬盘可能造成的症状"
    - 固态速度远低于标称 → 查是不是插了芯片组/共享通道槽、是否跑成 PCIe x1/x2；
    - 插上 M.2 后某个 SATA 口消失 → 通道共享，正常现象，看主板手册换口；
    - 卡 BOOT 灯、找不到启动盘 → 查启动顺序和系统盘是否接好，见《[点亮与故障排查](点亮与故障排查.md)》。

## :material-power-plug: 电源

电源是整机稳定和硬件安全的**底线**，最不该省。你只需要算清功率、认准接口、别乱搭模组线。

### 电源功率到底留多少余量？

把 CPU + 显卡满载功耗加上其他部件，得到整机峰值，**再留 30%~40% 余量**去选额定功率。这样电源常年工作在高效、低温、低噪区间。比总瓦数更关键的是 **+12V 这一路的输出能力**（CPU、显卡都吃它）。

### 80PLUS 金牌铜牌重要吗？

它是**转换效率**认证，反映用电效率和用料水平，但要结合正规品牌型号一起看，不能只认牌子或只看牌级。一个靠谱品牌的铜牌，远好于杂牌虚标的「金牌」。

### 模组线能不能和别的电源混用？

!!! danger "绝对不要混用不同电源的模组线"
    哪怕接口外观一模一样，不同电源的**针脚定义可能不同，混用有烧毁硬件的风险**。只用本电源原配、或厂家明确标注兼容的线。

!!! warning "电源可能造成的症状"
    - 一上负载就重启、黑屏、闪退 → 典型功率/12V 余量不足或电源老化；
    - 新显卡高负载黑屏 → 查供电是否插到底、功率是否够、12V-2x6 接口根部有没有死折；
    - 随机不稳、硬盘掉线 → 也可能是电源供电质量问题，别只盯着主板。

## :material-weather-windy: 散热

散热的任务就一个：**把 CPU（和显卡）的热量及时带走，让它不因过热降频**。选型只看解热能力、平台扣具和机箱尺寸。

### 风冷还是水冷？

- **塔式风冷**：同价位解热强、寿命长、无漏液顾虑，要核对机箱**散热限高**和是否挡内存；
- **一体式水冷（AIO）**：解热上限高、机箱风道更通透，要核对**冷排尺寸/安装位**，且接线务必看说明书（水泵不一定插 AIO_PUMP，有反常识案例，见《[装机流程指南 · 水冷](装机流程指南.md#2-安装-cpu-散热器)》）。
- 判断标准：散热标称的**解热瓦数要覆盖 CPU 满载功耗**，而不是数热管几根、外观多炫。

### 硅脂是不是越薄越好？

不是。硅脂用来填补金属接触面的微观空隙，**均匀完整覆盖即可**，豌豆大小一点、靠散热器压上去自然铺开，不用徒手刮成一层纸。

!!! warning "散热可能造成的症状"
    - CPU 温度高、撞温度墙降频 → 查硅脂、扣具是否压紧、风扇是否接到 CPU_FAN、风道；
    - 主板卡自检、报 CPU Fan 错误 → 多是水冷/风扇插错口，按说明书接回。

## :material-desktop-classic: 机箱

机箱不影响性能，但它是所有尺寸的「总容器」，买错任何一项都要返工。

### 买机箱要逐项核对哪些尺寸？

- [ ] 支持你的**主板板型**（ATX / M-ATX / ITX）；
- [ ] **显卡限长 / 厚度**装得下（三风扇厚卡、有水冷排挤时尤其注意）；
- [ ] **风冷限高**、**水冷冷排位**（240/280/360）对得上；
- [ ] 电源规格位（ATX/SFX）、硬盘位数量够；
- [ ] 前面板接口有没有你要的 Type-C / USB 数量。

### 风道怎么安排？

**前面/下面进冷风，后面/上面排热风，进风略多于出风**形成正压差，灰尘也更少。别为了「好看」把风扇全装成出风或装反风向。

## :material-vector-link: 搭配与平衡（钱和兼容怎么定）

如果你是从零配机，记住这条推导链，顺序别搞反：

!!! success "选件推导链"
    **用途和分辨率定显卡档位 → 显卡配门当户对的 CPU → CPU 决定主板平台和内存代数 → CPU/显卡功耗决定散热和电源 → 全部尺寸最后决定机箱。**

### 谁在拖谁的后腿（瓶颈）？

- **分辨率越高越吃显卡**：4K 下旗舰和中端 CPU 差距很小，钱给显卡；**1080P 高刷反过来更吃 CPU**；
- **单通道内存**是隐形短板，会同时拖累游戏帧和核显；
- **系统盘若不是 NVMe 固态**，整台机器都会显得迟钝；
- **电源和散热是地基**：它们不加分，但不够会让你直接翻车（降频、重启）。

### 「能插上」≠「该插」，「能用」≠「跑满」

PCIe / M.2 通道是有限且会共享的：第二根长 PCIe 槽可能只有 x4、某个 M.2 会占用 SATA 口。**装机前花十分钟看主板手册的通道说明，能避开绝大多数「能用但变慢」的坑**，验证方法见《[装机流程指南](装机流程指南.md)》和《[点亮与故障排查](点亮与故障排查.md)》。

### 下单前兼容性卡死清单

- [ ] CPU 插槽 = 主板插槽，且主板 BIOS 已支持该 CPU（新 U 配老板可能要先刷 BIOS）
- [ ] 内存代数（DDR4/DDR5）与主板一致，频率在平台支持范围内
- [ ] 主板供电规模压得住所选 CPU 的满载功耗
- [ ] 显卡长度 / 厚度装得进机箱，不与水冷排、硬盘位冲突
- [ ] 风冷限高 / 水冷冷排尺寸与机箱匹配，扣具支持 CPU 平台
- [ ] 电源对整机峰值留 30% 以上余量，+12V 能力足够
- [ ] 显卡供电接口齐全（8-pin 数量或 12V-2x6），只用原厂模组线
- [ ] M.2 / SATA 数量满足规划，已确认通道共享关系
- [ ] 机箱支持主板板型，风扇位与风道已规划
- [ ] 显示器接口 / 刷新率与显卡输出匹配（高刷要对应版本的 DP/HDMI 线）

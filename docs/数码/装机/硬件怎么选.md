每个硬件统一按四段写：**作用与原理 → 关键指标 → 匹配/兼容关系 → 分档建议**。

## CPU（中央处理器）

- 作用：通用计算，决定多数日常与生产力任务的下限
- 关键指标待写：核心/线程、频率、缓存、功耗（PL1/PL2/TDP）、平台代际
- 怎么判断游戏 CPU 瓶颈 / 生产力 CPU 选型
- 待补充

## GPU（显卡）

- 作用：图形渲染、GPU 计算（渲染/AI/视频编解码）
- 关键指标待写：CUDA/流处理器、显存容量与位宽、功耗、光追/编解码单元
- 游戏分辨率与显卡档位匹配（1080P / 2K / 4K）
- 待补充

## 主板

- 关键指标待写：插槽与芯片组、供电规模、内存插槽、M.2 数量与通道、扩展性
- 「丐版主板能不能带高端 CPU」判断方法
- 待补充

## 内存（RAM）

- 代数（DDR4/DDR5）、频率、时序、容量、双通道
- 不同用途容量建议、XMP/EXPO 是什么

## 硬盘（SSD/HDD）

- NVMe / SATA、协议与通道、颗粒与主控、缓外速度、TBW

- 风冷 / 水冷取舍，解热能力与 CPU 功耗匹配，热管/鳍片/硅脂原理

## 兼容性检查清单

- [ ] CPU 插槽 = 主板插槽，且主板 BIOS 支持
- [ ] 内存代数 = 主板支持代数
- [ ] 显卡长度/厚度装得进机箱
- [ ] 风冷限高 / 水冷冷排位与机箱匹配
- [ ] 电源功率与接口足够（含显卡供电线）
- [ ] 机箱风扇位与风道规划
- [ ] 显示器接口/刷新率与显卡输出匹配

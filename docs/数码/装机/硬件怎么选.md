## :material-chip: CPU

CPU 是整台机器的通用计算核心，决定日常卡不卡、多开行不行、游戏的最低帧稳不稳。理解 CPU，分核心、频率缓存、型号、功耗这几个层面就够了。

### 核心与线程

**核心（Core）**是真正干活的运算单元，几个核心就是几个能同时干活的「工人」；**线程（Thread）**是任务调度的流水线，一个核心通过超线程可以同时跑两条线程，提升多任务利用率。

- Intel 的超线程叫 **HT（Hyper-Threading）**，AMD 的对应技术叫 **SMT（同时多线程）**，开关一般在 BIOS；
- 核心数决定「同时能干多少件事」，单核性能决定「单件事干得多快」，游戏更依赖后者。

#### 性能核与能效核（大小核）

从第 12 代开始，Intel 把核心分成两种：

- **性能核 P-core（大核）**：单核强、频率高，负责吃性能的重负载和游戏主线程；
- **能效核 E-core（小核）**：能效比高，负责后台、下载、多开等不那么急的活，把大核解放出来。

两者由系统调度分配任务（Intel 平台靠 Thread Director 硬件调度器配合 Windows）。**AMD 主流桌面锐龙目前是同构核心，也就是没有大核小核之分**，大小核主要是 Intel 桌面平台的概念。

!!! warning "进阶 · 打游戏要不要把小核（E 核）关掉？"
    先说结论：**没遇到问题就不用关，这是进阶排查项，新手可以直接跳过。**

    - **Windows 11** 对大小核调度更完善，一般能正确把游戏主线程放到大核，保持默认即可；
    - **Windows 10** 对大小核的调度不如 Win11，极少数情况下会把游戏主线程丢到小核，表现为帧数不低但**帧时间忽快忽慢、周期性卡顿、漏帧**；
    - 真遇到了，先在任务管理器/工具里确认游戏主线程跑在哪个逻辑核心上，再用 Process Lasso 之类工具把它固定到大核，而不是一上来在 BIOS 关核；
    - 直接关掉全部小核会损失多任务和后台能力，属于下策。系统层面升级到 Win11 通常就解决了。

#### 核心数量怎么选

| 用途 | 大致需求 |
| --- | --- |
| 办公、影音、轻量网游 | 6 核富余 |
| 主流网游、3A 游戏 | 6~8 核足够，8 核以上游戏内提升很小 |
| 直播、多开、虚拟机、渲染/编译 | 12 核以上才真正吃得到红利 |

!!! tip "超线程 / SMT 要不要开？"
    绝大多数情况**保持开启**，它白送多线程性能。只有极少数很老的竞技游戏、或极限降温时，关 SMT 可能换来几帧或更低温度，需要自己 A/B 对比，没有普适结论，别当默认操作。

### 频率、缓存与 X3D

**主频/睿频**是核心每秒运算的节拍（GHz），同代架构下越高越快；**架构（IPC）**决定每个节拍能干多少活，所以跨代不能只比频率。**缓存**是核心身边的超高速小仓库，分 L1/L2/L3，离核心越近越快，作用是提前把要用的数据备好，减少干等内存的时间。

#### X3D 与大缓存

AMD 的 **X3D** 用 3D V-Cache（3D 垂直缓存）技术把一大块 L3 缓存叠在核心上方，缓存容量远大于普通型号。游戏（尤其网游、策略/模拟这类频繁调数据的）命中率更高、**取数据延迟更低——数据直接从身边的大缓存拿，不用反复去内存等**，所以帧数和最低帧往往明显更好。

!!! danger "X3D / AMD 超频务必注意（涉及硬件安全）"
    X3D 对电压和温度非常敏感，**不要手动给核心加电压、不要盲目把电压「调到甜品」**，出厂的睿频和 PBO 已经会自动管理，手动加压只会更热、更不稳，极端过压过热真的有损坏风险。
    想压榨一点空间，进阶做法是 **PBO2 的 Curve Optimizer 走「负压」（负值）**，且必须小幅度、逐档稳定性测试；新手保持默认、把散热装好，反而是最稳的。普通 AMD（非 X3D）同理，不需要手动升压。

### 型号后缀与核显

后缀直接决定你要不要买独显、能不能超频：

| 后缀 | 平台 | 含义 | 影响 |
| --- | --- | --- | --- |
| 无后缀 | Intel / AMD | 标准版 | 多数带核显，最省心 |
| F / KF | Intel | **无核显** | 必须有独立显卡才能点亮 |
| K | Intel | 不锁倍频、可超频 | 要配可超频主板才有意义 |
| X | AMD | 高频可超频 | 释放更高，也更吃散热 |
| G | AMD | 带较强核显 | 不玩大游戏可暂不买独显 |
| X3D | AMD | 3D 大缓存 | 游戏尤其网游强 |

!!! tip "核显是一份「保险」"
    核显（集成在 CPU 里的显示单元，Intel 叫 UHD/Iris，AMD 叫 Radeon 核显）能在独显故障、排查黑屏时充当「亮机卡」，还能承担视频编码（Intel QuickSync 等）。预算差不大时，留一颗带核显的 CPU 更从容。注意 **F / KF 这类无核显型号不具备这个能力**。

#### 散片与盒装

CPU 本身极难用坏。**盒装**走官方质保、部分带原装风扇；**散片**多为 OEM 流出、店铺质保、不带风扇、价格更低。找口碑好、支持验机的店买散片性价比很高，到手检查触点/针脚无使用痕迹即可。

### 功耗与匹配

TDP / PL（Intel 的 PL1/PL2、AMD 的 PBP/MTP）衡量的是这颗 CPU 的发热和供电量级，**它不代表性能，却决定你要配多强的[散热](#解热能力匹配)、多大的[电源](#功率与余量)、以及[主板供电](#供电规模vrm)够不够**。高功耗 CPU 这三样跟不上，满载就会降频。

!!! warning "CPU 可能造成的症状"
    - 高刷网游帧数上不去、最低帧频繁掉 → 可能是单核不够，也可能是[内存单通道](#单通道与双通道)；
    - 一满载就降频、温度撞墙 → 先查[散热](#解热能力匹配)和主板供电，别急着怪 CPU；
    - 大小核机器帧时间周期性卡顿 → 见上面「要不要关小核」；
    - 点不亮、Debug 灯停在 CPU → 多为插槽/供电/接触问题，见《[点亮与故障排查](点亮与故障排查.md)》。

## :material-expansion-card: 显卡

显卡是一整张加速卡：上面那颗并行计算芯片叫 **GPU**，旁边还有显存、供电、散热。它干的活远不止游戏。

### 显卡都负责什么

- **游戏**：实时渲染 3D 画面；
- **视频创作**：剪辑时间线特效、导出编码（PR、剪映、达芬奇），其中编码靠显卡/核显里的**硬件编码器**（N 卡叫 NVENC、A 卡叫 AMF、Intel 核显叫 QuickSync）；
- **3D 建模与渲染**：Blender、C4D、玛雅等，渲染加速分不同技术阵营——**CUDA / OptiX 是 NVIDIA 专有生态**，OpenCL 是通用标准，AMD 对应 HIP/ROCm；
- **AI**：本地大模型、AI 绘图主要看 **CUDA 生态和显存容量**，这也是 N 卡目前占优的领域；
- **音乐制作**要纠正一个常见误解：音频效果器运算**主要吃 CPU**，GPU 只在视频、可视化、部分 AI 降噪插件上帮忙，别为做音乐专门堆显卡。

!!! tip "生产力选卡，先查你用的软件"
    做内容/建模/AI，别只按游戏分辨率和帧数选，先查软件官方的「GPU 加速 / 推荐显卡」说明：它吃 CUDA 还是通用标准、吃显存还是编码器，结论可能和玩游戏完全不同。

### 显卡的主要规格

- **GPU 芯片与架构**：决定底子，同芯片不同品牌性能接近；
- **流处理器 / CUDA 核心数**：并行单元规模；
- **显存**：容量、位宽、代数（GDDR6 / GDDR6X / GDDR7）和**显存带宽**；
- **TGP / TBP**：整卡功耗，决定电源和散热。

#### 显存容量与作用

显存装的是材质、贴图、模型和计算数据。**1080P 8GB 起步、2K 建议 12GB 上下、4K 高材质或本地 AI 直接奔 16GB 以上**。显存不够的典型表现是高画质突然爆显存、掉帧、卡顿——这不是 GPU 核心慢，是「工作台」被塞满了。

### 同芯片的不同品牌型号（非公版）

不同品牌用同一颗 GPU，**核心性能差距通常只有几个百分点**，差价买的是散热规模（风扇数/热管数/均热板）、出厂频率、供电用料、噪音、外观和售后。预算有限选靠谱品牌的入门非公即可，避开散热严重缩水、温度撞墙的型号，不必为「旗舰皮」多花一大笔。

### 光追与超分辨率技术

- **光追（光线追踪）**让反射、阴影、全局光照更真实，但很吃性能，想开就把显卡档位提一级；
- **DLSS**（N 卡）/ **FSR**（通用，A 卡 N 卡都能用）/ **XeSS**（Intel）是「超分辨率」：先渲染较低分辨率再用算法放大，换取更高帧数；
- **帧生成**在两帧之间插出中间帧进一步提流畅度，但会增加一点操作延迟，单机大作很香，竞技网游不必依赖。

### A 卡与 N 卡

两家游戏都能玩。**N 卡（英伟达）**胜在 CUDA/AI 生态、DLSS/光追生态、编码器和驱动功能普及；**A 卡（AMD）**同价位常给更大显存、传统光栅性价比高。按你要玩的游戏和要用的软件定，而不是品牌立场。

### 性能发挥与异常排查

帧数不对，原因是一条链，**别只盯着显卡本身**，按顺序排查：CPU 瓶颈、内存是否单通道/容量够不够、PCIe 是不是跑在 x4（插错槽）、驱动版本、电源是否触发功耗墙、温度是否撞墙、游戏自身的垂直同步/分辨率缩放设置。

这里要认识一款检测软件：**GPU-Z 是一款免费的显卡信息与状态检测软件（Windows）**，用来看型号、显存、传感器和链路状态。它的 **Bus Interface（总线接口）**一栏显示 PCIe 协商状态，配合 **Render Test（渲染测试，让显卡短暂满载）**就能看出真实链路，而不是被桌面待机的省电状态骗到。

!!! example "真实案例：为了好看插错槽，能用却掉速"
    大显卡嫌第一根槽拥挤、为方便理线插到带金属加固的第二根长槽，结果能开机却掉帧。GPU-Z 配合 Render Test 一看，`x16 @ x4`——物理是 x16 槽，实际只协商到 x4。完整过程和验证方法见《[装机流程指南 · 安装显卡](装机流程指南.md#安装显卡建议最后装给走线留空间)》。

### 二手验卡

- 看金手指、挡板螺丝磨损，问清是否矿卡、是否维修；
- 到手立刻跑压力测试，盯**核心温度、显存温度（GDDR6X 尤其）、有无花屏掉驱动**；
- 用 GPU-Z 核对型号、显存容量、PCIe 链路。

!!! warning "显卡可能造成的症状"
    - 帧数明显偏低、跑分异常 → 按上面「性能发挥与异常排查」整条链排查，别急着认定卡坏；
    - 通电黑屏、Debug 灯停在 VGA → 先查视频线是不是插在独显上、卡有没有插到底，见《[点亮与故障排查](点亮与故障排查.md)》；
    - 高负载黑屏/重启/花屏/掉驱动 → 查供电是否到底、电源功率、温度与显存。

## :material-developer-board: 主板

主板不直接提高跑分，它决定你**能上什么 CPU/内存、有几个 M.2 和什么通道、供电稳不稳、以后怎么扩展**。

### 芯片组与平台

芯片组是主板的「中枢型号」，决定扩展上限和能否超频：

- **Intel**：入门 H、主流 B、高端 Z（只有 Z 系列支持给 CPU 倍频超频，通道和接口也更多）；
- **AMD**：入门 A、主流 B、高端 X；
- 不超频、不堆多盘多卡，**主流 B 系列就是性价比甜点**，不必为用不到的扩展上旗舰。

前提是插槽同代、且主板 BIOS 已支持这颗 CPU（新 U 配老板可能要先刷 BIOS，优先选带 **USB Flashback（免 CPU 刷写）**的板）。

- **ITX（Mini-ITX）**：最小，能做小钢炮，但同芯片更贵，且挑显卡长度、风冷限高和电源（常要 SFX 小电源）。

### 供电规模（VRM）

主板围绕 CPU 的那圈供电叫 **VRM**，负责把电源电压转换成 CPU 能用的电压。看三点：**供电相数、是不是 DrMOS、供电有没有散热片**。不用背参数，最靠谱的办法是查这块主板带同型号 CPU 的实测，看高负载下供电温度和 CPU 功耗能不能稳住。带高功耗 CPU 时，避开「几相裸电感、没有供电散热片」的极端丐版。

!!! note "贵的主板，通道布局不一定样样都好"
    价格高、堆料足，不等于 M.2 / PCIe 通道布局就一定对你最合适。部分高端板为了扩展口数量会**拆分通道**，某些槽共用带宽。所以别只看价位和「金属加固插槽」，下单前翻手册的通道拆分表、看实测，确认**主显卡槽是 CPU 直连满速、你要用的 M.2 不会挤掉别的口**。

### 后置接口与板载功能

- **后置 I/O**：看 USB 版本和数量（USB 3.x / Type-C / 雷电）、网口（是否 2.5G）、音频口、Wi-Fi/蓝牙天线座；
- **前置 Type-C**：机箱前面板有 Type-C 的话，主板必须有对应插针，否则用不了；
- **板载 Wi-Fi/蓝牙**：不方便插网线、要连无线耳机手柄就选带 Wi-Fi 的版本，或之后加装 M.2 无线网卡（注意它可能占用一个 M.2 通道）。台式机有条件还是插网线最稳。

#### 主板后置视频口、核显与独显的关系（容易误解，重点）

主板背后那排 HDMI / DP **物理上只和 CPU 核显（iGPU）相连**，和独立显卡不直接连通：

1. 想用主板视频口出画面，**CPU 必须带核显**，且部分主板默认把核显设为「自动/关闭」，要在 BIOS 里打开核显多显示器（常见名 **iGPU Multi-Monitor / 集成显卡 = Enabled**）；
2. 可以做到「**独显负责渲染、核显负责输出到显示器**」（类似笔记本的混合输出），但画面要从独显拷到核显再输出，**会多一点开销和延迟**，还可能影响独显硬件编码、部分全屏和 G-Sync/FreeSync；追求游戏体验应当把显示器直连独显；
3. **F / KF 等无核显 CPU，主板视频口永远是黑屏，不可能借独显从主板口出画面**——没有核显就没有那条输出通路。独显真坏了、CPU 又没核显，就是点不亮，这也是前面建议留核显的原因；
4. 核显的正确打开方式是：备用亮机排查、视频 QuickSync 编码、OBS 分流编码。

### 前面板跳线的普遍接法

新手最怕的一把散线，其实有**普遍规律**（不同主板丝印位置略有差异，**普遍规律能解决绝大多数情况，最终仍以你主板丝印和手册为准**）：

- **Power SW（开机）、Reset SW（重启）**：本质是个开关，**不分正负极**，找到主板上标 `PW/PWR_SW`、`RESET/RSW` 的两根针插上即可，方向无所谓；
- **Power LED、HDD LED（电源灯、硬盘灯）**：是发光二极管，**分正负极**——通常彩色（绿/红）为正、白色或黑色为负，主板针座旁印有 `+/-` 或小三角标正极；**接反了只是灯不亮，不会烧**，对调即可；
- **USB 2.0 / USB 3.x / Type-C / HD AUDIO**：都是**一体式防呆插头**，对准缺口和缺针方向，垂直按下即可，**不能靠「长得差不多」硬插**，前置 Type-C 尤其别用蛮力；
- 找不到丝印就找主板上的小字（常印在针座旁或主板边缘），再对照手册的前面板接线图。

### BIOS：一定要知道它存在

**BIOS（UEFI）是主板固件，开机按 Del（部分主板 F2）进入**，是硬件和系统之间的第一层设置。新手不必全懂，但要知道这些项在哪、是干什么的：

| 设置项 | 作用 | 什么时候碰 |
| --- | --- | --- |
| XMP / EXPO | 内存一键跑到标称频率 | 装完机开一次，详见[内存](#xmp-与-expo) |
| Boot 启动顺序 | 选择从哪个盘/U盘启动 | 装系统、找不到启动盘时 |
| Fan 风扇曲线 | 调风扇转速策略 | 嫌吵或想加强散热 |
| 核显 / iGPU 开关 | 启用主板视频口、核显编码 | 要用核显输出/编码时 |
| Secure Boot / TPM | 安全启动、可信模块 | 安装 Windows 11 要求开启 |
| SVM / VT-x | CPU 虚拟化 | 用虚拟机、模拟器时开 |
| PCIe 版本（Gen） | 手动锁定链路代数 | 排查链路异常时 |
| Flashback / BIOS 更新 | 升级主板固件 | 支持新 CPU、修 bug |
| 恢复默认 / 清 CMOS | 一键回到出厂设置 | 改设置改挂了的救命招 |

!!! tip "新手只需要会三件事"
    开 XMP/EXPO、选对启动盘、改挂了会恢复默认（清 CMOS）。其余等你明确知道为什么要改时再动，详细排查见《[点亮与故障排查](点亮与故障排查.md)》。

!!! warning "主板可能造成的症状"
    - 某 M.2/SATA 口突然不能用、固态跑不满速 → 多为通道共享或插错槽，不是硬盘坏；
    - 超频/开 XMP 后无限重启 → 清 CMOS 恢复默认；
    - 高功耗 U 满载掉频、供电发烫 → 主板供电规模不够；
    - 主板视频口黑屏 → 先确认 CPU 有没有核显、BIOS 有没有开 iGPU。

## :material-memory: 内存

内存是程序运行时的临时工作台，断电即清空。影响体验的优先级是：**容量 ＞ 通道 ＞ 频率/时序**，按这个顺序看不会错。

### 容量

- 办公、轻度使用：**16GB** 起步；
- 游戏、多开、大量浏览器标签：**32GB** 是当前最舒服的甜点；
- 剪辑、虚拟机、本地跑 AI：**64GB 起**，按需再加。

### 单通道与双通道

两条内存并行工作就是**双通道**，理论带宽翻倍。它对游戏最低帧、对核显性能影响尤其明显（核显没有独立显存，要借用内存当显存）。所以**优先两条组双通道，而不是单条大容量**；具体插哪两个槽（常见 A2+B2）见《[装机流程指南 · 安装内存](装机流程指南.md#安装内存为什么不是有空槽就插)》。

### 代数与频率

- **DDR4 / DDR5 是「代数」，由 CPU 和主板平台决定，互不兼容**，缺口位置都不同，不能混插；
- 同代之内频率（MHz）越高理论越快，但边际收益递减，不必为几百 MHz 加很多钱；
- 新平台直接 DDR5，老平台没必要为换 DDR5 连主板 CPU 一起换。

#### AMD 与 Intel 的内存「甜点」并不一样

内存控制器对频率的耐受度两家不同，**不是频率越高就一定越好，关键是频率、时序、内存控制器频率处在同步甜点**：

- **AMD Zen 架构**对内存延迟敏感，存在明显甜点：Zen3（DDR4）多在 **3600MHz 上下**（对应 FCLK 1800 的 1:1 同步，再高容易切异步、延迟反而上升）；Zen4/Zen5（DDR5）多在 **6000MHz 上下**，再往上可能进入分频，收益变小甚至不稳；
- **Intel** 对高频更宽容（分 Gear1/Gear2 模式），DDR5 可以上更高，但游戏里的实际收益同样有限；
- 目标是「频率够高 + 时序够紧 + 控制器同步」的平衡低延迟，而不是盲目追最高数字。开了 XMP/EXPO 后用内存测试验证稳定性。

### 时序（CL）

时序是内存响应的「等待节拍」，最常看 **CL（CAS Latency）**。同频率下 CL 越小反应越快；跨频率要换算**实际延迟 ≈ CL × 2000 ÷ 频率（纳秒）**才公平。日常使用中同时序差距基本感知不到，不必盯着参数表焦虑，稳定优先。

### 颗粒

内存条的真正核心是上面的 **DRAM 颗粒**，体质决定超频上限。能自产颗粒的原厂主要三家：**三星（Samsung）、海力士（SK hynix）、美光（Micron）**；同一家还分不同档次的 die（例如海力士 A-die/M-die、经典的三星 B-die、美光 Rev 系列），超频潜力不同。

而金士顿、芝奇、英睿达、海盗船这些「内存条品牌」是采购颗粒、设计 PCB 和散热片的模组厂。**普通用户不需要专门挑颗粒**，开 XMP/EXPO 能稳定跑就是好条；只有玩手动超频才需要研究颗粒体质。

### XMP 与 EXPO

内存出厂默认只跑在一个保守的通用频率（JEDEC 标准），你买的「32GB 6000」要跑到 6000，需要在 BIOS 打开厂家预设：

- **XMP（Extreme Memory Profile）**：Intel 主导的一键预设，AMD 平台多数也能用；
- **EXPO（EXtended Profiles for Overclocking）**：AMD 随 AM5/DDR5 推出的预设，针对 AMD 平台把参数调得更全更对口；
- **两者本质相同**：都是厂家预先写好、存在内存 SPD 芯片里的「频率 + 时序 + 电压」一键配置，Intel 平台选 XMP、AMD（尤其 AM5）优先 EXPO。**不开，内存就只跑默认低频。**

!!! danger "开了 XMP/EXPO 黑屏重启怎么办"
    这说明这一档在你这套 CPU/主板上不稳，**不是内存坏了**：清 CMOS 恢复默认 → 降低一档频率或收紧前先放宽时序 → 再开，逐步找到稳定值。手动加压、强行收紧时序属于超频，有不稳定甚至长期风险，新手用厂家预设即可。详见《[点亮与故障排查](点亮与故障排查.md#无限重启--卡自检先清-cmos)》。

### 几条、混插与插法

- **优先两条大容量，而不是四条插满**：四条对内存控制器压力更大，高频时可能要降频才稳；
- 不同品牌/频率**可以混插**，但整机统一按「最低频率、最松时序」运行，想要最佳性能和稳定，尽量买同规格**套条（成套两连包）**；
- 单条优先 A2、双条优先 A2+B2，以主板手册为准。

!!! warning "内存可能造成的症状（最容易「背锅」也最容易被冤枉）"
    - 买 32GB 只认到 16GB、双通道没认到 → 先重插、换槽、用 CPU-Z 核对，别急着判坏；
    - 开机黑屏、Debug 灯停在 DRAM → 九成是没插到底或 XMP/EXPO 不稳，先清 CMOS、逐条测试；
    - 游戏偶发卡顿、最低帧不稳 → 可能正是单通道或容量不足，不一定是显卡或 CPU 的问题。

## :material-database: 硬盘

硬盘决定开机、开软件、读存档、导素材有多快。先分清种类，再看性能、缓存、寿命这几个层面。

### 种类与接口

| 类型 | 形态/总线 | 速度梯队 | 定位 |
| --- | --- | --- | --- |
| NVMe 固态 | M.2 形态、走 PCIe 通道 | 最快（数千 MB/s） | 系统盘、常用软件、常玩游戏 |
| SATA 固态 | 2.5 寸或 M.2(B-key)、走 SATA | 约 500MB/s | 老机升级、副盘，性价比高 |
| 机械硬盘 HDD | 3.5/2.5 寸、SATA | 最慢（百 MB/s 级） | 大容量冷数据/素材仓库 |

注意 **M.2 只是一种插槽「形态」，不代表速度**：M.2 槽里既可能走 NVMe（PCIe，快），也可能走 SATA（慢），买之前看主板支持哪种协议。

### 性能指标与缓存

- **顺序读写**：连续搬大文件（视频素材、压缩包）时的速度，对应「上传=写入硬盘、下载=从硬盘读取」；
- **4K 随机读写**：大量小文件的读写能力，**最影响开机、开软件、游戏加载这种日常流畅度**。很多顺序跑分很高的盘，日常体感却取决于 4K。

#### 缓存的作用

- **独立 DRAM 缓存**：盘上带一颗小内存，存放「逻辑地址→物理位置」的映射表，重负载、长期写入时更稳更快；
- **HMB（主机内存缓冲）**：无独立 DRAM 的盘借用一小点系统内存当映射表，日常游戏开机几乎无感；
- **SLC 缓存**：主控把一部分 TLC 颗粒临时当成更快的 SLC 模式来吸收突发写入，缓存写满后速度回落到颗粒真实水平，就是常说的**「缓外速度」**。超大文件持续拷贝才容易碰到，日常使用基本都在缓存内。

### 游戏加载与流送

高速固态主要影响：**进游戏/读图的加载时间、开放世界高速移动时的贴图流送（贴图突然糊一下再变清晰就是流送跟不上）、场景切换和存档**。已经是主流 NVMe 后，再从 PCIe 4.0 换到 5.0，游戏内帧数不会变（帧数归显卡 CPU 管），只是加载再快一点点。把游戏放机械盘上，则容易出现加载慢、贴图延迟、场景卡顿。

### 容量与盘位分工

**系统盘建议 1TB 起步**，512GB 在游戏体积越来越大的今天很快吃紧。一块 1TB NVMe 装系统 + 常用软件 + 常玩游戏；大容量固态或机械盘当素材、冷数据仓库。别把系统装机械盘上，那会让整台机器「看起来很慢」。做系统盘优先[主板的第一 M.2 槽](#m2-与-pcie-通道布局)。

### 寿命原理：写入和擦除才磨损

固态的 NAND 颗粒以「块」为单位**擦除（Erase）**、以「页」为单位**写入（Program）**，一次擦写循环叫一次 **P/E（Program/Erase）循环**，颗粒能承受的 P/E 次数决定寿命，厂家用 **TBW（总写入字节数）**给你一个质保写入量。主控还有磨损均衡，把写入平摊到所有颗粒。

!!! warning "误区澄清：扫盘、读盘到底伤不伤硬盘？"
    **单纯读取不磨损颗粒**——游戏反作弊扫描、系统索引、反复读档，这些「读」不会消耗 P/E 寿命。只有在**长时间大量读取导致硬盘持续高温、且散热又很差**时，热量才可能加速颗粒老化，正常使用几乎遇不到。真正消耗寿命的是**写入和擦除**。普通用户一天写入量有限，一块主流 TBW 的盘正常用五六年往往都用不完额度，不必为「某游戏扫盘伤硬盘」之类的说法焦虑。

!!! warning "硬盘可能造成的症状"
    - 固态速度远低于标称 → 查是不是插了芯片组/共享通道槽、是否只跑到 ×1/×2；
    - 插上 M.2 后某个 SATA 口消失 → 通道共享的正常现象，看手册换口；
    - 大文件拷到后半段明显掉速 → 是 SLC 缓存写满后的缓外速度，不是故障；
    - 卡 BOOT 灯、找不到启动盘 → 查启动顺序和系统盘连接，见《[点亮与故障排查](点亮与故障排查.md)》。

## :material-power-plug: 电源

电源是整机稳定和硬件安全的**底线**，最不该省。

### 功率与余量

把 CPU + 显卡满载功耗加上其余部件得到整机峰值，**再留 30%~40% 余量**选额定功率，让电源常年工作在高效、低温、低噪区间。比总瓦数更关键的是 **+12V 这一路的输出能力**——CPU 和显卡都吃它。

### 转换效率与认证

**80PLUS（白牌/铜牌/金牌/白金）**衡量的是「转换效率」，即多少电能真正用到硬件、多少变成热。它要结合正规品牌型号一起看，不能只看牌级：靠谱品牌的主流方案，远好于杂牌虚标的「金牌」。

### 模组与线材

- **非模组**：线全焊死、最便宜，多余的线扎好藏起来即可；
- **半模组**：主板/CPU 必备线焊死、其余可插拔；
- **全模组**：所有线可插拔，最好走线。性能三者没有区别。

!!! danger "绝对不要混用不同电源的模组线"
    哪怕接口外观一模一样，不同电源的**针脚定义可能不同，混用有烧毁硬件的风险**。只用本电源原配、或厂家明确标注兼容的线。

### ATX 3.x 与 12V-2x6

**ATX 3.0/3.1** 是新电源规范，专门应对新显卡的瞬时功耗尖峰，并带原生 **12V-2x6（前身 12VHPWR）显卡供电口**。用 RTX 40/50 系或更高端新卡，优先选带原生 12V-2x6 的 ATX 3.x 电源；老电源用显卡附赠的转接线也能行，但务必插到底、根部别死折。

### 保护机制与为什么不能省

正规电源带一整套保护：**OVP 过压、UVP 欠压、OCP 过流、OPP 过功率、SCP 短路、OTP 过温**，异常时自动断电保护硬件。电源内部是电解电容，有寿命、会老化，一旦失控可能连累其他部件，因此**最不建议买二手和杂牌**。预算紧张可以在显卡、外观上让一步，电源选正规品牌、功率留足，这钱是给整机买保险。

!!! warning "电源可能造成的症状"
    - 一上负载就重启、黑屏、闪退 → 典型功率/12V 余量不足或电源老化；
    - 新显卡高负载黑屏 → 查供电到底没、功率够不够、12V-2x6 根部有没有死折；
    - 随机不稳、硬盘掉线、USB 掉设备 → 也可能是供电质量问题，别只盯主板。

## :material-weather-windy: 散热

散热的任务是把热量及时带走，让 CPU/显卡不因过热降频。

### 解热能力匹配

看散热标称的**解热瓦数是否 ≥ CPU 满载功耗并留点余量**，而不是数热管、看外观。功耗越高的 U，解热规格往上提一档。

### 风冷

- **下压式**：矮、兼容小机箱，还能顺带给主板周边散热，解热上限较低，适合低功耗/ITX；
- **塔式**：同价位解热强、寿命长、无漏液顾虑，主流首选。要核对机箱**散热限高**、是否挡内存；风扇方向通常**从前面吸风、吹过塔体、由机箱后方排出**，别只图好看装反。

### 一体式水冷

一体式水冷（AIO）解热上限高、风道通透，要核对**冷排尺寸和安装位**。冷排装顶部还是前面有讲究：装顶部利于把热气直接排出；装前面进风先过冷排、散热效率高但会把加热后的风送进机箱。水泵多数集成在冷头，尽量别让冷排长时间整体低于水泵，避免积气产生噪音。**接线务必看说明书**——水泵不一定插 AIO_PUMP，存在反常识接法，见《[装机流程指南 · 散热](装机流程指南.md#安装-cpu-散热器)》。正规 AIO 漏液概率很低且多有漏液包赔，寿命主要看水泵；不想有任何顾虑，高端塔式风冷几乎免维护。

### 硅脂

硅脂用来填补 CPU 顶盖与散热底座之间的微观空隙，**均匀完整覆盖即可，不是越薄越好**，豌豆大小一点、靠散热器压力自然铺开，不用徒手刮成纸。几年后温度异常升高，可能是硅脂干了，重新涂一次即可。**硅脂只涂在 CPU 顶盖金属面，绝不能碰到触点、针脚、金手指和电路板。**

### 风扇参数与风道

- **吹冷排/鳍片（有阻力）优先看风压**，**机箱进出风（开阔通道）优先看风量**；噪音看转速上限、轴承和扇叶设计；
- 风道遵循**前面/下面进冷风、后面/上面排热风**，进风略多于出风形成**正压差**，灰尘也更少；
- 风扇有框一面一般是进风侧、有支架/标签一面是出风侧，装反了风道就反了。

!!! note "冷知识：为什么拆了机箱侧板，温度反而可能更高"
    封闭机箱靠「前进后出」形成定向风道，把热量稳定带走。拆掉玻璃侧板后风道被破坏：显卡/CPU 排出的热风在机箱内部紊流打转，甚至被前面进风又吸回去（热风循环），热气积聚在顶部排不出去，**结果比装好侧板还高几度**。想靠「开盖」降温，前提是环境空旷、有额外风扇直吹；桌面底下这种闷热环境里，完整风道往往更凉。

!!! warning "散热可能造成的症状"
    - CPU 温度高、撞温度墙降频 → 查硅脂、扣具有没有压紧、风扇是否接到 CPU_FAN、风道；
    - 主板报 CPU Fan 错误、卡自检 → 多是水冷/风扇插错口，按说明书接回；
    - 水泵异响/水温偏高 → 检查冷排位置是否积气、水泵供电是否正常。

## :material-desktop-classic: 机箱

机箱不影响性能，但它是所有尺寸的「总容器」，买错任何一项都要返工。

### 尺寸兼容清单

- [ ] 支持你的[板型](#板型尺寸)（ATX / M-ATX / ITX）；
- [ ] **显卡限长/限厚**装得下（三风扇厚卡、有水冷排挤时尤其注意）；
- [ ] **风冷限高、水冷冷排位**（240/280/360）对得上；
- [ ] 电源规格位（ATX/SFX）、硬盘位数量够；
- [ ] 前面板有没有你要的 Type-C / USB 数量。

### 面板与风道

**前面板网孔**进风足、散热好，缺点是易进灰、灯效看得少；**整块玻璃/封闭前面板**颜值高但进风受限，高功耗硬件容易「闷罐」。侧板是不是玻璃不影响散热，**影响散热的是前面板进风面积**。

### ITX 小机箱

小机箱里所有尺寸都更苛刻：**先定机箱，再按它的显卡限长、风冷限高、电源规格（常要 SFX）、冷排位反选其他部件**，并预留走线空间，装机顺序通常先把主板子模块装好再进箱。

## :material-vector-link: 搭配与平衡

这一层解决「从零配机，钱怎么分、件怎么配才不翻车」。

### 预算分配

记住这条推导链，顺序别搞反：

!!! success "选件推导链"
    **用途和分辨率定显卡档位 → 显卡配门当户对的 CPU → CPU 决定主板平台和内存代数 → CPU/显卡功耗决定散热和电源 → 全部尺寸最后决定机箱。**

### 瓶颈判断

- **分辨率越高越吃显卡**：4K 下旗舰和中端 CPU 差距很小，钱给显卡；**1080P 高刷反过来更吃 CPU**；
- **单通道内存**是隐形短板，会同时拖累游戏帧和核显；
- **系统盘不是 NVMe 固态**，整台机器都会显得迟钝；
- **电源和散热是地基**：不加分，但不够会让你直接翻车（降频、重启）。

### 能插上不等于该插

PCIe / M.2 通道有限且会共享：第二根长 PCIe 槽可能只有 ×4、某个 M.2 会占用 SATA 口。「能用」只代表物理能点亮，「跑满」才代表性能到位。装机前花十分钟看[主板通道说明](#m2-与-pcie-通道布局)，能避开绝大多数「能用却变慢」的坑，验证方法见《[装机流程指南](装机流程指南.md)》和《[点亮与故障排查](点亮与故障排查.md)》。

### 下单兼容性清单

- [ ] CPU 插槽 = 主板插槽，且主板 BIOS 已支持该 CPU（新 U 配老板可能要先刷 BIOS）
- [ ] 内存代数（DDR4/DDR5）与主板一致，频率在平台甜点范围内
- [ ] 主板供电规模压得住所选 CPU 的满载功耗
- [ ] 显卡长度/厚度装得进机箱，不与水冷排、硬盘位冲突
- [ ] 风冷限高/水冷冷排尺寸与机箱匹配，扣具支持 CPU 平台
- [ ] 电源对整机峰值留 30% 以上余量，+12V 能力足够
- [ ] 显卡供电接口齐全（8-pin 数量或 12V-2x6），只用原厂模组线
- [ ] M.2 / SATA 数量满足规划，已确认通道共享关系
- [ ] 机箱支持主板板型，风扇位与风道已规划
- [ ] 显示器接口/刷新率与显卡输出匹配（高刷要对应版本的 DP/HDMI 线）

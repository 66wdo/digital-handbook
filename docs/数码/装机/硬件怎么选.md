# 硬件怎么选

选硬件不是把「最贵的零件」堆在一起，而是 **从需求和预算出发，让每个部件互相匹配、没有短板也不花冤枉钱**。

每个硬件统一按四段理解：**作用与原理 → 关键指标 → 匹配/兼容关系 → 分档建议**。第一次看建议先读后面的《[硬件之间的关系](#硬件之间的关系替代一图流)》，它解释了这些部件为什么必须一起考虑。

!!! abstract "先定三件事，再挑零件"
    1. **用途**：纯办公 / 网游 / 3A 大作（什么分辨率、多少刷新率）/ 剪辑渲染 AI 等生产力；
    2. **预算**：定总盘子，再按用途分配到各部件；
    3. **平台倾向**：Intel 还是 AMD、是否需要以后升级——这会直接决定主板和内存代数。

## :material-chip: CPU（中央处理器）

**作用与原理**：通用计算核心，决定日常流畅度、生产力吞吐，以及游戏帧数的「下限」和最低帧稳定性。

**关键指标**：

- **核心 / 线程**：多核利于同时干多件事、渲染、编译、多开；游戏目前更看重单核性能与缓存。
- **频率与架构代际**：同代比频率，跨代先看架构，越新的 IPC（每时钟周期能做的事）通常越高。
- **缓存**：对游戏最低帧、部分网游影响明显。
- **功耗（TDP / PL1 / PL2）**：决定你要配多强的散热和供电，不是性能数字本身。

**匹配关系**：插槽和芯片组必须与主板对应（详见后文关系章节）；游戏里 CPU 要和显卡「门当户对」，避免一方严重拖后腿。

**分档思路**：

=== "办公 / 影音 / 轻量网游"
    中端即可，把预算优先让给固态、内存容量和一块舒服的显示器，不必堆核心数。

=== "主流游戏（2K 以内、高刷）"
    选中上、单核强的型号，保证高刷新率下最低帧稳定。

=== "3A 大作 / 高分辨率"
    分辨率越高越吃显卡，CPU 主流偏上即可，不必旗舰。

=== "剪辑 / 渲染 / AI / 多开"
    优先多核多线程、大缓存，并按软件是否吃显卡加速来平衡 GPU 预算。

## :material-expansion-card: GPU / 显卡

**作用与原理**：负责图形渲染，也承担视频编解码、渲染、AI 计算等并行任务。注意 **GPU 是显卡上的芯片，显卡是 GPU + 显存 + 供电 + 散热的整张卡**。

**关键指标**：

- **GPU 规格**：流处理器 / CUDA 核心规模、架构代际；
- **显存容量与位宽**：高分辨率、高材质、AI、多开更吃显存容量，位宽与显存颗粒决定显存带宽；
- **功耗（TGP/TDP）**：决定电源功率和显卡供电接口数量；
- **光追 / 编解码单元**：开光追、录屏直播、剪片导出时才需要重点比较。

**匹配关系**：显卡档位主要由 **游戏分辨率和刷新率** 决定；同时受 CPU 是否拖累、电源是否带得动、机箱是否装得下三重约束。

**分档思路**：

| 目标 | 关注点 |
| --- | --- |
| 1080P 高刷网游 | 中端显卡 + 单核强的 CPU，更吃 CPU |
| 2K 中高画质 3A | 中高端显卡，CPU 主流偏上 |
| 4K / 光追 / 高材质 | 高端显卡、大显存，CPU 反而不用最旗舰 |
| 生产力 / AI | 看显存容量、计算生态与编解码，而不只看游戏跑分 |

## :material-developer-board: 主板

**作用与原理**：连接所有部件的「地基与交通枢纽」，本身不直接决定跑分，但决定**能上什么 CPU/内存、有多少扩展、供电稳不稳**。

**关键指标**：

- **插槽与芯片组**：决定支持哪一代 CPU、能否超频、通道与扩展数量；
- **供电规模（VRM）**：供电相数、DrMOS、散热装甲，决定能不能长时间喂饱高端 CPU；
- **内存槽与 M.2 数量 / 通道**：几个内存槽、几条 M.2、是否 CPU 直连；
- **板型**：E-ATX / ATX / M-ATX / ITX，决定机箱兼容和扩展；
- **后置 I/O 与接口**：USB 数量、Type-C、视频接口、Wi-Fi / 蓝牙是否板载。

!!! question "「丐版主板能不能带高端 CPU？」"
    看两点：**插槽/BIOS 是否支持**，以及 **供电与散热是否压得住该 CPU 的持续功耗**。满足这两点，入门芯片组也能正常用高端 CPU；芯片组高低主要差在扩展和超频，而不是把同一颗 CPU 跑出不同性能。

## :material-memory: 内存（RAM）

- **代数（DDR4 / DDR5）**：由 CPU 和主板平台决定，**两代互不兼容、缺口位置不同，不能混插**。
- **频率 / 时序**：同代内更高频率、更紧时序有提升，但边际递减，开 XMP/EXPO 才能跑在标称频率。
- **容量**：办公 16GB 起步；游戏与多任务建议 32GB；剪辑、虚拟机、AI 本地部署按需上 64GB 起。
- **双通道**：两条组双通道对核显和游戏帧率影响明显，**优先两条，而不是单条大容量**（具体插哪个槽见《装机流程指南》）。

## :material-database: 硬盘（SSD / HDD）

- **协议与接口**：M.2 NVMe（走 PCIe，最快）＞ SATA 固态 ＞ 机械硬盘。**M.2 只是外形，能不能跑满速取决于协议和通道**。
- **主控与颗粒 / 缓外速度**：大文件持续拷贝时，缓外速度才是真实下限。
- **TBW（写入寿命）**：质保期内允许的总写入量，普通用户不必焦虑，重度写入再关注。
- **分工建议**：一块中等容量 NVMe 做系统盘 + 常用软件/游戏；大容量固态或机械盘做仓库盘。

## :material-power-plug: 电源（PSU）

!!! danger "电源是整机稳定性和硬件安全的底线，最不该省"
    劣质电源在高负载下电压不稳，可能拖累整机甚至损坏其他硬件；省什么都别省电源。

- **额定功率**：按「整机峰值功耗 + 30%~40% 余量」估算，让电源长期工作在高效率、低噪音、低发热区间。
- **+12V 输出能力**：CPU 和显卡主要吃 12V，这一路够不够比「总瓦数」更关键。
- **80PLUS**：是转换效率认证（白牌/铜牌/金牌…），反映用料与效率，但要结合正规品牌型号看，不是唯一标准。
- **模组化**：全模组/半模组方便走线；**模组线必须用该电源原配或官方明确兼容的线，不同电源针脚定义可能不同，混用有烧毁风险**。
- **接口**：确认显卡供电（8-pin 数量或 12V-2x6）、CPU 供电、SATA 数量都够。

## :material-weather-windy: 散热

- **解热能力要匹配 CPU 功耗**：看散热标称「解热功耗（TDP/瓦数）」是否覆盖 CPU 满载功耗，而不是看热管数量好看。
- **风冷**：下压式省空间、塔式效率高；要核对**机箱散热限高**和是否挡内存。
- **一体式水冷（AIO）**：解热强、机箱内风道更通透，但要核对**冷排尺寸/安装位**，并按厂家说明书接线（水泵不一定插 AIO_PUMP，详见流程篇真实案例）。
- **硅脂**：作用是填补 CPU 顶盖与散热底座之间的微观空隙，均匀覆盖即可，**不是越薄越好、更不用刮成纸**。

## :material-desktop-classic: 机箱

机箱是所有尺寸约束的「总容器」，选购时逐项核对：

- 支持的**主板板型**（ATX/M-ATX/ITX）；
- **显卡限长 / 厚度**（尤其三风扇厚卡、水冷排挤占空间时）；
- **风冷限高**、**水冷冷排位与尺寸**（240/280/360）；
- **电源规格位**（ATX/SFX）与硬盘位数量；
- **风道**：前进后出 / 下进上出，进风略大于出风维持正压差，减少积灰。

## 硬件之间的关系（替代一图流）

硬件从来不是孤立挑选的。下面这张关系讲清楚「**谁约束谁、谁和谁必须匹配、钱该按什么顺序分**」，比一张静态图更有用。

### 匹配关系总表

| 部件 | 必须和谁匹配 | 匹配什么 | 不匹配的后果 |
| --- | --- | --- | --- |
| CPU | 主板 | 插槽（LGA1700/1851、AM4/AM5）、芯片组、BIOS 版本、供电 | 装不上 / 点不亮 / 高负载掉频 |
| 内存 | CPU + 主板 | DDR 代数、频率上限、插槽数量 | 代数不同插不进；频率被压低 |
| 显卡 | 需求、电源、机箱 | 性能档位、供电接口与功率、长度厚度 | 瓶颈 / 供电不足 / 装不进机箱 |
| 硬盘 | 主板 | M.2 还是 SATA、走什么协议、通道是否共享 | 跑不满速，或占用后禁用某 SATA 口 |
| 散热 | CPU + 机箱 | 解热功耗、平台扣具、限高/冷排位 | 温度墙降频 / 盖不上侧板 |
| 电源 | 整机 | 总功率余量、12V 能力、各类供电接口 | 高负载重启、不稳，极端情况损硬件 |
| 机箱 | 以上全部 | 板型、显卡限长、散热限高、冷排位 | 任何一件装不进去都要返工 |

### 「谁决定谁」的因果链

1. **用途与分辨率 → 显卡档位**：玩游戏先确定分辨率/刷新率/画质，它基本决定显卡需要到什么档。
2. **显卡档位 + 用途 → CPU 档位**：按不拖显卡后腿、且满足生产力来定 CPU，高分辨率下 CPU 可适当降档省钱。
3. **CPU → 主板平台与内存代数**：选定 CPU 后，插槽/芯片组和 DDR4 还是 DDR5 就被定下来了。
4. **CPU 功耗 → 散热规格 + 主板供电 + 电源功率**：这三者都要按 CPU（和显卡）的实际功耗配。
5. **整机峰值功耗 → 电源**：所有耗电件之和留足余量，电源反过来要提供显卡所需的供电接口。
6. **显卡长度、散热高度、冷排、板型 → 机箱**：最后用机箱把所有尺寸「装下并理顺风道」。

!!! tip "一句话记住分配顺序"
    **需求定显卡，显卡配 CPU，CPU 定主板和内存，功耗定散热和电源，尺寸定机箱。**

### 瓶颈：钱别花在被拖后腿的地方

- **分辨率越高越吃显卡**：4K 下旗舰 CPU 和中端 CPU 差距很小，把钱给显卡；**1080P 高刷网游更吃 CPU 单核**，弱 CPU 会让高端显卡发挥不出来。
- **双通道内存**对核显画质和游戏最低帧影响明显，单条内存是常见的「隐形短板」。
- **硬盘别成为系统盘瓶颈**：系统和常用软件一定放 NVMe 固态，机械盘只当仓库。
- **电源和散热是「地基」**：它们不会让跑分更高，但不够会让整机不稳或降频。

### PCIe 通道：为什么「长得一样的槽」速度可能不同

PCIe 是显卡、M.2、扩展卡走的高速通道，常见通道数有 **x16 / x8 / x4**，通道越多带宽越大。关键认知：

- 通道由 **CPU 直连**或**芯片组转出**两条路径提供；离 CPU 最近的那根长插槽通常是 CPU 直连、满速 x16。
- **第二根「看起来一样、甚至带金属加固」的长插槽，可能只分到 x8 甚至 x4**，插主显卡会损失性能。
- 部分 M.2 与某些 SATA / PCIe 插槽**共享通道**，插上一个可能让另一个降速或被禁用——这些都写在主板手册的「M.2 / PCIe 通道说明」里。

!!! warning "「能插」≠「该插」，「能用」≠「跑满」"
    显卡插错槽照样能开机进系统，但带宽被砍、游戏掉帧，属于「电脑能用、性能却没发挥」。具体怎么用 GPU-Z 验证当前链路是不是满速，见《[装机流程指南](装机流程指南.md)》与《[点亮与故障排查](点亮与故障排查.md)》。

## 下单前兼容性检查清单

- [ ] CPU 插槽 = 主板插槽，且主板 BIOS 已支持该 CPU（新 U 配老板可能要先刷 BIOS）
- [ ] 内存代数（DDR4/DDR5）与主板一致，频率在平台支持范围内
- [ ] 主板供电规模压得住所选 CPU 的满载功耗
- [ ] 显卡长度 / 厚度装得进机箱，且不与水冷排、硬盘位冲突
- [ ] 风冷限高 / 水冷冷排尺寸与机箱匹配，扣具支持 CPU 平台
- [ ] 电源额定功率对整机峰值留 30% 以上余量，12V 能力足够
- [ ] 显卡供电接口齐全（8-pin 数量或 12V-2x6），优先原厂线
- [ ] M.2 / SATA 数量满足硬盘规划，已确认是否有通道共享
- [ ] 机箱支持主板板型，风扇位与风道已规划
- [ ] 显示器视频接口 / 刷新率与显卡输出匹配（高刷需要对应版本的 DP/HDMI 线）

## 一句话方法

> 先回答「我拿它干什么」，再回答「我有多少预算」，最后才看参数和机型。

## 第一步：列出你的真实使用场景

- [ ] 日常通讯 / 社交 / 刷视频
- [ ] 游戏（什么游戏、每天多久）
- [ ] 拍照录像（自拍 / 人像 / 远景 / 夜景 / Vlog）
- [ ] 续航与充电（是否长时间在外）
- [ ] 屏幕敏感（护眼、尺寸、直屏/曲屏）
- [ ] 其他：红外、NFC、双卡、扬声器、手感重量……

!!! tip "框架"
    场景排序后，**只为前 2~3 个核心需求付溢价**，其余参数「够用就行」。

## 第二步：不同预算，钱该花在哪

=== "入门档"
    - 待补充：这一档最该保证的 3 件事（如续航、流畅度底线、存储容量）
    - 可以妥协：影像、质感、无线充等

=== "中端档"
    - 待补充：性价比甜点在哪
    - 常见「加一点就越级」的临界点

=== "旗舰档"
    - 待补充：旗舰溢价买到的是什么，哪些人其实用不到

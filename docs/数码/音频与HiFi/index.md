# 音频与 HiFi

音频设备的挑选容易陷入参数玄学。本分类坚持：**搞清信号链路与功能差异，再谈风格与听感**。

## 信号链路先理清

```text
数字音源(手机/电脑/播放器)
   │  USB/光纤/同轴/蓝牙(编码)
   ▼
解码 DAC（数字 → 模拟）
   │
   ▼
耳放/功放（放大模拟信号，提供驱动力）
   │
   ▼
耳机 / 音箱（电信号 → 声音）
```

# 显示器与刷新率

显示器是你「真正一直盯着看」的东西，面板类型决定底子，参数决定体验，接口决定能不能跑满。这一页按**面板 → 刷新率/响应 → 色彩/HDR → 同步与接口 → 形态与支架**讲清楚。

## 面板原理与类型

先别急着记缩写，用大白话搞懂屏幕到底是怎么出画面的，后面这一堆型号一眼就能分清楚。

常见屏幕其实就两套成像路子：

- **液晶（LCD）自己不发光**。你可以把它想成：背后有一整面灯（**背光**）一直亮着，灯前面是密密麻麻的「小百叶窗」——每个像素就是一扇小窗，靠转动叶片决定**放多少光透过去**，再蒙上一层彩色滤光片，就有了明暗和颜色。**TN、IPS、VA 都是液晶，差别只在这些「百叶窗叶片」怎么转**；而 **Mini LED 改的是背后那盏灯**（把一整面大灯换成成百上千颗能分区开关的小灯），前面的百叶窗照样是液晶，所以它属于「背光方式」，别和 IPS/VA 并列着比。
- **OLED 既没有背光、也没有百叶窗**：每个像素自己就是一盏能独立亮灭的小灯，想黑就直接关灯，所以黑得纯粹、反应也快。

下面这张表把常见面板放一起，「大白话原理」那列对着上面的百叶窗看就好懂了：

| 面板 | 大白话原理 | 优点 | 短板 | 适合谁 |
| --- | --- | --- | --- | --- |
| **TN** | 百叶窗结构最简单、叶片行程最短，所以转得最快 | 响应极快、几乎不拖影、高刷便宜 | 颜色淡、侧看发白/变色、对比度低 | 只追求极限跟手的 FPS、预算有限上高刷 |
| **IPS** | 叶片在「平面内」转动，转到哪个角度都比较透光 | 颜色准、侧看也不易变色、画面通透 | 比 TN 慢一点、黑场易漏光、对比度一般 | 设计/影音/游戏都要兼顾的大多数人 |
| **Fast IPS** | 给 IPS 的叶片换了更快的「驱动」 | 保住 IPS 色彩，响应快很多、能上高刷 | 更贵，调校不好会过冲 | 又要颜色又要高刷的玩家 |
| **Nano IPS** | 在 IPS 里加纳米粒子把颜色做更艳 | 色域广、颜色鲜艳、高刷表现好 | 对比度一般、有人觉得过饱和、漏光 | 喜欢鲜艳画面 + 高刷 |
| **VA** | 叶片竖着排，关窗时合得最严实 | **对比度高、黑位深、漏光少**、常做曲面 | 叶片行程长、转得最慢，快画面易拖影 | 看电影/单机、暗场多、不追极限响应 |
| **OLED（WOLED/QD-OLED）** | 每个像素一盏小灯、自己发光 | 响应近乎 0、对比度近乎无限、色彩好、超薄 | 长期定格高亮有烧屏风险、持续高亮有限、贵 | 追求画质与拖影控制的玩家/影音 |
| **Mini LED（背光）** | 还是液晶百叶窗，只是背后换成大量分区小灯 | 分区控光、HDR 和峰值亮度强 | 灯区边缘有光晕（blooming），响应仍是液晶底子 | 想要强 HDR 又顾虑 OLED 烧屏的人 |

一句话挑面板：<span class="hl-key">要色彩和全能选 IPS，要黑位和沉浸选 VA，要极限竞技选 TN，要画质天花板选 OLED，想要 HDR 亮度又怕烧屏就看 Mini LED</span>。

### 为什么 TN 和 OLED 都「几乎不拖影」，却是两回事

「拖影」说白了就是像素从上一个颜色变到下一个颜色太慢，运动物体拖着一条尾巴。同样是几乎不拖影，两者路子完全不同，看懂了你就明白为什么不能只盯「1ms」这个参数：

- **TN 属于「叶片本来就转得快」**：液晶偏转最简单、行程最短，灰阶之间切换天生最快，几乎不用靠 Overdrive 硬催，连过冲鬼影都很少。部分高端电竞 TN 还用**背光高频闪烁（插黑 / 黑帧，各厂有不同商品名）**进一步压掉视觉残留，连发压枪时画面显得更「定」。代价还是 TN 老问题：颜色淡、侧看发白。
- **OLED 属于「压根不用转叶片」**：像素是小灯，通电即亮、断电即灭，切换能到 0.1ms 级，自然没什么拖影，颜色和对比度还远胜 TN；代价是静态高亮元素长期停留有烧屏/老化风险。
- **IPS/VA 是叶片天生慢半拍**，厂商就用 **Overdrive（加压提速）**去追，催过头会在物体边缘甩出亮边/反色，这就是**过冲（鬼影、逆残影）**。所以<span class="hl-key">标称「1ms」不等于真 1ms，得看灰阶响应（GTG）实测和过冲控制</span>。

## 刷新率与响应时间

- **刷新率（Hz）= 每秒显示多少帧画面**，要和显卡输出帧率（FPS）匹配才有用：屏幕 144Hz 但游戏只跑 60 帧，也只能显示 60 帧；
- **响应时间（GTG，灰阶到灰阶）= 单个像素变色所需时间**，决定移动画面有没有拖影，它和刷新率是两件事；
- **MPRT 不是 GTG**：MPRT（运动画面响应时间）常通过背光闪烁让「看起来更清晰」，数值可以做到 1ms，但它不代表像素真变色这么快，且会降低亮度；
- **60→144→240→360Hz 体感边际递减**：60 到 144 是「一眼能看出」的跨越，再往上只有高强度竞技、且帧率稳定跟得上时才值；
- **高刷要配高帧率**：竞技玩家优先保证「游戏稳定帧率 ≥ 屏幕刷新率」，再谈更高 Hz。

## 分辨率、尺寸与 PPI

- **PPI（像素密度）= 分辨率 ÷ 尺寸**，决定颗粒感：同样 1080P，24 寸比 27 寸更细腻；27 寸建议至少 2K；
- 常见甜点：24~25 寸 1080P 高刷（FPS 易看清目标、对显卡压力小）、27 寸 2K（清晰度与性能平衡）、32 寸 4K（细腻但吃显卡）；
- **「分辨率 × 刷新率」越高越吃显卡**：4K 高刷对显卡的要求远高于 1080P，搭配档位见电脑篇[显卡部分](../电脑/装机/硬件.md)。

## 色彩与亮度

- **色域（能显示多少颜色范围）**
    - **sRGB**：网络/Windows/游戏的通用基准，日常和游戏以「能准确覆盖并正确映射 sRGB」最重要；
    - **DCI-P3**：影视、HDR 内容的广色域，数值越大颜色越广；
    - **Adobe RGB**：摄影/印刷设计用，覆盖更多青绿；
    - <span class="hl-key">广色域屏如果不做 sRGB 映射，日常看网页会「过饱和、颜色假」</span>，是否有准确的 sRGB 模式比单纯色域数值更重要；
- **色深/位深**：8bit（1670 万色）够用；10bit（10 亿色）过渡更平滑、HDR 必需；**FRC** 是用 8bit 靠抖动「模拟」10bit；
- **色准 ΔE**：数值越低越准，ΔE<2~3 人眼基本难辨色差，设计修图看这项；
- **HDR 与峰值亮度（nit）**：真 HDR 靠「高亮度 + 分区控光 + 广色域」共同实现。HDR400 只是入门（峰值 400nit、基本无分区，提升有限），HDR600/1000 及以上、分区越多、峰值越高，明暗对比才真正出来；**只贴个 HDR400 标的「伪 HDR」观感提升很小**。OLED 不靠峰值亮度而靠像素级控黑取胜。

## 同步技术与接口

### G-Sync / FreeSync / Adaptive-Sync

- 它们都是**可变刷新率（VRR）**：让屏幕刷新率跟着显卡实时帧率走，消除「帧率≠刷新率」造成的**画面撕裂**，并比传统垂直同步（V-Sync，锁帧、增延迟）更流畅；
- **FreeSync / Adaptive-Sync** 是开放标准（AMD 主导、多数显卡通用），**G-Sync** 是 NVIDIA 方案（有原生硬件版和兼容版）；现在 N 卡也能在多数 FreeSync 屏上开启兼容 G-Sync；
- 开启后一般在驱动里配合「垂直同步开 + 帧率上限略低于刷新率」获得低延迟无撕裂体验；**LFC（低帧率补偿）**保证帧率低于刷新率下限仍能同步。

### 接口带宽：HDMI 与 DP（高刷跑不跑得满全看它）

<span class="hl-key">同样一台高刷显示器，用错接口或线材就会被锁在低分辨率/低刷新率/8bit。</span>

| 接口 | 典型带宽 | 大致能力（参考，受色深/DSC 影响） |
| --- | --- | --- |
| HDMI 2.0 | 18Gbps | 4K@60、2K@144、1080P@240 |
| HDMI 2.1 | 48Gbps | 4K@120/144、甚至 8K；主机游戏首选 |
| DP 1.4 | 32.4Gbps | 2K 高刷无压力，4K 高刷常需开 DSC 压缩 |
| DP 2.1（UHBR） | 最高 80Gbps | 4K/8K 高刷、无损 10bit 余量充足 |

- **DSC（显示流压缩）**：带宽不够时用「视觉无损压缩」硬上高规格，DP 1.4 跑 4K 高刷基本靠它；
- **Type-C 一线通**：支持 DP Alt Mode 的 Type-C 口能用一根线同时传画面 + USB 数据 + 反向给笔记本供电（PD），要看清它支持的 DP 版本和供电瓦数；
- 线材也要匹配：标称 HDMI 2.1 / DP 高带宽的线才能跑满，老线会悄悄降规格；遇到「上不了高刷」先查接口版本、线材和驱动里是否选对了刷新率/色深。

## 曲面、带鱼屏与使用形态

- **曲面（曲率如 1000R/1500R/1800R，数字越小越弯）**：包裹感强、边缘到眼睛距离更一致，适合单机/影音/宽屏；竞技 FPS 和专业设计对几何形变敏感，慎选大曲率；
- **带鱼屏 21:9 / 超宽 32:9**：横向多出工作区，多窗口、剪辑时间线、赛车/开放世界游戏沉浸感强；**不适合**：需要严格几何准确的设计、追求极限帧数的竞技 FPS（同分辨率更吃显卡、部分游戏不支持超宽比例）；
- **比例/尺寸与视距**：屏幕宽度以不用频繁转头扫边角为宜，过大过近反而累。

## 显示器支架与机械臂

- **为什么上机械臂**：释放桌面空间、把屏幕抬到视线平齐、自由调高低/俯仰/横竖屏；
- **承重与 VESA 孔距**：先看背面 VESA 孔（常见 75×75 / 100×100mm）和整机重量，必须落在机械臂承重区间；
- **安装方式**：桌沿夹装（免打孔、看桌板厚度与边缘）vs 穿孔固定（更稳、需桌孔）；
- **臂型与弹力**：气压/弹簧悬臂原理；大屏、超宽带鱼屏、偏重的 OLED 要选重型臂，普通轻屏用标准臂；
- **重心与下垂**：屏幕厚度、重心、安装点决定会不会慢慢「点头」下沉；
- 单臂/双臂/搭配笔记本托盘的组合，以及臂内走线；搭配人体工学椅、键鼠高度一起规划坐姿。

## 避坑清单

!!! warning "买前先避开这些坑"
    - 只看「1ms」标称，不看是 GTG 还是 MPRT、不看过冲鬼影；
    - 高刷屏却用了老接口/老线，分辨率刷新率色深跑不满；
    - 只看广色域百分比，不看有没有准确的 sRGB 模式，结果日常过饱和；
    - 把 HDR400 当成「真 HDR」，实际暗场和亮度提升有限；
    - 只看面板标签（如「IPS」）不看具体调校——同是 Fast IPS，Overdrive 和色准调校差距很大；
    - 忽视烧屏风险长期把 OLED 当纯办公/任务栏常亮屏使用。

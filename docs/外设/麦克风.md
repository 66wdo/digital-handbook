# 麦克风

麦克风要解决的不是「参数好不好看」，而是**让对方清晰听到你、同时尽量少收进环境噪声**。这一页按「换能原理 → 拾音指向 → 连接链路 → 桌面摆位 → 按用途选」讲清楚，只讲技术、不点名推荐品牌。

## 电容麦与动圈麦

两种最常见的麦，差别在「声音怎么变成电信号」：

| 类型 | 原理 | 供电 | 灵敏度 / 细节 | 抗环境噪声 | 适合 |
| --- | --- | --- | --- | --- | --- |
| **电容麦** | 极薄振膜与背板构成电容，声压改变间距产生信号 | 需要 **48V 幻象供电**（声卡经 XLR 线供电，电源和信号走同一条线，故名「幻象」） | 高，细节、气音、高频泛音丰富，频响宽 | 弱，房间混响、空调、键盘、窗外声一起收 | 安静房间的录音、配音、人声 / 乐器 |
| **动圈麦** | 振膜带动线圈在磁场中运动，电磁感应出信号 | 无需供电，皮实耐造 | 较低，需要更近、更大声或更多增益 | 强，对远处环境声和房间反射不敏感 | 嘈杂房间、开黑、直播、舞台、手持 |

!!! tip "桌面 / 房间环境，多数人更该用动圈"
    电容麦灵敏是把双刃剑：专业吸音棚里它给你细节，普通卧室里它把<span class="hl-key">风扇、键盘、机箱、房间混响、隔壁说话一并收进去</span>，后期很难干净地去掉。没有做声学处理、又在电脑前用，动圈麦「只收嘴边、忽略环境」的特性反而出活更稳。别因为「电容更高级」就默认选电容。

补充：还有一类**驻极体 / 硅麦（MEMS）**，常见于耳机线控、TWS、会议麦和很多 USB 麦内部，体积小、成本低；**铝带麦（Ribbon）**是另一种细节柔和、但娇贵怕风、对话放要求高的类型，桌面很少用。

## 拾音指向模式（决定收声范围）

指向性描述麦对**不同方向声音**的敏感程度，按场景选：

- **全指向（Omnidirectional）**：360° 均匀收声，自然、无近讲效应，但环境声照单全收，适合圆桌、环境录音、ASMR 全空间；
- **心形 / 心型指向（Cardioid）**：正面最灵敏、背面明显抑制，<span class="hl-key">单人正对麦克风的开黑、直播、配音首选</span>，能挡掉身后的机箱和房间反射；
- **超心形 / 枪式（Super / Hypercardioid）**：正面拾音更窄、更「聚」，抗侧面噪声更强，但正后方会留一个小拾音区，要对准嘴、注意别让显示器正后方的噪声漏进来；
- **双向 / 8 字（Figure-8）**：正反两面收、两侧抑制，适合面对面双人访谈、特定立体声 / 合唱；
- **立体声 / 多振膜**：用两个或多个振膜记录空间方向感，适合乐器、环境、ASMR，语音通话用不上。

!!! note "心形不是「万能盾」"
    指向性主要抑制**轴外（侧面 / 背面）**的声音，对正前方的噪声（比如你和键盘都在麦的正面）无能为力。键盘声、敲桌声更多靠**摆位、防震架、噪声门**解决，而不是指望指向性。

## 连接方式：USB 还是 XLR

- **USB 麦**：把「麦 + 声卡（模数转换 + 话放）」做在一起，一根 USB 线即插即用，不占额外设备，入门和桌面最省事；
- **XLR 麦 + 独立声卡 / 调音台 / 话放**：麦只负责换能，模拟信号经卡农线进声卡，再由声卡放大、转数字。上限高、可单独升级每一环、可接多路，但要会调增益、要占桌面和预算；
- 两者没有绝对高下：<span class="hl-key">决定音质的首先是麦本身、房间和摆位，而不是接口</span>。同价位下「优质 USB 麦」通常比「便宜 XLR 麦 + 凑合声卡」更省心、出活更好；只有在你确实要多路输入、要接专业设备、要持续升级时，XLR 链路才体现价值。

**几个链路概念**：

- **增益（Gain）**：把麦的微弱信号放大到可用电平。动圈麦往往需要更大增益；增益开太大，底噪（嘶嘶声）跟着起来——<span class="hl-key">底噪大先怪增益和话放，别一味怪麦</span>；
- **采样率 / 位深**：语音 48kHz / 16bit 或 24bit 绰绰有余，盲目追 192kHz 没有可闻收益，只增加文件体积和负载；
- **监听延迟**：录音时若听到自己的声音有回声 / 延迟，是软件监听走了系统混音（DirectSound/WASPD 共享）的缓冲。专业声卡用 **ASIO**（或苹果的 CoreAudio）低延迟驱动、或直接开麦 / 声卡的**零延迟硬件监听**；
- **幻象供电只给需要的设备开**：电容麦、有源 DI 盒开 48V；动圈麦、铝带麦一般不要乱开（多数动圈无碍，但养成「不确定就先关」的习惯），热插拔时也建议先关 48V 再拔线。

## 桌面使用要点（比换设备更影响效果）

- **离嘴距离**：心形动圈 / 电容近讲一般 **10~20cm**，太近喷麦和呼吸声重、触发近讲效应（低频轰），太远环境声比例上升、声音发空；
- **防喷罩 / 防喷棉**：挡住「b、p」等爆破音的气流冲击，比后期硬救有效；
- **防震架（Shock Mount）与悬臂**：隔开桌面震动、敲键、碰桌的固体传声；悬臂把麦悬到嘴边、离开桌面，比直接立在桌上干净得多；
- **让麦背对噪声源**：心形麦的「背面」对准机箱、风扇、窗户、键盘主轴方向；
- **噪声门（Noise Gate）与降噪**：设一个阈值，不说话时自动静音切掉底噪和风扇声，是开黑 / 直播最立竿见影的一步；但阈值别太狠，否则说话开头被吃掉；
- **先声学、再设备**：房间混响（硬墙、瓷砖、空房间的回声）是电容麦最大的敌人，挂点窗帘、地毯、衣柜，关窗关风扇，收益常大于加钱换麦。

## 按用途选

| 用途 | 推荐方向 | 关键点 |
| --- | --- | --- |
| **游戏开黑 / 语音** | 心形动圈 USB 麦（或带麦耳机） | 清晰、抗键盘环境声、噪声门，省心第一 |
| **直播 / 主播** | 心形 / 超心形动圈为主，安静棚可电容 | 悬臂 + 防震 + 实时监听 + 噪声门，链路稳定 |
| **配音 / 有声书 / 人声录音** | 大振膜电容（需安静、做声学）或优质动圈 | XLR 声卡、24bit、防喷、监听，环境是前提 |
| **乐器 / 合唱 / 环境** | 电容、立体声 / 全指向 / 8 字 | 按乐器和空间选指向，可能多路 |
| **视频会议 / 网课** | 心形 USB 麦或耳麦 | 离嘴近、回声消除，稳定兼容即可 |
| **圆桌 / 多人 / 移动** | 全指向、领夹麦、无线小蜜蜂 | 覆盖多人、佩戴隐蔽、续航和对码 |

!!! warning "几个常见误区"
    - **「电容一定比动圈好听」**：在没声学处理的卧室，往往相反；
    - **增益拉满追求音量大**：正确做法是说话时电平到合适区间（峰值不爆），靠软件 / 系统再统一响度，而不是硬堆增益；
    - **忽略爆音（Clipping）**：录音电平顶到 0dB 削波是不可逆的破音，宁可录小一点后期拉，也别录爆；
    - **迷信高价线 / 玄学配件**：数字 USB 线只要合格、稳定传输就不影响音质；模拟 XLR 线重点是平衡抗干扰和结实，而非「发烧」。

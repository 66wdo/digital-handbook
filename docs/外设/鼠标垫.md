# 鼠标垫

鼠标垫不是「随便一块布」，它和脚贴、传感器共同决定鼠标移动时的**启动阻力、滑动顺滑度、停得稳不稳（控制感）和定位一致性**。这一页只讲市面流通的**类型与特性**，不点名品牌——看懂类型，就能把任何一块垫对号入座。

## 先理解两个维度：速度型 vs 控制型

- **速度型（Speed/滑垫）**：表面顺滑、X/Y 方向阻力小，鼠标一推就走、甩动省力，适合需要大幅快速转身、偏好「滑」手感的人；缺点是微调、急停时更考验控制力；
- **控制型（Control/涩垫）**：表面阻尼略大、摩擦力更「咬」，鼠标停得住、微调跟手，FPS 点射、压枪、精细瞄准更稳，代价是大幅甩动更费一点力；
- 没有绝对好坏，<span class="hl-key">「滑不滑」是垫面编织/材质和脚贴共同决定的</span>：同一块垫，换特氟龙脚贴更滑、换玻璃脚贴滑度再上一档。

## 材质大类（市面主流）

### 布垫（织物垫，绝对主流）

绝大多数人用的就是布垫，价格带宽、可卷、静音、不磨脚贴。布垫的手感由下面几个工艺点决定，这也是不同布垫差距的来源：

- **编织方式：平纹 vs 乱纹（乱织）**
    - *平纹/细织*：经纬规整、表面细腻，滑动均匀、噪声小，偏均衡或偏速度；
    - *乱纹/乱织*：纱线走向不规则，表面有细微颗粒感，阻尼更足、控制感和「咬手感」更强，多为控制型；
- **编织密度**：织得越密越平整顺滑，越疏越偏涩、越容易卡灰；
- **软底 / 硬底**：软底（橡胶+布面）能贴合桌面、压手腕舒适、可卷曲，是主流；硬底布垫在布面下加硬质夹层，表面更平整一致、启动更快，但不可卷、偏硬；
- **厚度（薄底/厚底）**：常见 3mm、4mm、5mm 甚至更厚。**厚底**更软、更填平桌面瑕疵、手腕压着舒服，但边缘和表面形变大、极端急停时会有轻微「陷」；**薄底**更硬挺、反馈直接、移动一致性好，但对桌面平整度要求高、硌手腕；
- **封边（锁边）**：边缘用线缝合锁边，防止布面长期使用后起边、脱线、翘角；不封边的更柔软但边缘更容易磨毛。**封边是否平整、会不会硌小臂**是做工重点；
- **底胶防滑**：底部天然橡胶/发泡橡胶的纹路和软硬度决定「鼠标在动、垫子不动」，好的底胶在桌面上推不滑、铺平后不卷边。

### 硬质 / 半硬质垫

- **树脂垫（复合/涂层硬垫）**：表面非常滑、启动快、易擦拭清洁，声音比布垫大、更磨脚贴，涂层会随使用逐渐磨损；
- **玻璃垫**：极致顺滑、一致性高、耐磨、凉感明显，配特氟龙或专用脚贴，声音偏大、对桌面平整度和防滑要求高，冬天偏凉；
- **金属垫（铝等）**：硬、滑、凉，类似玻璃垫，现已较少见；
- **硫化垫/特殊工艺垫**：介于布与硬垫之间，表面经过特殊处理，追求布垫的静音和硬垫的顺滑兼顾。

!!! note "脚贴磨损要单独记"
    越硬越滑的垫越磨脚贴，程度大致是 <span class="hl-key">玻璃 ＞ 金属 ≈ 树脂 ＞ 布垫</span>：硬垫上脚贴属于消耗品，要定期检查更换；布垫最省脚贴、也最安静。玻璃垫里也有「微蚀刻控制型」，靠表面细微纹路在丝滑和刹得住之间找平衡，急停比传统光面玻璃更好。

!!! tip "硬垫的共性"
    越硬越滑的垫，越磨脚贴、滑动和点击声音越大、对手腕缓冲越差；布垫则更安静、温润、好打理。选哪种，本质是在「极致顺滑」和「控制+舒适」之间取舍。

## 尺寸与灵敏度搭配

- **小号/中号**：办公、小幅度移动、桌面紧张时够用；
- **大号（铺键盘区）/整张桌垫（XXL）**：低灵敏度 FPS 需要大幅甩枪，垫面必须留足移动余量，桌垫还能让键盘同面、手腕统一高度、更美观；
- 经验：**有效灵敏度越低、手臂流甩动越大，越要上大垫**，避免甩到一半冲出垫面导致追踪丢失。

## 表面一致性与做工（比参数更影响体验）

- **X/Y 方向一致性**：横向、纵向滑动阻力应尽量一致，否则斜向移动会有「被带偏」的感觉；
- **平整度**：铺开来能否快速贴平、有无鼓包波浪，卷折运输后能否恢复；
- **封边与边缘高度差**：锁边凸起过高会在鼠标压线时「绊」一下；
- **底胶防滑**：见上，快速甩动时垫子必须纹丝不动；
- **异味与环保**：新橡胶垫轻微气味正常，刺鼻不散的慎选。

## 寿命、清洁与搭配

- **老化表现**：布面起毛、汗渍油污让局部滑度不一致、涂层磨损出现「补丁感」、底胶失去防滑、封边脱线——出现这些就该换；
- **清洁**：布垫可用中性洗剂温水轻柔手洗、阴干（别暴晒/烘干），汗手建议定期清洁，因为汗渍会明显改变局部阻尼；
- **与脚贴/传感器搭配**：
    - 传感器对垫面有适配，极个别在某类纯黑反光/特殊纹理垫上会丢帧，主流旗舰传感器兼容性都很好；
    - 布垫配特氟龙脚贴最通用；玻璃/树脂硬垫建议配对应脚贴并接受更快磨损；
    - 换垫等于换手感：滑度一变，原来的肌肉记忆和 eDPI 体感要重新适应。

!!! success "一句话对号入座：你该盯哪几个参数"
    - **低敏大幅 FPS（控枪）**：大号控制型布垫，停得住、表面一致性好。
    - **高敏微调 / 追求顺滑**：速度型布垫或硬质 / 半硬垫，记住硬垫更费脚贴。
    - **办公 / 桌面整洁**：中号布垫，易清洁、底胶防滑。
    - **所有人**：尺寸要配灵敏度和桌面空间，表面一致性、包边与底胶做工比品牌和噱头参数更影响手感。

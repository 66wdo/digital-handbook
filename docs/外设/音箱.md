# 音箱（桌面 / 多媒体）

这一篇只聚焦**桌面近场**：人坐在电脑前、离音箱几十厘米到一米多的场景。更通用的声学原理、解码 / 耳放、耳机评价、房间声学，都放在「音频与 HiFi」分区，这里不重复堆理论，只讲桌面怎么选、怎么接、怎么摆。

## 有源与无源：桌面默认有源

- **有源音箱（Active）**：功放做在箱体里，插电、给它线路信号就能响，桌面和近场监听的绝对主流。每只单元还可由独立功放通道**主动分频**驱动，调校由厂方在箱内完成；
- **无源音箱（Passive）**：箱内只有单元和分频器，要另配功放 / 合并机，用音箱线连接。声音上限和可玩性高，但占空间、要额外预算和搭配，桌面近场较少用；
- **监听取向 vs 多媒体取向**：近场监听追求平直、少音染、告诉你「录音本来是什么样」；多媒体 / 游戏音箱常对低频和氛围做讨好式增强。没有对错，<span class="hl-key">要准确混音选监听，要爽、要氛围可选调音偏暖偏多低频的</span>，但别把「低音轰」当「音质好」。

## 单元与结构

- **分频**：把声音按频率分给不同单元——小的**高音单元（球顶 / 带式等）**负责高频，大的**中低音 / 低音单元（锥盆）**负责中低频，箱内或功放里的**分频器**决定各管一段，避免一个单元硬扛全频；
- **2.0（立体声对箱）**：左右两只，是近场听音乐 / 混音的正道，声场和定位最正常；
- **2.1（两只小箱 + 低音炮）**：把低频交给独立低音炮，小箱子桌面好摆、量感足，适合影音游戏；代价是低频和主箱的**分频衔接、炮的摆位**调不好会浑浊、脱节；
- **书架箱 / 桌面箱 / 声棒（Soundbar）**：近场用近场监听尺寸（单元常见 3~5 英寸级别）即可，过大的箱体和单元在一米内反而开不开、低频轰头；声棒省空间、适合影视，但立体声分离和近场定位通常不如正经对箱；
- **低频量感与单元尺寸、箱体容积正相关**：想要真实下潜，物理尺寸骗不了人，巴掌大的箱子靠电路「轰」出的低频和真实下潜是两回事。

## 连接方式

| 连接 | 传的是什么 | 特点 |
| --- | --- | --- |
| **3.5mm / RCA（模拟）** | 已经解码好的模拟信号 | 最通用，用电脑 / 主板集成声卡输出；线材和接口屏蔽差时易有底噪、电流声 |
| **平衡 TRS / XLR（模拟）** | 抗干扰更强的平衡模拟信号 | 近场监听常见，线长、设备多时底噪更低 |
| **光纤（S/PDIF）** | 数字信号，进箱内解码 | 抗电气干扰、不传递接地噪声，不支持超高清多声道 |
| **USB** | 数字信号，箱内自带 DAC 解码 | 绕开主板集成声卡，常见于桌面多媒体箱，省事 |
| **蓝牙** | 编码压缩后的数字信号 | 方便、无线，音质和延迟看编码（见音频分区），近场认真听优先有线 |

!!! tip "桌面底噪 / 电流声先查接地和链路"
    音箱里传出「滋滋」「嗡嗡」声，多数不是音箱坏了：常见是<span class="hl-key">模拟线质量 / 走线差、和电源线捆一起、前后级接地不一致（地环路）、主板 3.5mm 口屏蔽差</span>。优先换数字连接（USB / 光纤 / 平衡）、把模拟线远离电源线、给设备接同一供电回路，往往能解决，别急着加「滤波玄学配件」。

## 近场摆位（桌面提升最大、且免费的一步）

近场监听的核心是让两只音箱和你的头构成一个**等边三角形**：

- 左右箱间距 ≈ 每只箱到你头部的距离，两箱向内**内凹（toe-in）**对准头部，高音单元轴线大致指向耳朵；
- **高音单元和耳朵大致同高**：箱体太小放桌面会偏低，用音箱架 / 海绵垫 / 支架垫起来，别让高音被桌面挡住；
- **离后墙、侧墙留距离**：低音是无指向的，箱体紧贴墙会让低频被边界叠加、发轰，留出十几厘米以上、左右对称更好；
- **桌面反射**：音箱直接放硬桌面，中低频会被桌面反射造成梳状滤波、声音发浑；近场监听海绵垫 /  Iso 类减震垫能减少箱体和桌面的耦合；
- **2.1 的低音炮**：低频方向性弱，炮的位置相对自由，但要靠实测（在听音位放测试音、移动炮找最干净的点），并把分频点和主箱衔接好，不是塞桌底就行。

!!! note "为什么近场监听「不太吃房间」"
    离箱越近，**直达声**相对房间反射声的比例越高，听到的主要是音箱直接传来的声音而非房间染色，所以近场监听能在普通房间里得到相对可靠的平衡；但<span class="hl-key">低频和桌面反射照样受空间影响</span>，摆位依然重要。房间声学的系统处理见《[音源、数字音频与房间声学](../音频与HiFi/音源数字音频与房间声学.md)》。

## 怎么选：按桌面和用途

- **桌面小、距离 60cm 内、以语音 / 游戏 / 影视为主**：小尺寸有源 2.0 或靠谱 2.1，数字输入（USB / 光纤）优先，省空间、少底噪；
- **桌面够大、认真听音乐 / 做剪辑混音**：一对 3~5 英寸级近场监听，平衡或数字输入，配音箱架摆成等边三角形，平直可靠；
- **想要氛围和低频、看片打游戏多**：可接受调音偏暖的多媒体箱或 2.1，但接受低频可能不够准确；
- **预算分配的朴素顺序**：<span class="hl-key">先把箱子本身和摆位做好，再谈解码、线材</span>。在糟糕摆位和桌面反射下，换更贵的前端收益极小。

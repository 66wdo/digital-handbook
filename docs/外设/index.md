# 外设

外设直接决定每天的**手感、观感与效率**，而且用途不同、最优解完全不同：办公、电竞、FPS、音游、编程各有侧重。选外设的主线不是堆参数，而是**先定用途和使用环境，再谈参数**。

!!! tip "怎么用这个分区"
    按「操控输入 → 画面与桌面 → 声音」三组往下看；每篇先讲原理再给判断框架。耳机的声学评价和「音频与 HiFi」分区互通，两边用按钮互相跳转。

# 键盘：机械轴与磁轴

键盘的手感和响应，核心在「**用什么方式触发**」和「**整套结构怎么调校**」。这一页先把轴体原理讲透，再讲磁轴的高级功能、客制化组装、连接方式与常见误区。

## 先搞懂原理：四大类触发方式

轴体名字五花八门（厂家随时能给一颗轴起个新名字），但按**触发原理**只分四大类，记住原理就不会被名字绕晕：

| 类别 | 触发原理 | 有无物理触点 | 特点 |
| --- | --- | --- | --- |
| **传统机械轴** | 金属动片/静片**物理接触**导通 | 有 | 手感风格最多、价格覆盖广；触点会氧化磨损，理论上有双击寿命问题 |
| **磁轴（霍尔轴 HE）** | 轴心磁铁 + PCB 霍尔传感器，实时读**按压距离** | 无 | 模拟量输出，触发点可调、支持 Rapid Trigger，竞技上限高 |
| **光轴（光学轴）** | 按下后打通/遮挡红外光路，靠光通断触发 | 无 | 无触点氧化、响应快、防双击，手感多接近机械轴 |
| **电感轴（电磁轴）** | 靠金属靠近改变线圈电感量来识别行程 | 无 | 同样无接触、可读行程，思路与磁轴相近，属另一套无触点方案 |

后三类都用「非接触」规避了机械触点的氧化双击问题；**磁轴/电感轴因为能连续读出按压深度，才支持可调键程、Rapid Trigger、模拟输入这些机械轴做不到的功能**。

### 没有完美方案：四类触发各自的短板

别只看优点，四类方案各有代价，这也是新技术一直在迭代的原因：

- **传统机械轴**：触点会氧化磨损、用久可能双击；金属弹片存在物理抖动，需要几毫秒「去抖」，这是它天生的延迟下限；
- **光轴（光学轴）**：本质仍是「通 / 断」两态的数字触发，<span class="hl-key">读不出连续按压深度，所以做不了 Rapid Trigger 和模拟输入</span>；触发依赖光路完整，重度进灰、强光直射理论上可能干扰（成熟封装后实际影响很小），早期光轴结构偏松、手感一般，因此一直比较小众；
- **磁轴（霍尔 HE，当下竞技主流）**：靠磁场读数，需要做磁通量校准、也存在温度漂移；<span class="hl-key">抗电磁干扰能力不如纯机械和纯光学方案</span>——周边强磁、无线模块或多模天线靠得太近时，理论上可能给霍尔信号引入噪声，这也是无线磁轴尤其考验主板布线和屏蔽的原因；另外要全行程稳定做到 0.01mm，对轴体磁铁一致性要求高（常需特挑）；
- **电感轴（电磁轴，最新的一条路线）**：用 PCB 线圈主动探测金属靠近产生的涡流变化来读行程，不依赖永磁体，厂商主打「不受磁场干扰、不受温湿度影响、免校准、寿命更长」，RT、8K 这些磁轴能做的它也都给。它非常新、上市产品少，长期一致性还需要时间验证。

!!! note "光轴、电感轴这么小众，为什么还要专门讲"
    因为看清「机械接触 → 光通断 → 磁 / 电感连续测量」这条技术演进线后，以后再遇到厂家造的任何新名词，你都能先把它归进这四类、再判断它是真创新还是换包装，而不是被参数和营销带着走。

### 磁轴的改良方向：多向 / 「八方」霍尔是什么

传统磁轴一颗键配一颗线性霍尔、只从一个方向读磁场；当你斜着按或键帽晃动时，磁铁相对传感器偏心，读数就可能偏。近年出现的<span class="hl-key">「多向霍尔 / 八方霍尔」，是在一颗键周围布置多个方向的霍尔、融合几路读数</span>，用来抵消倾斜和偏心误差，让行程检测更稳、标定更一致，厂商也常把它和更低的全链路延迟一起宣传。它属于磁轴自身的精度改良，并不是和磁轴并列的第五类触发方式。

### 机械轴：看懂行程与力度参数

- **结构**：上盖、轴心、弹簧、动片/静片触点；按下后触点接触即触发；
- **总行程**：从碰到键帽到按到底走多远，常见 3.6~4.0mm；
- **触发键程（导通行程/触发点）**：按到多深触发，传统机械轴多在 1.8~2.2mm 固定不变；
- **复位点（抬起行程）**：手指抬起、在多高处断开并允许下一次触发。机械轴必须抬过固定复位点才能再触发，这正是它和磁轴 RT 的关键差距；
- **触发压力（克力，gf/cN）**：需要多大的力按到触发点，常见 40~60gf，越轻越省力但也越容易误触；
- **回弹与弹簧**：长弹簧/渐进弹簧让回弹更跟手、力度曲线更线性；单段弹簧风格更传统。**厂润**（出厂润滑）和导轨精度决定顺滑度与杂音大小；
- **手感三分类**：线性轴（直上直下、无声，游戏主流）、段落轴（中段有轻微阻力反馈、打字有确认感）、有声段落轴（段落+脆响）。

### 磁轴：可调键程、死区与 Rapid Trigger

磁轴实时输出「当前按到了几毫米」，于是可以软件定义触发逻辑：

- **可调触发点（Actuation Point）**：想 0.2mm 一碰就触发、还是 1.5mm 防误触，都能设；
- **死区（Dead Zone）**：按键从完全松开到开始被纳入判定的区间，设死区可过滤手指虚搭造成的误触；
- **按下灵敏度 / 抬起灵敏度**：分别定义「再往下多少算触发」「往回抬多少算松手」；
- **Rapid Trigger（RT，快速触发）**：磁轴最核心的能力。机械轴必须把键抬回固定复位点才能再次触发；RT 改成**只看移动方向和位移量**——你按下触发后，只要往回抬一点点（比如 0.2mm）就立刻判定松手，再按下一点点又立刻触发。FPS 里 A/D 反复横移急停时，少抬的这一截就是快出来的几毫秒。

**灵敏度设多少合适**：日常/竞技常见落在 **0.1~0.3mm**，<span class="hl-key">0.1mm 上下对绝大多数人就已经到顶（再小更容易误触）</span>。再往下要分清「能不能做到」和「有没有必要」是两件事：

- **0.01mm 是「能做到、也经得起测」的**：好的磁轴靠线性霍尔加足够精度的模数转换，硬件和固件上确实能分辨 0.01mm。行业里评测一把新磁轴，常规操作就是用精密台架以 0.01mm 为步长抬升、按下，看它断触和触发准不准，送测机和零售机都会被拿来对比，所以不能简单说「硬件分辨不出 0.01」。但要**全行程都稳定做到 0.01mm 不断触**，对每颗轴磁铁的一致性要求很高（往往需要特挑轴体），而且从 0.02 缩到 0.01，普通人的实际手感收益非常小；
- **0.001mm 才更接近「参数游戏」**：这个量级已经小于居民楼环境微振动、手指自然抖动的振幅；再叠加后面[全链路延迟](#全链路延迟理论参数与真实手感)要讲的「游戏按固定节拍采样」，比一帧还小的变化会被直接量化掉，刻意追求意义不大；
- 另外手指搭在键上本来就有自然微抖，灵敏度越小越容易被这点抖动反复触发。新手从 0.2mm 上下起步，按「不误触的前提下尽量跟手」微调即可。

### 磁轴的高级功能（各家命名不同，原理就这几样）

不同品牌给同一类功能起的名字不一样，认准原理：

- **SOCD / Snap Tap 类（冲突方向清理、后输入优先）**：同时按住 A 和 D 这种相反方向时，传统键盘会互相抵消、角色原地不动；开启后按规则处理冲突，最常见的「后输入优先」是——按住 A 不松再按 D，立即判定为 D，无需先松开 A，变向少一个抬键步骤。*Snap Tap 是具体产品名，本质属于 SOCD；注意部分赛事/反作弊对这类功能有限制甚至禁用，参赛前先查规则。*
- **DKS（Dynamic Keystroke，动态键程）**：同一颗键在**不同下压深度绑定不同指令**，例如浅按「静步」、按深「奔跑」，MOBA 里可浅按显示技能范围、深按直接释放；
- **TGL / Toggle（切换）**：按一下等于持续按住、再按一下松开，适合需要长开的功能键；
- **MT / Mod Tap（短按/长按不同输出）**：轻按输出一个键、按住输出另一功能（如轻按是字母、长按当 Ctrl/Shift）；
- **模拟输入（Analog / 可变行程）**：把行程当摇杆扳机量，做到「轻推慢走、按满奔跑」（类似手柄扳机），需要游戏/系统支持。

### 键鼠宏是什么

**宏（Macro）= 把一串按键、点击、移动和间隔录下来，绑定到一个键一键执行**，比如一键连招、自动连点、批量重复操作。办公和单机游戏能省事；<span class="hl-key">但带反作弊的联机游戏里，宏/连点可能被判定为作弊而封号</span>，别在竞技网游里用。

## 怎么选：按用途对号入座

=== "FPS / 竞技游戏"
    - 首选磁轴/光轴这类无触点、响应快的方案，磁轴开 Rapid Trigger；
    - 线性手感、触发点 0.2~1.5mm 之间按误触情况调；配列建议至少保留方向键区（TKL/75%），避免误触；
    - 连接优先有线或高端 2.4G/星闪，回报率与鼠标匹配。

=== "打字 / 办公 / 码字"
    - 更看重段落反馈、声音是否扰人、克重和长时间疲劳度，而非极限触发；
    - 线性轴静音顺滑、段落轴有打字确认感；克重过轻反而容易误触、手搭上去就出字；
    - 多设备办公选支持多模切换、能在电脑/平板间一键切换的方案。

=== "音游 / 高速连点"
    - 看重最短触发、回弹跟手、RT 连续触发的稳定性；
    - 磁轴把触发点调浅、保证回弹一致；注意卫星轴和键帽晃动会影响高速输入的稳定性。

## 配列与整键结构

- **配列**：全尺寸（带数字小键盘）/ TKL 87（去小键盘）/ 75%（紧凑保留 F 区和旋钮位）/ 65%（去 F 区）/ 60%（极致紧凑、靠组合键实现方向键）。越紧凑越省桌面、越利于鼠标大幅移动，但要接受功能键靠组合实现；
- **结构（内胆怎么固定）**：Gasket（内胆靠硅胶垫「悬浮」夹持，软弹、声音干净，当下主流）、Top（上盖固定，偏扎实）、船壳（底板托住，最传统、偏硬）；
- **定位板材质**：PC（软、声音闷）、FR4（均衡偏暖）、铝（脆、硬朗）、碳纤维/黄铜等，直接改变敲击的软硬和音色。

## 客制化 DIY：一把键盘由什么组成

想自己组装/改装，按「外壳 → PCB → 内胆 → 键帽」理解，顺序上先定 PCB 和配列，再配内胆与外壳：

1. **PCB（电路板，核心）**：决定配列、是否热插拔（不焊接就能换轴）、是否支持磁轴/模拟、连接方案与**灯珠**；
    - **热插拔轴座**分三脚/五脚，买轴前确认兼容；
    - **灯珠位置分上灯位（北向南向）/下灯位**：影响 RGB 从轴体哪侧透光、以及和某些键帽/轴体是否打架；
2. **内胆**：定位板 + 轴体 + 各类消音填充的组合，是手感声音的主要来源；
3. **定位板**：见上，材质决定软硬音色；
4. **轴体**：按四大类原理选，再看克重、线性/段落、是否厂润；
5. **声音包（消音填充）**：夹心棉（PCB 与定位板之间）、轴下垫（轴底贴）、底棉（外壳底部），作用是抑制空腔音、让声音更集中干净；
6. **外壳**：决定结构（Gasket 等）、配重、颜值和打字时的整体刚性；
7. **键帽**：
    - **材质**：PBT 耐磨、不易打油发亮、偏磨砂；ABS 细腻、色彩好但易打油；
    - **键帽高度（profile）**：OEM（常见偏高）、**原厂/Cherry（偏矮、阶梯弧度经典）**、SA（高复古球帽）、**MDA（大接触面、圆润、近年流行）**、**低矮/矮轴帽（配合矮轴，更扁平）**等。高度不同，手指落点弧度和声音也不同，以敲起来自然为准；
8. **调校**：卫星轴（空格等大键）润滑与固定、轴体润滑、消除键帽钢丝音，是「同配置不同手感」的隐形差距。

## 连接方式与供电（三模 / 四模、电池）

### 有线、2.4G、蓝牙、星闪

- **有线**：零延迟、不耗键盘电量、最容易跑满回报率，竞技最稳，缺点是拖线；
- **2.4G 接收器**：延迟接近有线，是无线游戏主力，需占一个 USB 口，接收器尽量靠近键盘、远离 USB3 高带宽设备；
- **蓝牙**：方便多设备切换、省电，延迟相对最高，适合办公；
- **星闪（NearLink）**：和鼠标篇一致，主打微秒级低延迟与无线高回报率，但需随附的**星闪接收器/网关**，不能像蓝牙那样被任意主机直接搜到直连；
- **「三模」**通常指有线 + 2.4G + 蓝牙；**「四模」**没有统一标准，多是再加一路（第二路 2.4G、双有线口或额外通道），以厂商说明为准。

### 键盘鼠标到底插哪个 USB 口

这一点和装机篇主板接口是同一回事，这里再强调一次：

- <span class="hl-key">键鼠的带宽需求极低，USB 2.0 就绰绰有余，不需要非插蓝色/高速口</span>；
- 真正影响稳定的是：**优先插机箱后置、直连主板的口**，少走前置面板延长线；**别和移动硬盘、采集卡等高带宽设备共用同一个 USB 控制器**；
- 「插 2.0 一定比 3.0 快」在现代主板上基本是心理作用，按上面两条选口即可。详见电脑篇 [硬件 · 后置接口](../电脑/装机/硬件.md)。
- **2.4G 接收器丢了怎么办**：多数支持「对码配新接收器」，联系原厂买同方案接收器并按说明重新配对；通用接收器不一定兼容，买键盘时可留意是否支持多设备共用一个接收器。

### 电池与续航

- 供电分干电池与内置锂电；**RGB 背光对续航影响极大，关灯后续航常能翻数倍**；
- 关注边充边用、充电接口（Type-C）、闲置休眠与唤醒逻辑；
- 无线 + 锂电要兼顾电池重量对手感和配重的影响，电池老化后续航缩水是正常损耗。

## 全链路延迟：理论参数与真实手感

这一章很重要：**8K=0.125ms、RT=0.1mm 这些都是「某一个环节的理论值」，而你在游戏里真实感受到的快慢，是从手指到画面的一整条链决定的。** 理论参数固然重要，现实链路更重要。

### 一次输入要走过的完整链路

<figure>
手指发力 → 轴体导通 / 霍尔采样 → 主控扫描、去抖 / 滤波 →（无线编码、空口传输、接收）→ USB 上报 → 系统输入栈 → 游戏引擎采样 / 逻辑帧 → 显卡渲染 → 显示器刷新出光 → 人眼
</figure>

每一段都要花时间。厂商宣传的「0.1xx ms 全链路 / 端到端延迟」，通常只是把前面**几段硬件链路加起来**：

- <span class="hl-key">各家统计口径并不一样</span>：有的只算到 USB 上报，有的算到引擎收到，极少数才算到屏幕出光，所以不同品牌的「端到端延迟」数字不能直接比大小；
- 无线还要多「编码 → 空口 → 接收」几步，这也是同一款键盘有线往往比无线更稳的原因。

### 下游在「按拍子采样」：再快也会被量化

真正的天花板不在输入端，而在下游两个固定节拍：

- **游戏服务器 / 逻辑帧**：常见 64 / 128 tick，一拍约 15.6 / 7.8ms；
- **显示器刷新**：144 / 240 / 360Hz，一帧约 6.9 / 4.2 / 2.8ms。

<span class="hl-key">如果某一环节快到远小于「一个采样拍 / 一帧」，多出来的精度下游根本采不到，等于被四舍五入掉了。</span>比如在 60Hz 屏幕（一帧 16.7ms）上，把输入从 0.2ms 压到 0.05ms，这 0.15ms 的差距落在同一帧里，画面没有任何区别。

### 那为什么还要把每一环做好

「被量化」不等于「可以随便烂」：

- 链路追求的是<span class="hl-key">稳定在个位数毫秒、且不忽快忽慢（抖动小）</span>，而不是把某一项刷到 0.0x ms——一次 0.1ms、下一次 5ms 的抖动，比稳定的 1ms 更毁手感；
- 只有在高刷（240/360Hz）+ 高 tick 的竞技场景，一帧被压到 2.8~4.2ms，输入端稳定的亚毫秒差异才开始有意义；
- 这也回过头解释了前面几个结论：<span class="hl-key">RT 不必低于 0.1mm、回报率不必硬上 8K、0.001mm 步进没有意义</span>，都是同一个道理——单项突破下游节拍后收益迅速归零，而代价（CPU 占用、耗电、发热、误触、不稳定）实打实上升。

### 怎么判断真实延迟，而不是看宣传数字

- 看**第三方实测**：有线、无线分开测，看「稳定值和波动」而不是最低值，关注有没有丢包、回报率掉档；
- 看**整套搭配**：键鼠回报率要和你的 CPU、游戏帧率、显示器刷新率匹配，短板在下游时，换再贵的输入设备也白搭；
- 很多职业选手至今用 1K~4K 回报率、常规 RT，正是因为在他们的链路里这已经足够稳，剩下的靠训练和网络。

## 背光与灯珠：频闪是怎么回事

先纠正一个常见口误：**键盘背光用的都是 LED 灯珠，不存在「OLED 背光」**（OLED 是屏幕技术）。区别在**调光方式**：

- **恒流（DC）调光**：靠改变电流大小调亮度，全程稳定发光，手机相机对着拍**看不到滚动条纹**；
- **PWM 调光**：靠灯珠高速「亮—灭」闪烁、改变亮灭占空比来调亮度，低亮度时灭的时间变长，用**另一台手机的相机/慢动作**对着拍，能看到滚动的明暗条纹，就是频闪；
- 对频闪敏感（眼累、头晕）的人，优先选低亮度下仍不闪（高频 PWM 或 DC）的方案；上灯位/下灯位只影响透光方向，和闪不闪是两回事。

!!! note "PWM 不只键盘灯：风扇和水冷泵也在用"
    PWM 的全称是**脉冲宽度调制**，说白了就是「用很快的通/断切换、靠接通时间占比来控制平均输出」。键盘灯用它调亮度只是用途之一：<span class="hl-key">电脑里的机箱风扇、CPU 散热器风扇、水冷冷排风扇甚至水泵，也普遍用 PWM 调速</span>——同一个原理，一个调灯、一个调转速。那边怎么接线、为什么水冷也走 PWM，放在电脑篇散热里讲。

## 常见误区

!!! warning "这些坑先避开"
    - **「磁轴一定全面碾压机械轴」**：竞技触发确实是磁轴强，但打字手感、声音、性价比上机械轴仍有一席之地，按场景选；
    - **只看轴体不看整键盘调校**：卫星轴、定位板、结构、固件没调好，再好的轴也散；
    - **克重越轻越好**：过轻的轴手一搭就误触，长时间打字未必更省力；
    - **RT 灵敏度盲目拉到最低**：低于传感器分辨率和手指稳定极限后只剩误触，0.1~0.3mm 是务实区间；
    - **竞技网游乱开宏/SOCD**：先确认赛事和反作弊规则，避免封号。

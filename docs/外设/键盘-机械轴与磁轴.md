## 先搞懂原理

### 机械轴（传统触点轴）

- 结构：上盖、轴心、弹簧、两个金属触点（动片/静片）；按下后触点接触触发行程
- 手感来源：弹簧克重曲线 + 轴心导轨/段落结构 + 润滑
- 分类：线性轴（直上直下）/ 段落轴（有段落感）/ 有声段落轴
- 待补充：触发键程、总键程、导通行程、厂润、长弹簧/单段弹簧区别

### 磁轴（霍尔效应轴，无物理触点）

- 原理：轴心磁铁 + PCB 霍尔传感器，按**按压距离**输出键程值，不靠金属接触
- 由此带来的能力：
    - 可自定义触发点（0.1mm 级）
    - Rapid Trigger（动态急停：反向移动即触发，FPS 走 A/D 急停的关键）
    - 可调行程、模拟输入（部分方案）
- 待补充：不同磁轴方案（各家磁轴）、精度/延迟/一致性、RT 灵敏度怎么调

## 这个网站的组织原则

!!! info "内容主张"
    - **先讲判断框架，再给具体结论**：授人以渔，而不是简单罗列产品。
    - **区分「必须在乎」和「可以忽略」**：不同需求下，参数的重要性完全不同。
    - **标注经验的适用条件**：结论都有前提，避免绝对化。
    - **只讲技术原理，不夸、不推荐品牌**：品牌可以被客观提及，但值得被肯定的永远是技术本身，而不是牌子。

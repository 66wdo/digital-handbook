# 入户、光猫与路由器

这一篇讲数据进家的第一段：**光纤怎么进来、光猫和路由器各自负责什么、为什么很多人要让光猫「桥接」、以及路由器 / 交换机 / AP / Mesh 到底怎么分工**。把这几个设备的角色分清，家里网络的「大脑」就理顺了。

## 数据是怎么进家的

运营商的网络以**光纤**接到你家（老小区可能还是网线 / 电话线入户，现在基本都改光纤），链路是：

```text
运营商机房 / 分光器
   │  户外光纤
   ▼
弱电箱里的「光猫」  ← 光信号转成电信号、完成注册和拨号
   │  网线（WAN）
   ▼
「路由器」          ← 拨号 / NAT / 分配地址 / 发 Wi-Fi
   │            │
 有线设备      Wi-Fi / Mesh / AP
（电脑、NAS、电视） （手机、笔记本、智能家居）
```

**光猫（ONU / ONT，光网络单元）**做的第一件事是光电转换：光纤里是光脉冲，设备用的是网线上的电信号。它还要在运营商网络里「注册上线」，并常被塞进拨号、路由、Wi-Fi、IPTV、固定电话等功能，所以运营商送的机器本质是一台「光猫 + 路由器 + 无线 AP」的一体机。

光猫面板上几个口 / 灯的含义：

- **PON 口**：插入户光纤的方口，里面是激光，<span class="hl-key">不要直视光纤头、不要弯折光纤（弯曲半径别太小）</span>；
- **LAN 口**：接路由器或电脑，注意是千兆口还是百兆口、有没有 2.5G 口，老光猫可能混着一个百兆口；
- **IPTV / 电视口**：给运营商电视机顶盒专用，常和上网口走不同的内部通道；
- **电话口**：办了固话才用；
- 指示灯：**PON 常亮 = 光纤注册正常；LOS 亮红灯 = 光路断了**（光纤没插好、外线故障）；LAN 灯闪 = 有数据。

!!! note "LOS 红灯意味着什么"
    LOS 红灯是<span class="hl-key">光纤物理层没收到光</span>，问题在光猫之外的光纤段：入户尾纤被碰松、被折死，或户外分光器 / 外线故障。先检查家里光纤有没有被踩、被折、接头是否到位；没问题就报障，这不是改路由器设置能解决的。

## 光猫的两种模式：路由与桥接

光猫拿到数据后，有两种工作方式：

- **路由模式（默认）**：光猫自己拨号（PPPoE）、自己做 NAT、分配地址、发 Wi-Fi。好处是插上就能用、运营商远程好维护；代价是功能和转发性能受限于这台一体机；
- **桥接模式（Bridge）**：光猫<span class="hl-key">只负责光电转换，把拨号和路由交给你自己的路由器</span>。光猫变成一个「透明的转换器」，由性能更强、功能更全的路由器来拨号、NAT、发 Wi-Fi。

进阶用户常让光猫桥接，原因是：自己的路由器无线更强、功能更多（Mesh、QoS、插件等）、转发性能更高，也避免「光猫路由一次 + 自己路由又一次」的**双重 NAT**——双重 NAT 下，设备互访、游戏主机的 NAT 类型、端口映射都会更麻烦。

!!! warning "改桥接前先想清楚，别把网改没了"
    改桥接通常需要光猫的管理员（超级密码）或让装维 / 客服远程下发，改之前<span class="hl-key">务必记下运营商给的宽带拨号账号和密码</span>，桥接后要在自己路由器 WAN 口选 PPPoE 并填这套账号密码才能上网。没有靠谱路由器、或还看运营商 IPTV 的，保持光猫路由模式完全够用，不必为「显得专业」硬改。

!!! tip "桥接后 IPTV 怎么办"
    IPTV 机顶盒走的往往是和上网不同的内部通道（VLAN）。常见做法：让光猫继续保留 IPTV 口（只把上网改成桥接），机顶盒照旧插光猫的 IPTV 口；或用支持 IPTV / VLAN 的路由器接管。具体以当地运营商和光猫为准，别把电视和上网一起改断。

## 路由器到底负责什么

别把路由器和「发 Wi-Fi 的盒子」划等号，它同时干这些活：

1. **拨号 / 连外网**：PPPoE 拨号或自动获取地址，建立到运营商的连接；
2. **NAT**：把家里几十台设备共享成一条宽带、一个公网出口；
3. **DHCP**：自动给每台设备分内网 IP；
4. **路由转发 / 防火墙**：决定数据包往哪走、挡住不该进来的访问；
5. **有线交换 + 无线 AP**：提供 LAN 口和 Wi-Fi。

其中**有线转发性能（NAT 吞吐）由路由器的处理器决定**。千兆宽带普及后，一台老弱的路由器可能「光纤是千兆、测速却只有四五百兆」，瓶颈就在它的转发能力，而不是宽带本身。

## 路由器、交换机、AP、Mesh 的分工

这几个名词最容易混，核心区别是「**谁负责拨号和发地址，谁只负责把设备接进来**」：

| 设备 | 拨号 / NAT / DHCP | 提供有线口 | 发 Wi-Fi | 什么时候加 |
| --- | --- | --- | --- | --- |
| **路由器** | 是（网络的大脑） | 几个 | 是 | 一台起步，必需 |
| **交换机（Switch）** | 否 | 很多（5/8/16 口） | 否 | 路由器网口不够、要接大量有线设备 / NAS |
| **AP（无线接入点）** | 否 | 少量 | 是（专职） | 想要更强 / 更多位置的无线覆盖 |
| **Mesh 节点** | 主节点是路由，子节点做扩展 | 有 | 是 | 大户型、没预埋网线时无线扩展 |
| **光猫（一体机）** | 路由模式下是 | 少量 | 常带 | 运营商提供，负责入户第一段 |

- **网口不够 → 加交换机**。交换机是「傻快」的设备，插上就把所有有线口接到同一局域网，不参与拨号；
- **无线覆盖不够 → 加 AP 或 Mesh 节点**，而不是再买一台路由器串着拨号（那会制造双重 NAT）；
- 全屋无线覆盖有两套成熟思路：**Mesh**（同品牌节点自动组网、配置简单、适合没预埋网线的家庭）和 **AC + AP**（一个 AC 控制器统管多个吸顶 / 面板 AP，装修时预埋网线，效果稳定、美观，适合提前规划）。

## 路由器怎么选：只看技术维度

不推荐品牌，只给判断时该看的硬指标，按重要性排：

1. **有线网口规格（最容易被忽略、却决定天花板）**：WAN / LAN 是千兆还是 **2.5G**。如果你办了 2000M 宽带、或要用 2.5G NAS 内网高速互传，路由器和光猫之间、路由器和电脑之间都得是 2.5G 口 + 超五类以上网线，<span class="hl-key">任何一环只有千兆，整体就按千兆跑</span>；
2. **Wi-Fi 代际与频段**：Wi-Fi 6 是当前主流甜点，6E / 7 需要对应终端和环境才用满，详见《[无线 Wi-Fi](无线WiFi.md)》；
3. **流数和天线，而不是天线根数**：实际速率取决于**空间流数量、MIMO、频宽和 QAM**，天线只是收发元件，「六根天线」不等于快；
4. **处理器 / 转发性能 / 带机量**：智能家居设备多、要跑满千兆以上尤其重要；
5. **Mesh 与回程方式**：能不能组网、子节点之间走有线还是无线回程。

!!! warning "别被「AX5400 / BE7200」这类数字唬住"
    这个数字通常是<span class="hl-key">把 2.4G、5G（甚至 6G）各频段的理论协商速率相加</span>得到的峰值营销数字，现实里没有任何一台设备能同时占满所有频段，它也不反映处理器和网口规格。看它不如分别看「每个频段几流、多宽频宽、有没有 2.5G 口」。

## 大户型覆盖与设备摆放

- **一台主路由尽量放在房屋几何中心、偏高、开阔的位置**，信号向四周均匀扩散；
- 装修时**预埋了网线到各房间**：优先「主路由 + 各房间 AP / Mesh 节点走有线回程」，这是最稳的全屋方案；
- 没预埋网线：用 Mesh 的**无线回程**，节点之间尽量隔一堵墙以内、少穿钢筋混凝土；三频 Mesh 可用专用频段做回程，减少对终端带宽的占用；
- **金属弱电箱是信号屏蔽箱**：光猫和交换机可以放里面，<span class="hl-key">无线路由器不建议关进金属弱电箱</span>，否则 Wi-Fi 还没出门就被削掉一截；
- 路由器远离微波炉、蓝牙设备、无线鼠标接收器的拥挤频段，远离镜子和大面积金属，并注意散热（高温会让电子元件降速、缩短寿命）。

## 拨号、NAT 类型与游戏联机

- 家用宽带的上网方式主要是 **PPPoE 拨号**（填账号密码）或 **DHCP / 自动获取 IP**（上级设备已经拨号），路由器 WAN 设置里二选一，由运营商决定；
- 游戏主机里常看到 **NAT 类型：开放 / 中等 / 严格**。NAT 严格时难匹配、易掉线，多发生在「双重 NAT」或对称型 NAT 之后；改善思路是减少一层 NAT（光猫桥接）、让主机走 UPnP / 端口转发，或申请公网 IP；
- **UPnP / 端口转发 / DMZ** 都是「让外网能找到内网某台设备」的机制，游戏主机会用到；不了解时保持 UPnP 默认即可，不要随便把设备暴露到公网。

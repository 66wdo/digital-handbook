## 规划中的组织方式

建议每款游戏按下面的结构整理，方便检索：

```text
游戏攻略/
├─ 游戏A/
│  ├─ index.md          # 总览：机制、上手路线
│  ├─ 流程攻略.md
│  ├─ 职业或角色build.md
│  └─ 技巧与避坑.md
└─ 游戏B/
```

## 每篇攻略建议包含

- [ ] 适用版本（游戏会更新，结论必须标注版本/时间）
- [ ] 面向人群（新手/进阶/特定流派）
- [ ] 核心机制解释（先讲为什么，再讲怎么做）
- [ ] 分步流程 / 配置 / 路线
- [ ] 常见翻车点与解决办法

!!! note "提示"
    等开始写具体游戏时，我们在 `mkdocs.yml` 的「游戏攻略」下逐个登记即可，支持任意层级。

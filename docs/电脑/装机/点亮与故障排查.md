# 点亮与故障排查

第一次点不亮、风扇转却黑屏、开机反复重启——**这些极其常见，而且绝大多数不是硬件坏了**。本篇给你一套「不慌、不乱拆、靠证据」的排查方法。配合《[装机流程指南](装机流程指南.md)》一起看。

!!! abstract "核心心法"
    **从最简单处开始，一次只改一个变量，必要时回到最小系统。** 先怀疑线和设置，最后才怀疑硬件损坏。

## 开机时到底发生了什么：POST 自检

按下电源后，电脑并不是直接进系统，而是先做 **POST（Power-On Self-Test，开机自检）**：依次检查 CPU、内存、显卡、启动设备等关键硬件，通过后才开始引导系统。

排查时主板会用几种方式「告诉你卡在哪」：

- **Debug LED 故障灯**：主板上常标 CPU / DRAM / VGA / BOOT 四个小灯，**停在哪个灯，就指向哪个环节**（DRAM 灯常和内存没插好有关，VGA 灯常和显卡/视频输出有关）；
- **两位数字故障代码**：高端主板用代码表示具体阶段，含义查主板手册；
- **蜂鸣器报警**：不同长短「嘀」声组合对应不同问题；
- 也有主板用指示灯颜色表达。

!!! tip "先找到你主板的「诊断信号」再动手"
    开机时盯住 Debug 灯停在哪，比一上来拆零件高效得多。代码/灯号含义都在主板说明书里。

## 首次开机应该确认什么

第一次通电**别急着装系统**，先确认：

- [ ] 电源开关已开、主板正常通电、风扇正常转动
- [ ] 显示器有画面、能进入 BIOS
- [ ] CPU 型号被正确识别
- [ ] **内存容量正确**（买 32GB 就该显示约 32GB，不是 16GB）、双通道被识别
- [ ] SSD 容量和型号被识别
- [ ] CPU 温度正常（刚进 BIOS 不应异常偏高）
- [ ] CPU 风扇 / 水泵转速能被读到，没有异常报警

## 无限重启 / 卡自检：先「清 CMOS」

典型现象：**开机 → 黑屏 → 重启 → 黑屏 → 再重启……** 循环。这时候不要立刻断定「CPU 烧了」，先做两件最基础的事。

**先彻底断电、放掉残余电荷**

1. 关机、关掉电源后部开关、**拔掉电源线**；
2. 按几下机箱开机键并保持几秒，放掉主板残余电荷。

**再清 CMOS（把 BIOS 设置恢复到基础状态）**，常见方式（以你主板说明书为准）：

- 主板上的 **CLR_CMOS 跳线**，用螺丝刀短接几秒；
- 板载的 **Clear CMOS 按钮**或机箱后置清 CMOS 键；
- 最通用：**取下主板纽扣电池，等待几分钟再装回**。

!!! question "为什么清 CMOS 这么管用？"
    因为黑屏循环很多时候是 **BIOS 设置异常**导致的：内存 XMP/EXPO 参数不稳、CPU/内存超频或降压失败、电压或 PCIe 设置错误、启动配置异常。清 CMOS 是**把设置恢复默认，并不是维修硬件**，却能排除掉一大半「自己改设置改挂了」的问题。

### 超频 / 开 XMP / EXPO 后不开机

XMP（Intel 平台内存一键加速档）、EXPO（AMD 平台对应档）、CPU 超频、内存手动超频、降压（Undervolt），只要参数不稳都可能黑屏循环。

1. 先按上面方法**清 CMOS / 恢复默认**；
2. 部分主板支持 **BIOS Recovery、USB Flashback（免 CPU/内存刷写恢复）**，可在黑屏下救回；
3. **先用全默认设置验证硬件本身没问题，再逐项、一点点打开超频功能**，定位是哪一项不稳。

## 通电但黑屏无画面：最容易被吓到的问题

现象：**风扇在转、RGB 也亮、看着全都有电，显示器就是没画面。** 不要第一反应就拆显卡。

### 先查显示器和视频线

优先检查 **HDMI、DP（DisplayPort）**：

- 视频线**两端是否插到底**；
- **有独立显卡时，视频线要插在显卡的输出口上（机箱下方、横着的显卡位置），而不是主板的视频口（机箱后方 I/O、竖着的主板位置）**；
- 显示器**输入源（Source）是否选对**（插在 DP1 就要切到 DP1）；
- 换一根线、换显卡上另一个接口、HDMI/DP 互换试试；
- 例外：如果你本来就是要用 CPU 核显测试（没装独显），那才插主板视频口。

### 一次只改一个变量，别把整机拆光

!!! danger "错误示范：没画面就把 CPU、显卡、内存、水冷全拆一遍"
    同时换线、换内存、换槽、重装显卡，就算最后亮了，你也不知道是哪一步修好的，还可能把一个小问题拆成几个新问题。

正确做法是**一次只动一处，验证后再动下一处**。推荐排查顺序（从最简单、最易恢复的开始）：

!!! success "无画面基础排查链"
    **视频线 → 显示器输入源 → 显卡输出接口 → 显卡是否插好 → 内存重插 → Debug 灯 → 清 BIOS/CMOS → 再往 CPU / 主板等硬件深入**

举例：先换 DP 线，不亮；再换显卡上另一个 DP 口，不亮；换 HDMI，不亮；重新插显卡，还是不亮；最后看 Debug 灯停在哪……逐级深入。

### 重新安装显卡（物理步骤）

1. 关机、关电源、**拔电源线**；
2. 拧下显卡挡板固定螺丝、**拔掉显卡供电**；
3. 按下主板 PCIe 插槽尾部**卡扣**，平稳拔出显卡；
4. 重装时对准**主 PCIe x16 槽**、确认卡扣处于打开位，**垂直均匀插到底**，直到卡扣自动扣上、金手指完全没入；
5. 固定挡板螺丝、**重新插好显卡供电并确认到底**。

内存同理：黑屏且 Debug DRAM 灯亮时，断电后把内存拔出，用橡皮或干净软布轻擦金手指，对准防呆缺口重新垂直压到底，双条优先 A2+B2。

## 排查三原则

### 从最简单的问题开始

不要一上来就怀疑「CPU 坏了」。先查线插没插、供电到没到、输入源对不对——**绝大多数故障都在最简单的环节**。

### 一次只改一个东西

每改一处就开机验证一次。这样问题一旦消失，原因是确定的；同时改一堆，等于没排查。

### 回到「最小系统」缩小变量

问题复杂时，把机器精简到能点亮的最少配置：**一条内存（插 A2）、一块显卡（或先用核显）、一个系统盘、一个显示器、CPU + 散热 + 必需供电，BIOS 恢复默认**。最小系统能亮，再一件件加回设备，加到哪件出问题，方向就锁定了。

## 用软件「把感觉变成证据」

进了系统后，别凭感觉下结论，用检测软件验证（软件用途见分区首页术语表与流程篇）：

- 怀疑显卡性能不对 → **GPU-Z** 看 Bus Interface（总线接口）与 Render Test（渲染测试）下的 PCIe 链路；
- 怀疑内存没认全/没双通道 → **CPU-Z** + BIOS 对照；
- 怀疑温度异常 → **HWiNFO** 看温度、功耗、风扇/水泵转速。

!!! example "记一辈子的判断链：显卡为美观插错槽"
    **现象**：大显卡嫌第一根槽拥挤，为方便装水冷、理线，插到带金属加固的第二根长槽；能开机，但游戏掉帧。

    **正确思路不是「显卡坏了？」，而是「问题 → 建立假设 → 找证据」**：

    1. GPU-Z → Bus Interface → 点 Render Test 满载 → 看到实际链路只有 x8 / x4；
    2. 翻主板说明书 → 查第二根 PCIe 槽的通道配置，确认它不是满速主槽；
    3. 假设成立：显卡被降速，而非损坏；
    4. 换回第一根 CPU 直连 x16 槽 → 问题解决。

    这比死记「显卡必须插第一槽」有价值得多：你既知道了**为什么**，也学会了以后**怎么自己验证**。

!!! tip "真正值钱的是「反常识案例」"
    「水冷按说明书插 CPU_FAN 而非 AIO_PUMP」「第二根 PCIe 槽看着一样却只有 x4」「通电却无画面多是视频线问题」「自检不过未必是硬件坏」——记住这些反例，比背标准步骤更能让新手少走弯路。

## 装机完成 · 最终检查清单

=== "硬件（封盖前）"
    - [ ] CPU 方向正确、已落平并锁好
    - [ ] CPU 散热器扣具牢固、风扇/水泵线接好
    - [ ] 硅脂覆盖正常、没有过量溢出
    - [ ] 内存插在正确槽位（双条 A2+B2）且完全到位
    - [ ] M.2 固定牢固、导热垫保护膜已撕、散热片装回
    - [ ] 显卡插在主 x16 槽、卡扣锁住、挡板螺丝固定
    - [ ] 显卡供电完全插到底、卡扣锁住、根部无死折
    - [ ] 主板 24-pin、CPU EPS 供电都插好
    - [ ] SATA 设备数据线、电源线都接好
    - [ ] 前面板跳线、USB、HD AUDIO 正确
    - [ ] 系统风扇进/出风方向合理
    - [ ] 机箱内没有遗留螺丝、工具或多余扎带

=== "第一次开机"
    - [ ] 正常通电、能进入 BIOS
    - [ ] CPU 型号正确、温度正常
    - [ ] 内存容量、双通道正确
    - [ ] SSD 型号容量被识别
    - [ ] 水泵 / 风扇转速正常、无报警
    - [ ] 显卡被正确识别
    - [ ] 显示器正常输出画面

=== "装完系统后"
    - [ ] 先装主板芯片组驱动，再装显卡驱动
    - [ ] 设备管理器无未知/异常设备
    - [ ] CPU-Z 核对 CPU / 内存与双通道
    - [ ] GPU-Z 配合 Render Test 确认 PCIe 满速
    - [ ] 需要时用 HWiNFO 看温度、电压、功耗
    - [ ] 开启 XMP / EXPO 后重新验证稳定性
    - [ ] 由轻到重逐步做稳定性测试，而不是一次全上

## 写在最后

装机并不可怕。**真正危险的不是「我第一次装」，而是「不确定自己在做什么，却认定自己没错，然后开始用力」。**

遇到任何不确定，先停手，然后依次去看：**防呆标记 → 接口丝印 → 主板说明书 → 硬件说明书 → 通道/参数 → BIOS → 软件监测数据**，再决定下一步。

!!! success "最终原则"
    不靠猜、不靠蛮力、不靠「听说」——而是 **理解 → 安装 → 验证 → 排查**。经验帮你更快锁定方向，但永远不能代替说明书；真正可靠的说法是「通常这么接」，而不是「永远必须这么接」。

## :material-chip: CPU

CPU 是整台机器的通用计算核心，决定日常卡不卡、多开行不行、游戏的最低帧稳不稳。理解 CPU，分核心、频率缓存、型号、功耗这几个层面就够了。

### 核心与线程

**核心（Core）**是真正干活的运算单元，几个核心就是几个能同时干活的「工人」；**线程（Thread）**是任务调度的流水线，一个核心通过超线程可以同时跑两条线程，提升多任务利用率。

- Intel 的超线程叫 **HT（Hyper-Threading）**，AMD 的对应技术叫 **SMT（同时多线程）**，开关一般在 BIOS；
- 核心数决定「同时能干多少件事」，单核性能决定「单件事干得多快」，游戏更依赖后者。

#### 性能核与能效核（大小核）

从第 12 代开始，Intel 把核心分成两种：

- **性能核 P-core（大核）**：单核强、频率高，负责吃性能的重负载和游戏主线程；
- **能效核 E-core（小核）**：能效比高，负责后台、下载、多开等不那么急的活，把大核解放出来。

两者由系统调度分配任务（Intel 平台靠 Thread Director 硬件调度器配合 Windows）。**AMD 主流桌面锐龙目前是同构核心，也就是没有大核小核之分**，大小核主要是 Intel 桌面平台的概念。

!!! warning "进阶 · 打游戏要不要把小核（E 核）关掉？"
    先说结论：**没遇到问题就不用关，这是进阶排查项，新手可以直接跳过。**

    - **Windows 11** 对大小核调度更完善，一般能正确把游戏主线程放到大核，保持默认即可；
    - **Windows 10** 对大小核的调度不如 Win11，极少数情况下会把游戏主线程丢到小核，表现为帧数不低但**帧时间忽快忽慢、周期性卡顿、漏帧**；
    - 真遇到了，先在任务管理器/工具里确认游戏主线程跑在哪个逻辑核心上，再用 Process Lasso 之类工具把它固定到大核，而不是一上来在 BIOS 关核；
    - 直接关掉全部小核会损失多任务和后台能力，属于下策。系统层面升级到 Win11 通常就解决了。

#### 输入设备也要吃 CPU：键鼠绑性能核、轮询率要匹配

容易被忽略的一点：**鼠标、键盘并不是「插上就和性能无关」，它们的输入处理同样要占用 CPU。**

- **把键鼠 / 游戏进程交给性能核（P 核、大核）**：鼠标移动、点击和按键会按固定的「轮询率」不断向 CPU 上报，高刷游戏鼠标每秒可上报上千次。大小核平台上，如果鼠标驱动或游戏主线程被调度到 E 核（小核），而小核正忙着后台任务，输入就得排队、延迟变大，体感是「鼠标偶尔发黏、转身不跟手」。用 Process Lasso 这类工具把游戏和鼠标驱动固定到 P 核，输入会更跟手；AMD 桌面平台核心同构、没有大小核，但同样可以把它们固定在主频更高、不被后台抢占的核心上。
- **轮询率不是越高越好，要看 CPU 带不带得动**：1000Hz 对绝大多数 CPU 毫无压力，但 4000Hz / 8000Hz 鼠标每秒要产生数千次中断。单核性能弱、或 CPU 已经被游戏占满时，就可能出现**占用瞬间飙高、帧时间抖动、画面周期性卡顿，极端情况下鼠标一动反而掉帧**——这不是鼠标坏了，是 CPU 处理不过来。
- **结论**：高端高刷键鼠要配够用的 CPU；<span class="hl-key">CPU 偏弱时，把轮询率从 8K 降到 1K~2K，往往比硬扛更顺滑</span>。轴体、微动、轮询率本身怎么选，见外设篇。

!!! tip "CPU 太弱时，太好的键鼠反而「带不动」"
    输入设备越高端（高轮询率鼠标、磁轴键盘、带屏幕 / 带常驻驱动的外设），背后需要 CPU 处理的中断和后台进程就越多。当 CPU 本身已经是整机瓶颈时，再上 8KHz 鼠标、挂一堆驱动后台，可能出现鼠标一动帧率就掉、画面不稳、输入延迟反而增大的反常现象。**外设体验是有「CPU 门槛」的**，均衡搭配比单点堆料更重要——这一点在外设篇还会再呼应。

#### 核心数量怎么选

| 用途 | 大致需求 |
| --- | --- |
| 办公、影音、轻量网游 | 6 核富余 |
| 主流网游、3A 游戏 | 6~8 核足够，8 核以上游戏内提升很小 |
| 直播、多开、虚拟机、渲染/编译 | 12 核以上才真正吃得到红利 |

!!! tip "超线程 / SMT 要不要开？"
    绝大多数情况**保持开启**，它白送多线程性能。只有极少数很老的竞技游戏、或极限降温时，关 SMT 可能换来几帧或更低温度，需要自己 A/B 对比，没有普适结论，别当默认操作。

### 频率、缓存与 X3D

**主频/睿频**是核心每秒运算的节拍（GHz），同代架构下越高越快；**架构（IPC）**决定每个节拍能干多少活，所以跨代不能只比频率。**缓存**是核心身边的超高速小仓库，分 L1/L2/L3，离核心越近越快，作用是提前把要用的数据备好，减少干等内存的时间。

#### X3D 与大缓存

AMD 的 **X3D** 用 3D V-Cache（3D 垂直缓存）技术把一大块 L3 缓存叠在核心上方，缓存容量远大于普通型号。游戏（尤其网游、策略/模拟这类频繁调数据的）命中率更高、**取数据延迟更低——数据直接从身边的大缓存拿，不用反复去内存等**，所以帧数和最低帧往往明显更好。

!!! danger "X3D / AMD 超频务必注意（涉及硬件安全）"
    X3D 对电压和温度非常敏感，**不要手动给核心加电压、不要盲目把电压「调到甜品」**，出厂的睿频和 PBO 已经会自动管理，手动加压只会更热、更不稳，极端过压过热真的有损坏风险。
    想压榨一点空间，进阶做法是 **PBO2 的 Curve Optimizer 走「负压」（负值）**，且必须小幅度、逐档稳定性测试；新手保持默认、把散热装好，反而是最稳的。普通 AMD（非 X3D）同理，不需要手动升压。

### 型号后缀与核显

后缀直接决定你要不要买独显、能不能超频：

| 后缀 | 平台 | 含义 | 影响 |
| --- | --- | --- | --- |
| 无后缀 | Intel / AMD | 标准版 | 多数带核显，最省心 |
| F / KF | Intel | **无核显** | 必须有独立显卡才能点亮 |
| K | Intel | 不锁倍频、可超频 | 要配可超频主板才有意义 |
| X | AMD | 高频可超频 | 释放更高，也更吃散热 |
| G | AMD | 带较强核显 | 不玩大游戏可暂不买独显 |
| X3D | AMD | 3D 大缓存 | 游戏尤其网游强 |

!!! tip "核显是一份「保险」"
    核显（集成在 CPU 里的显示单元，Intel 叫 UHD/Iris，AMD 叫 Radeon 核显）能在独显故障、排查黑屏时充当「亮机卡」，还能承担视频编码（Intel QuickSync 等）。预算差不大时，留一颗带核显的 CPU 更从容。注意 **F / KF 这类无核显型号不具备这个能力**。

#### 散片与盒装

<span class="hl-key">CPU 本身极难用坏</span>。**盒装**走官方质保、部分带原装风扇；**散片**多为 OEM 流出、店铺质保、不带风扇、价格更低。找口碑好、支持验机的店买散片性价比很高，到手检查触点/针脚无使用痕迹即可。

### 功耗与匹配

TDP / PL（Intel 的 PL1/PL2、AMD 的 PBP/MTP）衡量的是这颗 CPU 的发热和供电量级，**它不代表性能，却决定你要配多强的[散热](#解热能力匹配)、多大的[电源](#功率与余量)、以及[主板供电](#供电规模vrm)够不够**。高功耗 CPU 这三样跟不上，满载就会降频。

### 超频与降压（进阶）

CPU 主频 ≈ 外频 × 倍频，现代超频主要就是调**倍频**和电压，属于进阶玩法，新手保持默认即可：

- **Intel**：只有型号带 **K**、且主板是 **Z 系列**才能自由调倍频，非 K 锁倍频；
- **AMD**：锐龙带 X 及全系在 B/X 板上可开 **PBO**（在功耗/温度墙内自动冲高），还能用 **Curve Optimizer（曲线优化器）做负压降压**，常常降温还略微提性能；
- **X3D 型号严禁手动加核心电压**——它的 3D 堆叠缓存对电压和温度敏感，加压有损坏风险，最多只做小幅负压；
- 比起超频，**降压（Undervolt）**往往更实用：在稳定的前提下降低电压，温度功耗双降，小机箱和笔记本尤其值得；
- 每次调整后都要用烤机和内存测试验证稳定，不稳就清 CMOS 重来。工具见《[软件调试与测试](软件调试与测试.md)》，设置项见[主板 BIOS](#bios一定要知道它存在)。

#### 降压 / 降压超频：往往比硬超更实用

**降压（Undervolt）**是在「依然稳定」的前提下，把芯片跑到某频率所需的多余电压减掉；如果降压的同时还把频率略微拉高，就叫**降压超频**——温度更低，频率反而能维持得更久，常出现「又凉又快」的效果。

- **为什么能降**：厂方为了保证同一批次所有芯片都稳定，电压普遍给得偏保守，体质好的芯片用更低电压也能稳跑，这部分余量就是降压空间；
- **好处**：温度、功耗、风扇噪音一起降，ITX 小机箱、夏天、笔记本尤其明显；不撞温度墙后睿频能持续更久，等于变相提性能；
- **什么情况值得做**：满载温度经常顶到温度墙（90℃上下）、想要更安静、或愿意花时间慢慢测稳定；本来温度就很低、不折腾的人没必要动；
- **Intel 怎么动**：在 XTU 或 BIOS 里用核心电压 **Offset（负偏移）/ Adaptive**，一次约减 0.01V 量级慢慢试，带 K 的型号也可以定压定频；
- **AMD 怎么动**：先开 PBO，再用 **Curve Optimizer（曲线优化器）**给全核或单核做负偏移，从 −10～−20 起步、每次 −5 逐档下探；
- **怎么看稳不稳**：压过头的表现是蓝屏、死机、跑分中途掉、游戏闪退或花屏——这不是温度问题，而是电压给少了，**回退一档**即可；用 Cinebench 循环、日常游戏和烤机共同验证，工具见《[软件调试与测试](软件调试与测试.md)》。

!!! warning "降压也要为稳定负责"
    降压不是越低越好，目标是「长期稳定」而不是极限温度数字；**X3D 只允许小幅负压、绝对不能加核心电压**。每调一档都要测稳，宁可留一点余量，也别压在崩溃临界点上长期用。

!!! danger "加压超频有代价"
    盲目加压会让发热和功耗陡增、缩短寿命，X3D 这类堆叠缓存型号加压甚至可能直接损坏。先把默认稳定运行和散热匹配搞明白再谈超频——对绝大多数人，「默频 + 良好散热」就是最优解。

!!! warning "CPU 可能造成的症状"
    - 高刷网游帧数上不去、最低帧频繁掉 → 可能是单核不够，也可能是[内存单通道](#单通道与双通道)；
    - 一满载就降频、温度撞墙 → 先查[散热](#解热能力匹配)和主板供电，别急着怪 CPU；
    - 大小核机器帧时间周期性卡顿 → 见上面「要不要关小核」；
    - 点不亮、Debug 灯停在 CPU → 多为插槽/供电/接触问题，见《[点亮与故障排查](点亮与故障排查.md)》。

## :material-expansion-card: 显卡

显卡是一整张加速卡：上面那颗并行计算芯片叫 **GPU**，旁边还有显存、供电、散热。它干的活远不止游戏。

### 显卡都负责什么

- **游戏**：实时渲染 3D 画面；
- **视频创作**：剪辑时间线特效、导出编码（PR、剪映、达芬奇），其中编码靠显卡/核显里的**硬件编码器**（N 卡叫 NVENC、A 卡叫 AMF、Intel 核显叫 QuickSync）；
- **3D 建模与渲染**：Blender、C4D、玛雅等，渲染加速分不同技术阵营——**CUDA / OptiX 是 NVIDIA 专有生态**，OpenCL 是通用标准，AMD 对应 HIP/ROCm；
- **AI**：本地大模型、AI 绘图主要看 **CUDA 生态和显存容量**，这也是 N 卡目前占优的领域；
- **音乐制作**要纠正一个常见误解：音频效果器运算**主要吃 CPU**，GPU 只在视频、可视化、部分 AI 降噪插件上帮忙，别为做音乐专门堆显卡。

!!! tip "生产力选卡，先查你用的软件"
    做内容/建模/AI，别只按游戏分辨率和帧数选，先查软件官方的「GPU 加速 / 推荐显卡」说明：它吃 CUDA 还是通用标准、吃显存还是编码器，结论可能和玩游戏完全不同。

### 显卡的主要规格

- **GPU 芯片与架构**：决定底子，同芯片不同品牌性能接近；
- **流处理器 / CUDA 核心数**：并行单元规模；
- **显存**：容量、位宽、代数（GDDR6 / GDDR6X / GDDR7）和**显存带宽**；
- **TGP / TBP**：整卡功耗，决定电源和散热。

#### 显存容量与作用

显存装的是材质、贴图、模型和计算数据。<span class="hl-key">1080P 8GB 起步、2K 建议 12GB 上下、4K 高材质或本地 AI 直接奔 16GB 以上</span>。显存不够的典型表现是高画质突然爆显存、掉帧、卡顿——这不是 GPU 核心慢，是「工作台」被塞满了。

### 同芯片的不同品牌型号（非公版）

不同品牌用同一颗 GPU，<span class="hl-key">核心性能差距通常只有几个百分点</span>，差价买的是散热规模（风扇数/热管数/均热板）、出厂频率、供电用料、噪音、外观和售后。预算有限选靠谱品牌的入门非公即可，避开散热严重缩水、温度撞墙的型号，不必为「旗舰皮」多花一大笔。

同一张卡名字后面的字母也有讲究，下单前看清，别只看名字像就当同款：

- **OC**：厂家出厂预超频版，频率略高、散热通常也配强一点，属于同芯片的「加料版」；
- **Ti / Super / Ti Super**：NVIDIA 的**官方提档型号**，流处理器/显存规格和原版不同，是另一档芯片，不只是超频；
- **V2 / Rev2 / 改版**：厂家后期修订版，可能换显存颗粒、换供电或换散热，有变好也有悄悄降规的，搜「型号 + V2 评测」对比；
- **LHR**：早年的「锁算力」版本，只限制挖矿算力，**对游戏没有影响**；
- **D（例如 RTX 4090D）**：面向中国大陆市场的合规特供版，按出口管制削减了一部分核心规模，和非 D 版并不是同一张卡；个别品牌型号尾部的 D 则表示「降规/缩水版」，以官方参数表为准。

### 光追与超分辨率技术

- **光追（光线追踪 / Ray Tracing）**用硬件光追单元实时计算反射、阴影、环境光遮蔽和全局光照，画面更真实，但非常吃性能，想开光追通常要把显卡档位提一级；
- **超分辨率**的思路是「先渲染较低分辨率、再用算法放大到屏幕分辨率」，用少量画质换大量帧数，分三派：
    - **DLSS**：NVIDIA 专有，靠 RTX 卡上的 Tensor AI 单元，分质量 / 平衡 / 性能 / 超级性能几档，渲染分辨率依次降低；DLSS 2 是时序放大，DLSS 3/4 进一步加入帧生成、多帧生成与光线重建，同档位画质通常最好，**只有 RTX 卡能用**；
    - **FSR**：AMD 开源、**A 卡 N 卡甚至核显都能用**，不依赖专用 AI 单元，FSR 2/3 也有时序放大和帧生成，极限放大倍率下细节略逊于 DLSS，但胜在通用免费；
    - **XeSS**：Intel 的方案，走 AI 放大，Arc 卡上有专用单元、其他卡也能跑，定位介于两者之间；
- **帧生成（Frame Generation）**在两帧之间「插」出中间帧，让显示帧率更高、画面更顺滑，但插出来的帧不是你操作实时算出来的，会增加一点渲染/输入延迟。

#### 光栅化与光追的区别

很多人把「光追」当成一个简单的画质开关，其实它和传统渲染是两套完全不同的「算光」思路，理解原理就知道它为什么真实、又为什么掉帧：

- **光栅化（传统渲染管线）**：先把场景里的三角形一个个「投影」到屏幕像素上，确定每个像素属于哪个物体再上色；光照、阴影、反射主要靠**提前烘焙好的贴图和屏幕空间特效去「模拟」**。路径是「物体 → 像素」，速度极快、最省性能，但阴影和镜面反射是近似出来的，换个角度、走到反射面前就可能露馅。
- **光线追踪**：方向反过来，从摄像机的每个像素向场景里**发射光线并反复弹射**，真实计算这条光先碰到谁、被谁挡住形成阴影、在镜面或水面上又反射出什么颜色，路径是「像素 → 光线 → 物体」。软阴影、镜面反射、间接的全局光照因此接近真实；代价是每个像素要追踪成百上千条光线，**极其吃算力**，必须靠显卡里专门的光追（RT）核心，还要配合超分 / 帧生成把帧数补回来。
- **游戏里并不是二选一**：现在大多是「光栅化打底 + 光追只负责反射、阴影、全局光照这几项」的**混合管线**，再用降噪和超分把结果补完整。这也解释了为什么开光追后掉帧主要集中在反光、阴影多的场景，而不是全程均匀变慢。

!!! tip "超分和帧生成，什么时候开"
    **单机 3A、沉浸体验**收益最大：开光追 + DLSS/FSR 质量档，画面和帧数兼得；**竞技网游、快节奏对战**优先保证输入延迟和清晰度，一般不开帧生成、超分也选质量档或不开。它本质是「用一点细节和延迟换帧数」，不是免费性能。渲染延迟、输出延迟和显示器刷新率的关系，会在《[显示器与刷新率](../../外设/显示器与刷新率.md)》里专门讲。

### A 卡与 N 卡

两家游戏都能玩。**N 卡（英伟达）**胜在 CUDA/AI 生态、DLSS/光追生态、编码器和驱动功能普及；**A 卡（AMD）**同价位常给更大显存、传统光栅性价比高。按你要玩的游戏和要用的软件定，而不是品牌立场。

### 性能发挥与异常排查

帧数不对，原因是一条链，**别只盯着显卡本身**，按顺序排查：CPU 瓶颈、内存是否单通道/容量够不够、PCIe 是不是跑在 x4（插错槽）、驱动版本、电源是否触发功耗墙、温度是否撞墙、游戏自身的垂直同步/分辨率缩放设置。

这里要认识一款检测软件：**GPU-Z 是一款免费的显卡信息与状态检测软件（Windows）**，用来看型号、显存、传感器和链路状态。它的 **Bus Interface（总线接口）**一栏显示 PCIe 协商状态，配合 **Render Test（渲染测试，让显卡短暂满载）**就能看出真实链路，而不是被桌面待机的省电状态骗到。

!!! example "真实案例：为了好看插错槽，能用却掉速"
    大显卡嫌第一根槽拥挤、为方便理线插到带金属加固的第二根长槽，结果能开机却掉帧。GPU-Z 配合 Render Test 一看，`x16 @ x4`——物理是 x16 槽，实际只协商到 x4。完整过程和验证方法见《[装机流程指南 · 安装显卡](装机流程指南.md#安装显卡建议最后装给走线留空间)》。

### 尺寸、散热与安装

显卡性能越强，散热规模（风扇数、热管、均热板）越大，卡也就越长越厚——这是最容易被忽略、却会直接导致**装不进去**的硬指标：

- **长度**：对照机箱参数里的「显卡限长」。三风扇长卡常见 300～340mm，小机箱/有水冷排排挤时尤其要提前量；
- **厚度（占几槽）**：双槽、2.5 槽、三槽，越厚越会挡住下方 PCIe 槽、贴紧主板；
- **供电插头和线材**在卡尾/卡侧，要预留插拔和弯折空间；
- 想彻底避开长度焦虑，就选**双风扇短卡**，绝大多数机箱都能装。

!!! tip "显卡竖装 / PCIe 延长线（转向支架）"
    想让显卡灯面朝向侧透玻璃，就要用 **PCIe 延长线 + 竖装支架**把横插的卡「转向」竖装。它**不改变任何硬件原理**，只是把插槽延长转向；成本和普通装机几乎一样、只略贵一点（线加支架通常几十到一两百），主要买的是**美观和整机视觉统一**。下单务必看清三点：①延长线要匹配 **PCIe 代数（4.0/5.0 选屏蔽合格的线，劣质线会降速、不稳，装完用 GPU-Z 确认仍跑在 ×16）**；②机箱是否带竖装位、够不够厚度；③竖装后显卡离侧板要留进风间隙，贴太近会把散热闷死。

!!! note "同一件事在两处讲，不是啰嗦"
    这里从「显卡散热规模决定长度」切入，《[机箱 · 尺寸兼容清单](#尺寸兼容清单)》从「机箱限长怎么量、怎么对照」切入，是一件事的两头——下单前把显卡长度和机箱限长对上，就不会翻车。

### 电感啸叫（ coil whine）

**啸叫是显卡（也可能来自电源、主板供电）上的电感在高频电流变化下振动发出的「吱吱 / 滋滋」高频声**，不是风扇声、也不等于硬件坏了，最常出现在游戏菜单帧率几百上千、跑分加载、或负载剧烈波动时。

- **为什么说它「玄学」**：声音大小和负载电流、帧率、每颗电感个体、整机供电环境都有关，没法保证某张卡一定不叫，也没有一招能保证彻底消除；
- **先区分是不是风扇**：把风扇手动停转（或用工具短暂拉到 0 转速）还响，就是电感；随风扇转速变化的沙沙 / 咔咔声则是轴承，两码事；
- **常见缓解办法**：开垂直同步或在驱动 / 小飞机里**限制最大帧率**（菜单空转高帧最容易叫）、提高分辨率和画质让负载更平稳、用功率余量足的优质电源、插紧供电线、把显卡固定结实减少共振；
- 声音大到无法接受、且在退换期内，可以走售后，但**轻微啸叫通常不属于质量故障**，也不影响寿命和性能，理性看待。

### 一体水冷显卡（水冷卡）

除了常见的风冷卡，高端型号还有**一体式水冷显卡**：GPU 核心由冷头压住，通过软管连到装在机箱上的外置冷排风扇散热，而显存、供电一般仍靠卡上的小风扇或机箱风道照顾。市面上客观存在的例子有七彩虹 iGame「水神」、微星部分水冷型号、华硕这类水冷联名/一体式方案等。

- **优点**：核心温度低、风扇更安静、排到机箱内的废热更少，适合追求低温静音、且机箱能装冷排的人；
- **代价**：要像装 CPU 水冷一样安排冷排位、走管、给冷排风扇接线，价格更高、结构更复杂，漏液和水泵故障虽罕见，但安装与质保要更上心；
- 对多数人，**一台散热做足的风冷旗舰卡反而更省心**，水冷卡是「为极致低温和安静买单」的选择。

### 显卡超频与调校

显卡也能小幅超频，但游戏帧数收益通常只有几个百分点，代价是更高的功耗和发热，**新手保持默认即可**。最常用的工具是 **MSI Afterburner（微星小飞机，免费，A 卡 N 卡通用）**：可以小步拉核心/显存频率、调功耗墙与温度墙、自定义风扇曲线；它附带的 RivaTuner 还能在游戏角落显示帧率、CPU/显卡占用和温度，是排查瓶颈的利器。更多测试软件见《[软件调试与测试](软件调试与测试.md)》。

#### 显卡降压超频（进阶，降温降噪明显）

显卡和 CPU 一样能「降压」，而且高端卡收益常常更直观。用 **MSI Afterburner 按 Ctrl+F 打开曲线编辑器（频率-电压曲线）**：找到显卡默认高频对应的电压点（常见在 0.9～1.0V 一带），把这个点的频率略微上移、再把曲线右侧压平并锁定，就能让显卡**用更低的电压跑到同样甚至略高的频率**。

- **好处**：核心温度和供电发热下降、风扇更安静，不撞温度/功耗墙后频率更稳，等于「同功耗更高性能、或同性能更低功耗」；
- **怎么试**：一次把频率点上移约 15MHz，锁定后跑 3DMark 压力测试（稳定性 97% 以上）和实际游戏，不花屏、不掉驱动、不闪退才算稳；不稳就退回上一点；
- 这是进阶微调，**新手保持默认即可**，原理和 CPU 降压一致，都是在稳定前提下挤掉厂方预留的电压余量。

!!! danger "加压、拉满有风险"
    超频遵循「不动电压、小步加频率、每步都测稳定性」：不稳的表现是花屏、掉驱动、黑屏，退回默认频率即可。**不要盲目加核心电压、拉满功耗墙**，显存超太猛也可能崩溃甚至影响寿命；刷显卡 BIOS、改卡更不建议新手尝试。

!!! warning "显卡可能造成的症状"
    - 帧数明显偏低、跑分异常 → 按上面「性能发挥与异常排查」整条链排查，别急着认定卡坏；
    - 通电黑屏、Debug 灯停在 VGA → 先查视频线是不是插在独显上、卡有没有插到底，见《[点亮与故障排查](点亮与故障排查.md)》；
    - 高负载黑屏/重启/花屏/掉驱动 → 查供电是否到底、电源功率、温度与显存。

## :material-developer-board: 主板

<span class="hl-key">主板不直接提高跑分</span>，它决定你**能上什么 CPU/内存、有几个 M.2 和什么通道、供电稳不稳、以后怎么扩展**。

### 芯片组与平台

芯片组是主板的「中枢型号」，决定扩展上限和能否超频：

- **Intel**：入门 H、主流 B、高端 Z（只有 Z 系列支持给 CPU 倍频超频，通道和接口也更多）；
- **AMD**：入门 A、主流 B、高端 X；
- 不超频、不堆多盘多卡，**主流 B 系列就是性价比甜点**，不必为用不到的扩展上旗舰。

前提是插槽同代、且主板 BIOS 已支持这颗 CPU（新 U 配老板可能要先刷 BIOS，优先选带 **USB Flashback（免 CPU 刷写）**的板）。

!!! note "冷知识：老主板说的「南桥、北桥」是什么"
    早年主板上有两颗芯片：**北桥**离 CPU 最近，管内存、显卡这些高速通道；**南桥**在主板下方，管硬盘、USB、网卡、声卡这些相对慢速的外设，一北一南协同。后来 CPU 把内存控制器和 PCIe 显卡通道（北桥的核心职责）一点点**收进了自己内部**，独立的北桥就此消失；剩下的慢速外设扩展仍由一颗芯片负责，它就是今天的**芯片组（Intel 叫 PCH，本质相当于原来的南桥）**。理解这段历史，你就能想通：为什么高速的第一根显卡槽、第一根 M.2 是「CPU 直连」，而其余设备要绕道芯片组——后面的通道布局图正是这个结构。

- **ATX**：插槽最多、扩展最全，适合大机箱和多硬盘；
- **M-ATX（mATX）**：紧凑、性价比高，绝大多数人够用；
- **ITX（Mini-ITX）**：最小，能做小钢炮，但同芯片更贵，且挑显卡长度、风冷限高和电源（常要 SFX 小电源）。

### 供电规模（VRM）

主板围绕 CPU 的那圈供电叫 **VRM**，负责把电源电压转换成 CPU 能用的电压。看三点：**供电相数、是不是 DrMOS、供电有没有散热片**。不用背参数，最靠谱的办法是查这块主板带同型号 CPU 的实测，看高负载下供电温度和 CPU 功耗能不能稳住。带高功耗 CPU 时，避开「几相裸电感、没有供电散热片」的极端丐版。

!!! note "贵的主板，通道布局不一定样样都好"
    价格高、堆料足，不等于 M.2 / PCIe 通道布局就一定对你最合适。部分高端板为了扩展口数量会**拆分通道**，某些槽共用带宽。所以别只看价位和「金属加固插槽」，下单前翻手册的通道拆分表、看实测，确认**主显卡槽是 CPU 直连满速、你要用的 M.2 不会挤掉别的口**。

#### 散热装甲（主板上的「马甲」）有没有用

主板上的金属装甲分两类：CPU 周边的 **VRM 供电散热片**、覆盖 M.2 的 **M.2 装甲**，也有纯装饰性的盖板。

- VRM 装甲让供电 MOS 在高负载下温度更低、不至于过热限流，带高功耗 CPU 时比裸电感更稳；
- M.2 装甲给高速固态散热（原理见[硬盘 · 固态散热马甲](#固态散热马甲m2-散热片要不要)），安装时导热垫两面的膜都要撕；
- 也有部分「装甲」只是装饰盖、底下并没有导热垫，<span class="hl-key">装甲块头大不等于供电强</span>，真正依据仍是供电相数、DrMOS 和实测温度；反过来，没装甲的板也不是不能用，CPU 功耗不高、机箱风道好一样稳定。

### 后置接口与板载功能

- **后置 I/O**：看 USB 版本和数量（USB 3.x / Type-C / 雷电）、网口（是否 2.5G）、音频口、Wi-Fi/蓝牙天线座；
- **前置 Type-C**：机箱前面板有 Type-C 的话，主板必须有对应插针，否则用不了；
- **板载 Wi-Fi/蓝牙**：不方便插网线、要连无线耳机手柄就选带 Wi-Fi 的版本，或之后加装 M.2 无线网卡（注意它可能占用一个 M.2 通道）。台式机有条件还是插网线最稳。

#### 老而弥坚的 PS/2 圆口（绿 / 紫双色）

后置 I/O 上偶尔还能见到一个圆形接口，那是 USB 普及之前的标准键鼠口，现在属于"小众但关键时候救命"：

- **颜色分工**：<span class="hl-key">绿色接鼠标、紫色接键盘；也有绿紫各半的「二合一复合口」，键鼠都能插（靠插头识别）</span>；
- **为什么高端板、老服务器还留它**：PS/2 走中断直连，<span class="hl-key">不依赖 USB 控制器、不占 USB 资源</span>。在 USB 还没完成初始化的开机最早期、超频失败清 CMOS 重新进 BIOS 时，PS/2 键盘往往照常能操作，而此时 USB 键盘可能完全没反应；加上它天生容易实现全键无冲、不和其他 USB 设备抢控制器，所以在工业机、服务器上一直没消失；
- **为什么日常很少见**：不支持热插拔（开机拔插通常要重启才认）、只能接键鼠、速率低，消费市场早已被 USB 和无线取代；
- **转接线分两种，别买错**：
    - **被动转接头（几块钱、只改形状）**：里面没有芯片，要求键鼠**本身原生支持 PS/2 协议**（不少老机械键盘的 USB 其实是双模、可直转），纯 USB 设备插上没反应；
    - **主动转换器（带芯片）**：把真正的 USB 键鼠"翻译"成 PS/2，但兼容性一般，多媒体键、宏、高回报率这些高级功能容易失灵；反过来，**PS/2 键盘转 USB 也一样必须用主动转换器**。

日常用 USB / 无线就好；<span class="hl-key">PS/2 的价值主要在极限排障、进 BIOS 和老设备/服务器场景</span>，这也是高端主板仍愿意留一个复合 PS/2 口的原因。

#### 板载 Wi-Fi 与蓝牙（WiFi 6 / 6E / 7 怎么看）

主板的无线由一颗 M.2 形态的无线网卡提供（常见 Intel AX / BE 系列），规格写作 Wi-Fi 6 / 6E / 7，并配套蓝牙 5.x；带 Wi-Fi 的主板后置 I/O 上有两个**天线座**，要把随附的拧扣天线接上、立起来，信号才好。

- **Wi-Fi 6（802.11ax）**：当前主流，速率高、多设备并发稳，绝大多数人够用；
- **Wi-Fi 6E**：在 Wi-Fi 6 基础上新增 6GHz 频段，干扰更少、延迟更稳，但需要同样支持 6E 的路由器和终端才用得到；
- **Wi-Fi 7（802.11be）**：最新一代，速率、并发和多链路更强，属于面向未来，现阶段路由器和终端还没普及，不必为它硬加预算；
- **蓝牙**用来连无线耳机、手柄、键鼠；台式机有条件优先插网线（延迟和稳定性最好），没法布线再用 Wi-Fi；
- 不带 Wi-Fi 的主板日后也能自己加装 M.2（E-Key）无线网卡或 PCIe 无线网卡，但**可能占用一个 M.2/通道，加装前看手册**；天线不接、又被金属机箱和挡板挡住，无线信号会很差。

#### 主板后置视频口、核显与独显的关系（容易误解，重点）

主板背后那排 HDMI / DP **物理上只和 CPU 核显（iGPU）相连**，和独立显卡不直接连通：

1. 想用主板视频口出画面，**CPU 必须带核显**，且部分主板默认把核显设为「自动/关闭」，要在 BIOS 里打开核显多显示器（常见名 **iGPU Multi-Monitor / 集成显卡 = Enabled**）；
2. 可以做到「<span class="hl-key">独显负责渲染画面、核显负责输出到显示器</span>」（类似笔记本的混合输出），但画面要从独显拷到核显再输出，**会多一点开销和延迟**，还可能影响独显硬件编码、部分全屏和 G-Sync/FreeSync；追求游戏体验应当把显示器直连独显；
3. **F / KF 等无核显 CPU，主板视频口永远是黑屏，不可能借独显从主板口出画面**——没有核显就没有那条输出通路。独显真坏了、CPU 又没核显，就是点不亮，这也是前面建议留核显的原因；
4. 核显的正确打开方式是：备用亮机排查、视频 QuickSync 编码、OBS 分流编码。

#### USB 版本、接口颜色，与 Type-C / 雷电的区别

先分清「形状」和「协议」是两回事：USB-A、USB-C（Type-C）说的是接口的**物理形状**；USB 2.0 / 3.x、雷电说的是**跑什么协议、有多快**。同一个 Type-C 口，可能只是 USB 2.0，也可能是满血雷电，具体看主板手册和口旁的丝印标识。

- **速度梯队（理论带宽）**：USB 2.0 为 480Mbps（实际约 40MB/s 级）；USB 3.0 / 3.1 Gen1 / 3.2 Gen1 都是 **5Gbps**（反复改名、速度没变）；USB 3.1 Gen2 / 3.2 Gen2 为 **10Gbps**；3.2 Gen2×2 为 **20Gbps**（需专用线材和接口）。命名被厂商改过好几轮，认准 Gbps 数字即可；
- **接口颜色只是惯例、不是强制标准**（最终以手册为准）：**黑色**多为 USB 2.0；**蓝色**多为 USB 3.0（5G）；**青绿/绿色**多为 10G/20G 高速口；**红/黄**常是「关机也供电」的常电充电口；**橙色**部分厂家用来标快充/大电流口；
- **Type-C ≠ 雷电**。Type-C 只是形状。**雷电（Thunderbolt，口旁有闪电标志）**在同一 Type-C 上同时跑 PCIe + DisplayPort + USB：雷电 3/4 带宽 40Gbps、雷电 5 达 80Gbps，能外接显卡坞、高速硬盘坞、多台扩展屏并一线供电；普通 USB-C 只有 USB 协议速度。**USB4** 在物理形态上与雷电同规格、可达 40Gbps，但是否完整兼容雷电功能仍要看厂家标注；
- **键盘鼠标插哪个口**：<span class="hl-key">键鼠需要的带宽极低，USB 2.0 就绰绰有余，不存在「必须插 3.0」</span>。真正影响稳定的是别和移动硬盘、采集卡这类高带宽设备挤在同一个 USB 控制器上；插在机箱后置、直连主板的口，通常比走前置延长线更稳。网传「键鼠插 2.0 比 3.0 更快」在现代主板上基本是心理作用——优先选后置直连、不与高负载设备共享的口即可（键鼠篇还会再呼应一次）。

#### PCIe 长插槽除了插显卡，还能插什么

那几根长短不一的 PCIe 插槽（x16 全长槽、x1 短槽）本质是"高速扩展通道"，独立显卡只是最常见的一种插法，它还能扩展：

- **采集卡**：把主机游戏、相机、另一台电脑的 HDMI/SDI 画面采集进来直播或录制；
- **网卡**：<span class="hl-key">万兆 / 2.5G 有线网卡、Wi-Fi/蓝牙无线网卡</span>，板载网口不够、或想组万兆内网时加装；
- **独立声卡**：对板载声卡音质不满意时，加 HiFi / 游戏独立声卡；
- **各类扩展卡**：更多 USB/SATA 口、Type-C/雷电扩展卡、把 NVMe 固态装上去的 M.2 转接卡、视频压缩协处理器等。

加装时记住三点：①<span class="hl-key">插哪根槽、实际跑几速由通道布局决定</span>（对照上面的走线图，物理长槽不一定满速，还可能和某根 M.2 共享通道）；②显卡占满 x16 后，第二根长槽常被降到 x8/x4，插万兆网卡、NVMe 扩展这类高速卡前先查手册通道表；③x1 短卡通常能插进更长的槽（槽前端开放时），低速设备用 x1 就够。

!!! note "特殊设计：DIMM.2 扩展卡"
    部分高端板（典型如华硕 ROG 的一些型号）不在主板平面铺 M.2，而是配一张**插在内存槽之间的 DIMM.2 子卡**，把一两个 M.2 插槽做在这张卡上，以节省主板空间、改善固态散热。它同样占用 PCIe 通道、也可能和别的槽共享：装机时先按手册把 DIMM.2 卡插到位，再往卡上装 M.2，认盘和测速逻辑与普通板载 M.2 完全一致。

### 前面板跳线的普遍接法

新手最怕的一把散线，其实有**普遍规律**（不同主板丝印位置略有差异，**普遍规律能解决绝大多数情况，最终仍以你主板丝印和手册为准**）：

- **Power SW（开机）、Reset SW（重启）**：本质是个开关，**不分正负极**，找到主板上标 `PW/PWR_SW`、`RESET/RSW` 的两根针插上即可，方向无所谓；
- **Power LED、HDD LED（电源灯、硬盘灯）**：是发光二极管，**分正负极**——通常彩色（绿/红）为正、白色或黑色为负，主板针座旁印有 `+/-` 或小三角标正极；**接反了只是灯不亮，不会烧**，对调即可；
- **USB 2.0 / USB 3.x / Type-C / HD AUDIO**：都是**一体式防呆插头**，对准缺口和缺针方向，垂直按下即可，**不能靠「长得差不多」硬插**，前置 Type-C 尤其别用蛮力；
- 找不到丝印就找主板上的小字（常印在针座旁或主板边缘），再对照手册的前面板接线图。

### 背插式（背线）主板与背插整机

近年很流行的「背插」是一种**整机形态**：把供电、风扇、前面板、USB 等接口和走线都挪到主板背面，让机箱正面看不到一根线，更整洁、风道也不被线材挡住。

- **背插式主板**：针脚和接口主要布置在主板背面，正面只剩 CPU、内存、显卡、M.2 这些插槽和散热片；
- **必须成套搭配**：背插主板要配**专用背插机箱**（背面有对应开孔和理线仓），普通机箱装不出背插效果；显卡可通过「背插显卡 / 背插连接套件」把供电转到背面；
- **优点**：正面极简、理线门槛低、风道顺；**代价**：主板和机箱的选择面较小、价格略高、和普通配件通用性差，换机箱受限。

!!! tip "背插不改变任何硬件原理"
    背插只是把接口和走线「换了个面」，CPU、内存、显卡、通道、供电、跳线的知识完全通用；背插整机的具体装机与走线顺序见《[装机流程指南](装机流程指南.md)》。

### BIOS：一定要知道它存在

**BIOS（现在多为图形化的 UEFI）是写在主板上的固件，开机狂按 Del（部分品牌机/笔记本是 F2）进入**，是硬件和操作系统之间的第一层设置；你改的设置存在主板一块叫 **CMOS** 的小存储里，靠纽扣电池维持。新手不必每项都懂，但要知道常用项在哪、是干什么的：

| 设置项 | 作用 | 什么时候碰 |
| --- | --- | --- |
| XMP / EXPO | 内存一键跑到标称频率 | 装完机开一次，详见[内存](#xmp-与-expo) |
| Boot 启动顺序 | 选择从哪个硬盘/U 盘启动 | 装系统、找不到启动盘时 |
| Secure Boot / TPM(PTT/fTPM) | 安全启动、可信平台模块 | 装 Windows 11、部分反作弊要求 |
| SVM / VT-x 虚拟化 | 打开 CPU 硬件虚拟化 | 见下方说明，**不只是虚拟机才要开** |
| Resizable BAR（ReBAR / SAM） | 让 CPU 一次性访问全部显存 | 新平台默认开，老平台手动开，游戏小幅提帧 |
| iGPU / 核显开关 | 启用主板视频口、核显编码 | 用核显输出/QuickSync 编码时 |
| Fan / Q-Fan 风扇曲线 | 设定风扇随温度的转速策略 | 嫌吵或想加强散热时 |
| CPU 倍频 / 电压 | 手动超频、降压 | 进阶，仅 Z/X 等可超频板，新手不动 |
| 内存频率/时序/电压 | 手动超内存 | 进阶，XMP/EXPO 不够用时再研究 |
| PCIe 版本（Gen） | 手动锁定链路代数 | 排查链路协商异常时 |
| Flashback / BIOS 更新 | 免 CPU 刷写、升级固件 | 支持新 CPU、修 bug、补微码 |
| Load Defaults / 清 CMOS | 一键回到出厂设置 | 改设置改挂了的救命招 |

#### 虚拟化：不只是虚拟机才要开

BIOS 里的 **Intel VT-x / AMD-V（AMD 主板常叫 SVM）**是 CPU 的硬件虚拟化开关。很多人以为只有装虚拟机、安卓模拟器才用，其实**现在不少内核级反作弊也要它**：例如部分游戏的 **ACE（反作弊）**、Vanguard 这类运行在系统内核层的保护，以及 Windows 的 WSL2、沙盒、Hyper-V、Docker，都依赖虚拟化；**没开可能出现反作弊加载失败、游戏进不去、模拟器报错**。如果你不用这些、且追求极致，可以保持默认；遇到上述问题，先进 BIOS 把虚拟化打开。

#### 超频在 BIOS 里到底调什么

CPU 主频 ≈ **外频 × 倍频**，现代超频主要是拉**倍频**（再加一点电压稳定）：Intel 只有型号带 K、且配 Z 系列主板才能调倍频；AMD 带 X 的和锐龙全系在 X/B 板上可小幅调（PBO、曲线优化）。内存超频就是调频率、时序和内存电压。**这些都属于进阶操作，不稳定的代价是黑屏循环，靠清 CMOS 救回**，新手用 XMP/EXPO 和默认即可，原理见《[软件调试与测试](软件调试与测试.md)》的稳定性验证。

!!! tip "分三档对待 BIOS"
    **必会**：开 XMP/EXPO、选对启动盘、改挂了会 Load Defaults / 清 CMOS；**按需**：虚拟化、ReBAR、核显、风扇曲线、Secure Boot/TPM；**别乱动**：CPU/内存电压与时序、PCIe 代数、各种高级时序，等你清楚后果再改。详细排查见《[点亮与故障排查](点亮与故障排查.md)》。

!!! warning "主板可能造成的症状"
    - 某 M.2/SATA 口突然不能用、固态跑不满速 → 多为通道共享或插错槽，不是硬盘坏；
    - 超频/开 XMP 后无限重启 → 清 CMOS 恢复默认；
    - 高功耗 U 满载掉频、供电发烫 → 主板供电规模不够；
    - 主板视频口黑屏 → 先确认 CPU 有没有核显、BIOS 有没有开 iGPU。

## :material-memory: 内存

内存是程序运行时的临时工作台，断电即清空。影响体验的优先级是：<span class="hl-key">容量 ＞ 通道 ＞ 频率/时序</span>，按这个顺序看不会错。

### 容量

- 办公、轻度使用：**16GB** 起步；
- 游戏、多开、大量浏览器标签：**32GB** 是当前最舒服的甜点；
- 剪辑、虚拟机、本地跑 AI：**64GB 起**，按需再加。

### 单通道与双通道

两条内存并行工作就是**双通道**，理论带宽翻倍。它对游戏最低帧、对核显性能影响尤其明显（核显没有独立显存，要借用内存当显存）。所以<span class="hl-key">优先两条组双通道，而不是单条大容量</span>；具体插哪两个槽（常见 A2+B2）见《[装机流程指南 · 安装内存](装机流程指南.md#安装内存为什么不是有空槽就插)》。

### 代数与频率

- **DDR4 / DDR5 是「代数」，由 CPU 和主板平台决定，互不兼容**，缺口位置都不同，不能混插；
- 同代之内频率（MHz）越高理论越快，但边际收益递减，不必为几百 MHz 加很多钱；
- 新平台直接 DDR5，老平台没必要为换 DDR5 连主板 CPU 一起换。

#### AMD 与 Intel 的内存「甜点」并不一样

内存控制器对频率的耐受度两家不同，<span class="hl-key">不是频率越高越好，关键是频率、时序、内存控制器频率处在同步甜点</span>：

- **AMD Zen 架构**对内存延迟敏感，存在明显甜点：Zen3（DDR4）多在 **3600MHz 上下**（对应 FCLK 1800 的 1:1 同步，再高容易切异步、延迟反而上升）；Zen4/Zen5（DDR5）多在 **6000MHz 上下**，再往上可能进入分频，收益变小甚至不稳；
- **Intel** 对高频更宽容（分 Gear1/Gear2 模式），DDR5 可以上更高，但游戏里的实际收益同样有限；
- 目标是「频率够高 + 时序够紧 + 控制器同步」的平衡低延迟，而不是盲目追最高数字。开了 XMP/EXPO 后用内存测试验证稳定性。

### 时序（CL）

时序是内存响应的「等待节拍」，最常看 **CL（CAS Latency）**。同频率下 CL 越小反应越快；跨频率要换算**实际延迟 ≈ CL × 2000 ÷ 频率（纳秒）**才公平。日常使用中同时序差距基本感知不到，不必盯着参数表焦虑，稳定优先。

### 颗粒

内存条的真正核心是上面的 **DRAM 颗粒**，体质决定超频上限。能自产颗粒的原厂主要三家：**三星（Samsung）、海力士（SK hynix）、美光（Micron）**；同一家还分不同档次的 die（例如海力士 A-die/M-die、经典的三星 B-die、美光 Rev 系列），超频潜力不同。

而金士顿、芝奇、英睿达、海盗船这些「内存条品牌」是采购颗粒、设计 PCB 和散热片的模组厂。**普通用户不需要专门挑颗粒**，开 XMP/EXPO 能稳定跑就是好条；只有玩手动超频才需要研究颗粒体质。

### 散热马甲：有马甲 vs 无马甲

内存「马甲」是包在颗粒外的金属片，作用是扩大散热面积、兼顾外观和 RGB 灯效：

- 普通只开 XMP/EXPO 的内存发热并不大，**有没有马甲对性能、稳定几乎没区别**，马甲更多是颜值和一点超频余量；
- 只有手动超到较高频率/电压、或 ITX 密闭小机箱里内存紧贴显卡、风道很差时，马甲才有实际散热意义；
- 马甲厚度不代表性能，别为夸张的「重甲 / 高塔马甲」额外付太多，反而要注意高马甲会不会和塔式风冷打架。

### XMP 与 EXPO

内存出厂默认只跑在一个保守的通用频率（JEDEC 标准），你买的「32GB 6000」要跑到 6000，需要在 BIOS 打开厂家预设：

- **XMP（Extreme Memory Profile）**：Intel 主导的一键预设，AMD 平台多数也能用；
- **EXPO（EXtended Profiles for Overclocking）**：AMD 随 AM5/DDR5 推出的预设，针对 AMD 平台把参数调得更全更对口；
- **两者本质相同**：都是厂家预先写好、存在内存 SPD 芯片里的「频率 + 时序 + 电压」一键配置，Intel 平台选 XMP、AMD（尤其 AM5）优先 EXPO。**不开，内存就只跑默认低频。**

!!! danger "开了 XMP/EXPO 黑屏重启怎么办"
    这说明这一档在你这套 CPU/主板上不稳，**不是内存坏了**：清 CMOS 恢复默认 → 降低一档频率或收紧前先放宽时序 → 再开，逐步找到稳定值。手动加压、强行收紧时序属于超频，有不稳定甚至长期风险，新手用厂家预设即可。详见《[点亮与故障排查](点亮与故障排查.md#无限重启--卡自检先清-cmos)》。

### 几条、混插与插法

- **优先两条大容量，而不是四条插满**：四条对内存控制器压力更大，高频时可能要降频才稳；
- 不同品牌/频率**可以混插**，但整机统一按「最低频率、最松时序」运行，想要最佳性能和稳定，尽量买同规格**套条（成套两连包）**；
- 单条优先 A2、双条优先 A2+B2，以主板手册为准。

!!! warning "内存可能造成的症状（最容易「背锅」也最容易被冤枉）"
    - 买 32GB 只认到 16GB、双通道没认到 → 先重插、换槽、用 CPU-Z 核对，别急着判坏；
    - 开机黑屏、Debug 灯停在 DRAM → 九成是没插到底或 XMP/EXPO 不稳，先清 CMOS、逐条测试；
    - 游戏偶发卡顿、最低帧不稳 → 可能正是单通道或容量不足，不一定是显卡或 CPU 的问题。

## :material-database: 硬盘

硬盘决定开机、开软件、读存档、导素材有多快。先分清种类，再看性能、缓存、寿命这几个层面。

### 种类与接口

| 类型 | 形态/总线 | 速度梯队 | 定位 |
| --- | --- | --- | --- |
| NVMe 固态 | M.2 形态、走 PCIe 通道 | 最快（数千 MB/s） | 系统盘、常用软件、常玩游戏 |
| SATA 固态 | 2.5 寸或 M.2(B-key)、走 SATA | 约 500MB/s | 老机升级、副盘，性价比高 |
| 机械硬盘 HDD | 3.5/2.5 寸、SATA | 最慢（百 MB/s 级） | 大容量冷数据/素材仓库 |

注意 <span class="hl-key">M.2 只是一种插槽「形态」，不代表速度</span>：M.2 槽里既可能走 NVMe（PCIe，快），也可能走 SATA（慢），买之前看主板支持哪种协议。

#### 特殊形态：DIMM.2 转接卡（长得像内存的硬盘扩展卡）

少数高端主板（例如华硕部分 ROG 型号）会提供 **DIMM.2 卡**：它外形像一根内存条、插在专用的 DIMM.2 插槽里（占用一个类似内存槽的位置），卡上再装 1～2 个 M.2 固态，并通过走线直连 CPU。这么做是为了把 M.2 从显卡下方的闷热位置挪出来，改善散热、也更灵活地分配通道。

!!! note "DIMM.2 不是拿固态当内存"
    它只是**借用内存槽的物理形态来扩展 M.2**，上面跑的仍是 PCIe 通道的 NVMe 固态，不会变成内存。它占不占内存通道、走 CPU 还是芯片组、是否和别的槽共享，完全以该主板手册为准；普通主板没有这个插槽，不用刻意追求。

### 性能指标与缓存

- **顺序读写**：连续搬大文件（视频素材、压缩包）时的速度，对应「上传=写入硬盘、下载=从硬盘读取」；
- **4K 随机读写**：大量小文件的读写能力，**最影响开机、开软件、游戏加载这种日常流畅度**。很多顺序跑分很高的盘，日常体感却取决于 4K。

#### 缓存的作用

- **独立 DRAM 缓存**：盘上自带一颗小内存，存放「逻辑地址→物理位置」的映射表（FTL）。带独立缓存的盘，在**长期连续大写入、高队列深度、盘快存满**时更稳更快——不必反复从颗粒里回读映射表，掉速和顿挫更少。提升幅度随主控、颗粒、容量和工况差异很大，没有固定百分比；无 DRAM 的盘日常开机游戏几乎无感，但专业素材盘、长期写入场景更建议选带独立缓存的型号；
- **HMB（主机内存缓冲）**：无独立 DRAM 的盘借用一小点系统内存当映射表，日常游戏开机几乎无感；
- **SLC 缓存**：主控把一部分 TLC 颗粒临时当成更快的 SLC 模式来吸收突发写入，缓存写满后速度回落到颗粒真实水平，就是常说的**「缓外速度」**。超大文件持续拷贝才容易碰到，日常使用基本都在缓存内。

#### 固态散热马甲（M.2 散热片）要不要

M.2 固态（尤其 PCIe 4.0 / 5.0 高速盘）满载时主控和颗粒会发烫，一旦撞到温度墙就会主动降速。主板自带的 M.2 装甲、随盘附带的散热片就是干这个的：

- 安装时**导热垫两面的保护膜都要撕掉**，对准主控和颗粒位置压实，膜不撕等于隔着塑料散热；
- 普通风道机箱里裸条大多也能用，但高速盘、或 M.2 槽正好在显卡下方闷烤的位置，建议一定盖散热片；
- 马甲不提高标称的顺序读写峰值，主要作用是**防止过热降速、延缓颗粒老化**。

### 游戏加载与流送

高速固态主要影响：**进游戏/读图的加载时间、开放世界高速移动时的贴图流送（贴图突然糊一下再变清晰就是流送跟不上）、场景切换和存档**。已经是主流 NVMe 后，再从 PCIe 4.0 换到 5.0，游戏内帧数不会变（帧数归显卡 CPU 管），只是加载再快一点点。把游戏放机械盘上，则容易出现加载慢、贴图延迟、场景卡顿。

### 容量与盘位分工

<span class="hl-key">系统盘建议 1TB 起步</span>，512GB 在游戏体积越来越大的今天很快吃紧。一块 1TB NVMe 装系统 + 常用软件 + 常玩游戏；大容量固态或机械盘当素材、冷数据仓库。别把系统装机械盘上，那会让整台机器「看起来很慢」。做系统盘优先[主板的第一 M.2 槽](#m2-与-pcie-通道布局)。

### 寿命原理：写入和擦除才磨损

固态的 NAND 颗粒以「块」为单位**擦除（Erase）**、以「页」为单位**写入（Program）**，一次擦写循环叫一次 **P/E（Program/Erase）循环**，颗粒能承受的 P/E 次数决定寿命，厂家用 **TBW（总写入字节数）**给你一个质保写入量。主控还有磨损均衡，把写入平摊到所有颗粒。

!!! warning "误区澄清：扫盘、读盘到底伤不伤硬盘？"
    <span class="hl-key">单纯读取不磨损颗粒</span>——游戏反作弊扫描、系统索引、反复读档，这些「读」不会消耗 P/E 寿命。只有在**长时间大量读取导致硬盘持续高温、且散热又很差**时，热量才可能加速颗粒老化，正常使用几乎遇不到。真正消耗寿命的是**写入和擦除**。普通用户一天写入量有限，一块主流 TBW 的盘正常用五六年往往都用不完额度，不必为「某游戏扫盘伤硬盘」之类的说法焦虑。

!!! warning "硬盘可能造成的症状"
    - 固态速度远低于标称 → 查是不是插了芯片组/共享通道槽、是否只跑到 ×1/×2；
    - 插上 M.2 后某个 SATA 口消失 → 通道共享的正常现象，看手册换口；
    - 大文件拷到后半段明显掉速 → 是 SLC 缓存写满后的缓外速度，不是故障；
    - 卡 BOOT 灯、找不到启动盘 → 查启动顺序和系统盘连接，见《[点亮与故障排查](点亮与故障排查.md)》。

## :material-power-plug: 电源

<span class="hl-key">电源是整机稳定和硬件安全的底线，最不该省</span>。

### 功率与余量

把 CPU + 显卡满载功耗加上其余部件得到整机峰值，<span class="hl-key">再留 30%~40% 余量</span>选额定功率，让电源常年工作在高效、低温、低噪区间。比总瓦数更关键的是 **+12V 这一路的输出能力**——CPU 和显卡都吃它。

### 转换效率与认证

**80PLUS（白牌/铜牌/金牌/白金）**衡量的是「转换效率」，即多少电能真正用到硬件、多少变成热。它要结合正规品牌型号一起看，不能只看牌级：靠谱品牌的主流方案，远好于杂牌虚标的「金牌」。

### 模组与线材

- **非模组**：线全焊死、最便宜，多余的线扎好藏起来即可；
- **半模组**：主板/CPU 必备线焊死、其余可插拔；
- **全模组**：所有线可插拔，最好走线。性能三者没有区别。

!!! danger "绝对不要混用不同电源的模组线"
    哪怕接口外观一模一样，不同电源的**针脚定义可能不同，混用有烧毁硬件的风险**。只用本电源原配、或厂家明确标注兼容的线。

### 新规范 ATX 3.x 与新显卡供电口（12V-2×6）

先用大白话解释这两个词：

- **ATX 是电源的行业规范，「3.x」里的 x 是小版本号（3.0、3.1……），数字越大越新**。ATX 3.x 最大的改进，是让电源扛得住新显卡那种「一瞬间突然冲高」的功耗尖峰，不容易因为瞬时电流保护而黑屏重启；
- **12V-2×6 是新一代中高端显卡用的一体式 16 针供电口**（它的前身叫 12VHPWR，新版在防呆和接触可靠性上做了改进）。RTX 40/50 系这类卡常用：电源自带这个原生口最稳妥；老电源用**显卡包装盒里附赠的转接线**也能点亮，但一定要插到底听到卡扣声、线材根部别直角死折。

!!! danger "高功率显卡：慎用「一拖二」供电线"
    一根 PCIe 模组线末端分出两个 8-pin 头，就叫**一拖二（菊花链）**。中低端卡这么用没问题，但 **RTX 4090 这一级别的高功耗卡，建议每个 8-pin 都单独用一根线从电源接出（一卡一头、各自走线）**，别让两个头都挤在同一根线上。原因是单根线要承担接近翻倍的电流，一旦线材/端子用料一般、又没完全插到底，接触电阻会让接口处持续发热，极端时熔化、烧毁供电口——40 系早期不少事故正和「一拖二 + 没插到位」有关。拿不准就宁可多占一个模组口，走独立线。

### 保护机制与为什么不能省

正规电源带一整套保护：**OVP 过压、UVP 欠压、OCP 过流、OPP 过功率、SCP 短路、OTP 过温**，异常时自动断电保护硬件。电源内部是电解电容，有寿命、会老化，一旦失控可能连累其他部件，因此**最不建议买二手和杂牌**。预算紧张可以在显卡、外观上让一步，电源选正规品牌、功率留足，这钱是给整机买保险。

!!! warning "电源可能造成的症状"
    - 一上负载就重启、黑屏、闪退 → 典型功率/12V 余量不足或电源老化；
    - 新显卡高负载黑屏 → 查供电到底没、功率够不够、12V-2×6 根部有没有死折；
    - 显卡供电口/线材发烫、有焦味 → 立刻停用，查是否一拖二过载、是否插到底，改用独立供电线；
    - 随机不稳、硬盘掉线、USB 掉设备 → 也可能是供电质量问题，别只盯主板。

## :material-weather-windy: 散热

散热的任务是把热量及时带走，让 CPU/显卡不因过热降频。

### 解热能力匹配

看散热标称的<span class="hl-key">解热瓦数是否 ≥ CPU 满载功耗并留点余量</span>，而不是数热管、看外观。功耗越高的 U，解热规格往上提一档。

### 风冷

- **下压式**：矮、兼容小机箱，还能顺带给主板供电和内存吹风，解热上限较低，适合低功耗 U / ITX；
- **塔式分单塔与双塔**：单塔（一组鳍片配一把风扇）最常见，兼顾解热与兼容；**双塔**（前后两组鳍片、中间夹扇或双扇）热管和鳍片面积更大、解热更强，但更宽更高，可能挡内存、超出机箱散热限高；
- **看热管，而不是只看个头**：热量靠热管从底座快速搬到鳍片，主流 4～6 根，同代结构下热管越多越粗、底座直触/焊接工艺越好，解热越强；
- **为什么底座、热管多用铜，鳍片却多用铝**：铜导热远快于铝，适合紧贴 CPU 快速吸热；铝更轻、便宜、易压成大面积鳍片来散热。所以常见「铜底 + 铜热管 + 铝鳍片」，是导热效率、重量与成本的平衡，高端型号才上全铜镀镍；
- <span class="hl-key">塔式风冷同价位解热强、寿命长、没有漏液顾虑，是主流首选</span>；风扇方向通常**从机箱前面吸风、吹过塔体、由后方排出**，别只图好看装反。

### 一体式水冷

一体式水冷（AIO）解热上限高、机箱风道更通透，由**冷头（多集成水泵）、软管、冷排 + 冷排风扇**组成。选购和安装看这几项：

- **冷排规格**：按风扇位分 **120（单 12cm）/ 240（双 12cm）/ 280（双 14cm）/ 360（三 12cm）**，冷排越长、越厚，散热面积越大、解热越强，但必须机箱有对应冷排位和安装空间；
- **看参数**：水泵转速与噪音、冷排风扇转速与轴承、冷排材质厚度；
- **带屏显 / 灯效的冷头**：部分高端冷头带小屏幕，可显示温度、GIF 动画，需要用 USB 线接主板、靠厂家软件设置；ARGB 灯一般接主板 ARGB 针脚或随附线控器，**具体在哪调、用什么软件，以说明书为准或直接问客服**；
- **冷排装顶部还是前面**：装顶部利于把热气直接排出机箱；装前面则进风先过冷排、水冷效率更高，但会把被加热的风送进机箱，让显卡/内存区略热，按机箱风道取舍；
- 水泵多数集成在冷头，尽量别让冷排长时间整体低于水泵，避免积气产生噪音；**接线务必看说明书**——水泵不一定插 AIO_PUMP，存在反常识接法，见《[装机流程指南 · 散热](装机流程指南.md#安装-cpu-散热器)》。

!!! warning "新水冷到手，先撕保护膜"
    冷头底面、冷排、屏幕表面新件常贴有透明保护膜/绝缘贴，**安装前一定要撕掉**：冷头底面的膜不撕，等于在 CPU 和冷头之间隔了一层塑料，温度会非常难看；屏幕膜不撕则影响显示。这是非常容易忽略、又会让你误以为散热翻车的细节。

正规 AIO 漏液概率很低、多数还有漏液包赔，寿命主要看水泵；想要完全免维护、不操心，高端塔式风冷更省心。

### 填充介质：硅脂、液金与相变片

散热器底座和 CPU 顶盖无论多光滑，微观上都有凹凸，中间的**填充介质**就是用来填平这些空隙、赶走空气（空气导热很差）的，常见有三类：

- **导热硅脂（最常用）**：绝缘、好操作，**均匀完整覆盖即可，不是越薄越好**，豌豆大小一点、靠散热器压力自然铺开，不用徒手刮成纸；几年后温度异常升高往往是硅脂干了，重新涂一次即可。网上流传「硅脂最好的形态是粉末」并不准确——成品做成膏状正是为了便于均匀填充，关键是均匀、完整、无气泡，而不是追求某种形态；
- **液态金属（液金）**：导热能力远高于硅脂，是极限玩家的选择。但它**本身导电、还会腐蚀铝制散热底座**，一旦流溢到主板元件上会造成短路，**新手不要用**；要用也只能配铜底、做好围挡防泄漏；
- **相变片 / 石墨烯相变片**：常温是固体片、受热软化后贴合，上手简单、不会像硅脂那样被「泵」到边上，适合怕涂硅脂的人，导热能力介于普通与高端硅脂之间，重复拆装略麻烦。

!!! danger "液金与开盖（delid）风险很高，新手止步"
    任何填充介质都只能出现在 CPU 顶盖金属面，<span class="hl-danger">绝不能碰到触点、针脚、金手指和电路板。</span> 像 Thermal Grizzly（暴力熊）这类厂商还提供专用「开盖扣具」，可以取下 CPU 顶盖、把顶盖和核心之间的原厂材料换成液金再扣回，极限降温明显，但会**失去保修、操作不当会直接报废 CPU**，只适合老平台的进阶玩家，普通装机用普通硅脂就是最优解。

### 风扇参数与风道

- **风压 vs 风量**：吹冷排、鳍片这种「有阻力」的位置优先看**风压**（能不能把风压过密集鳍片）；机箱进出风这种开阔通道优先看**风量**（单位时间搬多少空气）；
- **轴承决定寿命和异响**：**含油 / 液压（FDB 流体动态轴承）**静音、成本低，是当下主流；**双滚珠**耐高温、寿命长，适合高转速工业扇，但廉价滚珠低转速下噪音略大；此外还有磁悬浮、改良 FDB 等，长期用下来轴承水平直接影响几年后会不会嗡嗡响；
- **静音扇 vs 暴力扇**：静音扇转速低、扇叶大而缓，适合机箱进出风；「暴力扇」转速高、风压大，专门吹冷排/厚鳍片，噪音也大，别拿来当日常机箱扇；
- **积木 / 拼联风扇**：以联力积木风扇为代表，风扇之间靠卡扣和侧边触点物理拼接，供电与灯信号沿串串联，**不用每把都单独走线**，理线干净、灯效同步，缺点是价格偏高、成组设计下单把损坏要连带考虑，且第一把仍需把供电/灯线接到主板或控制器；
- 风道遵循<span class="hl-key">前面/下面进冷风、后面/上面排热风</span>，进风略多于出风形成**正压差**，灰尘更少；风扇有框一面一般是进风侧、有支架/标签一面是出风侧，装反风道就反了。

#### PWM 调速：风扇、水冷泵为什么都走它

风扇要按温度自动调速，常见两种方式，装机时会反复遇到：

- **DC 调压（3pin 风扇的老办法）**：直接改变供给电机的电压高低来调快慢，电压低转得慢。结构简单，但低转速时扭矩不足、可能「憋停」或启动困难，低速线性也一般；
- **PWM 调速（4pin 风扇，现在的主流）**：第 4 根线专门传一路 **PWM（脉冲宽度调制）信号**。风扇始终以额定电压供电，主控用一个固定频率（风扇标准约 **25kHz**，高过人耳听觉范围，不会啸叫）的方波快速「通—断」，<span class="hl-key">靠「接通时间占比（占空比）」控制平均输出，从而线性地调转速</span>。低转不憋停、响应快、多把风扇还能共用同一条调速基准同步加减速。

!!! tip "一句话理解 PWM"
    就像快速拨动开关让灯「亮一会儿、灭一会儿」，开关速度快到你看不出闪烁，<span class="hl-key">亮的时间占比越大、平均就越亮</span>。风扇换成「转一会儿、松一会儿」，占空比越大平均转速越高——这就是脉冲宽度调制。

**为什么一体式水冷也到处是 PWM**：

- 水冷冷排上的风扇本质就是机箱风扇，自然走 PWM 按水温/CPU 温度调速；
- <span class="hl-key">水泵本身也常用 PWM（或专用调速口）</span>：低温时压低泵速换安静，高温时拉满增强循环。主板上 **CPU_FAN / SYS_FAN 走温度曲线，AIO_PUMP / PUMP_FAN 往往默认全速**，就是为了让水泵稳定不停转——别把水泵误插到会降速的普通风扇口；
- 一把 4pin PWM 风扇插 4pin 座（有防呆，3pin 也能插进去但改走 DC 调压）；风扇多就上 **Fan HUB / 集线器**，由一路 PWM 信号统一带多把。

!!! note "同一个 PWM，键盘灯和手机屏幕也在用"
    PWM 是个通用原理、不是风扇专属：<span class="hl-key">键盘背光靠 PWM 调亮度（低亮度频闪就是这么来的）、手机 OLED 屏幕也有 PWM 调光</span>——都是「高速通断 + 占空比」，只是一个调转速、一个调亮度。

!!! note "冷知识：为什么拆了机箱侧板，温度反而可能更高"
    封闭机箱靠「前进后出」形成定向风道，把热量稳定带走。拆掉玻璃侧板后风道被破坏：显卡/CPU 排出的热风在机箱内部紊流打转，甚至被前面进风又吸回去（热风循环），热气积聚在顶部排不出去，**结果比装好侧板还高几度**。想靠「开盖」降温，前提是环境空旷、有额外风扇直吹；桌面底下这种闷热环境里，完整风道往往更凉。

!!! tip "风冷、水冷都分 Intel / AMD 扣具，下单先确认"
    无论塔式风冷还是一体水冷，都要对应具体插槽扣具（如 LGA1700 / LGA1851、AM4 / AM5）。**正规散热器通常 Intel、AMD 两套扣具都自带**，但散装、二手或跨代升级时可能缺件，下单前问清客服、到货先核对扣具包；以后换平台（比如 AM4 升 AM5），旧散热能不能继续用，也只看厂家有没有出对应扣具，别想当然。《装机流程指南》安装散热处会再讲一遍。

!!! warning "散热可能造成的症状"
    - CPU 温度高、撞温度墙降频 → 查硅脂、扣具有没有压紧、风扇是否接到 CPU_FAN、风道；
    - 主板报 CPU Fan 错误、卡自检 → 多是水冷/风扇插错口，按说明书接回；
    - 水泵异响/水温偏高 → 检查冷排位置是否积气、水泵供电是否正常。

### 海景房与玻璃侧透

「海景房」机箱用大面积钢化玻璃（侧透 + 前面板，甚至顶部）做无立柱或双舱展示，硬件和灯效一览无余，分一体大玻璃和分体拼接两种。它好看，但要注意两点：一是前面板若整块封死成玻璃，进风就得靠侧面、底部或专门开孔，下单看清风道设计；二是玻璃又重又脆。

!!! danger "钢化玻璃侧板：轻拿轻放，最怕磕角"
    钢化玻璃正面能承压、却**最怕竖着磕到边角**：侧板竖着往地上一磕角，很容易整面碎裂或崩掉一角。拆装时平拿平放、手拧螺丝别死命拧、不要在侧板吃力时搬动整机；需要运输 / 搬家，建议把玻璃侧板拆下单独包好，别让它跟着机箱一起颠。

### 带副屏的机箱

部分机箱在前面板或侧面带一块小屏幕（方屏或长条 IPS），用来显示温度、帧率、动图壁纸。它本质上是**给主机多接了一块小显示器**：一般通过 HDMI / Type-C 取视频信号、USB 取电或触控，再用机箱厂家软件或 AIDA64 传感器面板之类推流。装之前确认三件事——屏幕靠什么取电取信号、占不占用一个显卡/主板视频口和 USB 插针、配套软件支不支持；视频口本来就紧张的机器要提前规划。它不影响主机性能，属于外观和信息展示件。

### ITX 小机箱（小钢炮专题）

ITX（Mini-ITX，主板 170×170mm）不是「把 ATX 等比缩小」那么简单，而是用尺寸约束反过来挑所有部件——这一节就相当于小钢炮专题，单独不再开新篇。

- **选型顺序反过来：先定机箱。** ITX 机箱先卡死四个硬指标——显卡限长/限厚、风冷限高、电源规格（多为 SFX/SFX-L）、冷排位，再按这四个数反选显卡、散热、电源和主板，最后才轮到其它配件；
- **电源多为 SFX。** SFX 比 ATX 小一圈，SFX-L 稍长、风扇更大更安静；功率和接口仍按整机峰值留 30% 余量（见后文[功率与余量](#功率与余量)）。小机箱内部空间金贵，全模组/定制短线几乎是刚需，硬塞标准 ATX 电源前先确认仓位；
- **显卡常用 PCIe 延长线转装。** 很多 ITX 机箱显卡不直接插在主板上，而靠一根 PCIe x16 延长线竖装或横移。务必用随箱或合格的 PCIe 4.0/5.0 屏蔽延长线，走线避开风扇，装好后用 GPU-Z 确认链路仍跑在满速 x16（原理见 [M.2 与 PCIe 通道布局](#m2-与-pcie-通道布局)）；
- **散热是 ITX 最大难点。** 内部体积小、风道短、热量集中。下压式风冷能同时照顾供电与内存，是 ITX 常见解；上 240 水冷要先确认冷排加风扇的总厚度；维持进风略多于出风的正压，及时把显卡和电源排出的热带走；
- **装机顺序也不同。** 通常先在箱外把 CPU、内存、M.2 装到主板上组成「子模块」，接好电源线和跳线再整体进箱——因为进箱之后几乎没有下手空间；
- **别和兼容性清单对着干。** 显卡长 1mm、风冷高 1mm 都可能盖不上侧板，硅脂、线材、冷排厚度都要提前量好，ITX 的返工成本远高于大机箱。

!!! tip "小钢炮的代价"
    同芯片下 ITX 往往更贵（主板、SFX 电源、小尺寸高端件都更贵）、更挑兼容性、散热和噪音余量更小。它换来的是体积和颜值，而不是性能——想清楚自己是不是真的需要这么小。

## :material-vector-link: 搭配与平衡

这一层解决「从零配机，钱怎么分、件怎么配才不翻车」。

### 预算分配

记住这条推导链，顺序别搞反：

!!! success "选件推导链"
    **用途和分辨率定显卡档位 → 显卡配门当户对的 CPU → CPU 决定主板平台和内存代数 → CPU/显卡功耗决定散热和电源 → 全部尺寸最后决定机箱。**

!!! tip "尽量一步到位，别总想着「以后再升级」"
    电脑是互相牵制的整体，升级一件往往要连带动别的：换更高功耗的显卡，可能电源功率和主板供电都得跟上；加硬盘要看主板还有没有空闲 M.2 / SATA 和通道；换更强的 CPU，可能连主板平台、内存代数、散热都要一起换。**与其先买半档、日后反复补，不如攒够预算按真实需求一步到位。** 硬盘尤其如此——主板 M.2 位有限，明知道自己要存大量游戏 / 素材，一开始直接上 2TB / 4TB，比日后盘位捉襟见肘再折腾省心。真要为未来留余量，就把**电源功率和主板供电**这两个「地基」留足，而不是每个件都买半档。

### 瓶颈判断

- <span class="hl-key">分辨率越高越吃显卡</span>：4K 下旗舰和中端 CPU 差距很小，钱给显卡；<span class="hl-key">1080P 高刷反过来更吃 CPU</span>；
- **单通道内存**是隐形短板，会同时拖累游戏帧和核显；
- **系统盘不是 NVMe 固态**，整台机器都会显得迟钝；
- **电源和散热是地基**：不加分，但不够会让你直接翻车（降频、重启）。

### 老机升级路线：先找瓶颈，再决定换一件还是全换

老机器别一上来就「先换张新显卡试试」，按瓶颈判断走能少花很多冤枉钱。

1. **先定位真正的瓶颈。** 玩游戏/干活时开监控，看是 CPU 某核占满、显卡占满、内存爆掉还是硬盘太慢——谁满载谁是瓶颈，对照前面的[瓶颈判断](#瓶颈判断)和各部件「它可能造成的症状」；
2. **单点瓶颈、平台还够新 → 只换那一件。** 显卡不够但 CPU 还带得动、电源也够，就只换显卡；内存不够就加内存（注意代数与双通道）；系统盘还是机械盘或老 SATA 固态，换一根 NVMe 的提升最立竿见影；
3. **平台太老、处处是瓶颈 → 整平台换新。** 如果 CPU、主板、内存（如还停在 DDR3、早期 DDR4）都成短板，单换任何一件都会被其余部件拖住，没有意义——这时 CPU+主板+内存往往要一起换代；
4. **哪些可以留。** <span class="hl-key">硬盘最值得留</span>：装着资料、游戏库的 M.2 和机械硬盘，只要接口兼容、健康度好，换平台直接迁过去，重要数据另做备份；机箱（装得下新件、风道尚可）、电源（功率接口跟得上、不是老化杂牌）、散热器（扣具支持新平台）也常能沿用；
5. **哪些基本跟着换。** 跨代 CPU 几乎必换主板、常连带换内存代数；老电源没有新显卡供电口、功率余量不足，也要一起换。

!!! tip "一句话判断"
    拿不准时问自己：换上这件之后，会不会立刻被另一个老部件拖住？会，就说明该整平台换了——除了装数据的硬盘，没有什么是「必须留」的。

### 能插上不等于该插

PCIe / M.2 通道有限且会共享：第二根长 PCIe 槽可能只有 ×4、某个 M.2 会占用 SATA 口。<span class="hl-key">「能用」只代表物理能点亮，「跑满」才代表性能到位。</span>装机前花十分钟看[主板通道说明](#m2-与-pcie-通道布局)，能避开绝大多数「能用却变慢」的坑，验证方法见《[装机流程指南](装机流程指南.md)》和《[点亮与故障排查](点亮与故障排查.md)》。

### 下单兼容性清单

- [ ] CPU 插槽 = 主板插槽，且主板 BIOS 已支持该 CPU（新 U 配老板可能要先刷 BIOS）
- [ ] 内存代数（DDR4/DDR5）与主板一致，频率在平台甜点范围内
- [ ] 主板供电规模压得住所选 CPU 的满载功耗
- [ ] 显卡长度/厚度装得进机箱，不与水冷排、硬盘位冲突
- [ ] 风冷限高/水冷冷排尺寸与机箱匹配，扣具支持 CPU 平台
- [ ] 电源对整机峰值留 30% 以上余量，+12V 能力足够
- [ ] 显卡供电接口齐全（8-pin 数量或 12V-2x6），只用原厂模组线
- [ ] M.2 / SATA 数量满足规划，已确认通道共享关系
- [ ] 机箱支持主板板型，风扇位与风道已规划
- [ ] 显示器接口/刷新率与显卡输出匹配（高刷要对应版本的 DP/HDMI 线）

# 电脑

自己装机的本质不是「照着图片把线插对」，而是 **先理解每个部件是什么、为什么这么接，再动手安装；出了问题先判断、再排查**。

今天用 Intel、明天换 AMD，今年是某代显卡、几年后又是全新接口——具体的插法会变，但「接口为什么存在、厂家为什么要求这么接、接不上该怎么办」这套逻辑不会变。理解了它，哪怕换一代硬件，你依然能自己装。

!!! tip "本分区的主线"
    **先理解，再安装；先判断，再排查。** 不背「这根线永远插这里」，而是搞懂「这根线是干什么的」。

## 常见英文 / 缩写注释（先看这里）

装机圈长期混用大量英文缩写。为了阅读顺畅，本分区约定：**高频、说中文反而别扭的词一律保留英文**（如 CPU、BIOS、PCIe），在下面统一注释；只偶尔出现的词，会在正文里就地加括号说明。

!!! note "特别注意：GPU ≠ 显卡"
    **GPU** 指显卡上那颗图形芯片，**显卡**是包含 GPU、显存、供电、散热的整张卡，二者不能划等号。所以本分区不会把 GPU 直接翻译成「显卡」。

=== "核心硬件"

    | 英文 | 中文 / 全称 | 说明 |
    | --- | --- | --- |
    | CPU | 中央处理器 | 通用计算核心，习惯直接叫 CPU |
    | GPU | 图形处理器 | 显卡上的计算芯片，注意不等于整张显卡 |
    | RAM / 内存 | 随机存取存储器 | 临时运行内存，掉电清空 |
    | SSD | 固态硬盘 | 分 NVMe（M.2 接口为主）与 SATA 两种 |
    | HDD | 机械硬盘 | 大容量仓库盘，速度远低于 SSD |
    | DDR4 / DDR5 | 第四 / 五代内存 | 内存「代数」，主板和 CPU 支持哪代就用哪代，不通用 |
    | AIO | 一体式水冷 | All-In-One，预装冷头+冷排+水管的封闭水冷 |
    | PSU | 电源 | 给整机供电的部件，稳定性底线 |
    | TDP / PL | 热设计功耗 / 功耗墙 | 衡量 CPU、显卡发热与供电需求的参考值 |

=== "接口、总线与设置"

    | 英文 | 中文 / 全称 | 说明 |
    | --- | --- | --- |
    | BIOS | 主板固件设置 | 开机按 Del/F2 进入的那层系统，习惯直接叫 BIOS |
    | CMOS | 主板设置记忆 | 靠纽扣电池保存 BIOS 设置，「清 CMOS」=恢复默认 |
    | POST | 开机自检 | Power-On Self-Test，进系统前的硬件自检阶段 |
    | PCIe | 高速扩展总线 | 读「PCI-E」，显卡、M.2、扩展卡都走它；x16/x8/x4 是通道（带宽）数 |
    | M.2 | 一种插槽形态 | 常见于固态/无线网卡，具体跑什么协议还要看主板 |
    | NVMe | 高速固态协议 | 走 PCIe 通道，比 SATA 固态快得多 |
    | SATA | 老式硬盘总线/供电 | 分 SATA 数据线与 SATA 电源线，两者不是一回事 |
    | USB / Type-C | 通用串行总线 | 前置机箱跳线常见，Type-C 口最怕蛮力插坏 |
    | DP（DisplayPort）/ HDMI | 视频输出接口 | 独显输出线应插在显卡上，而不是主板 |
    | 24-pin | 主板主供电 | 主板上最宽的那排供电口 |
    | EPS（CPU 供电） | CPU 专用供电 | 4/8 针，靠近 CPU，**不能和显卡 PCIe 供电线混用** |
    | 12VHPWR / 12V-2x6 | 新一代显卡供电口 | 高功率新显卡使用，必须完全插到底 |
    | RGB / ARGB | 定色 / 可编址灯效 | 风扇、灯带、水冷头的灯光，两者电压接口不同，不通用 |
    | PWM / DC | 两种风扇调速 | PWM 多为四针智能调速；DC 靠改变电压调速 |
    | XMP / EXPO | 内存一键超频档 | XMP 多对应 Intel 平台，EXPO 对应 AMD 平台 |
    | Debug LED | 故障诊断灯 | 主板上 CPU/DRAM/VGA/BOOT 四个小灯，指示卡在哪一步 |
    | PCB | 印刷电路板 | 常说的「主板板面」 |
    | I/O | 输入输出 | 机箱背部那排接口区域叫 I/O 挡板 |

=== "品牌与检测软件"

    **品牌名**（正文首次出现会「中文（英文）」并列，之后用中文）：

    | 英文 | 常见中文 | 英文 | 常见中文 |
    | --- | --- | --- | --- |
    | Intel | 英特尔（常直接叫 Intel） | AMD | 超威（圈内常直接叫 AMD） |
    | NVIDIA | 英伟达 | MSI | 微星 |
    | ASUS | 华硕 | GIGABYTE | 技嘉 |
    | ASRock | 华擎 | — | — |

    **检测软件**（软件名是专有名词，一律不翻译）：

    | 软件 | 主要用途 |
    | --- | --- |
    | CPU-Z | 查看 CPU、主板、内存代数/频率、SPD 颗粒信息 |
    | GPU-Z | 查看显卡型号、显存、**PCIe 链路状态**、显卡传感器 |
    | HWiNFO | 整机温度、电压、功耗、风扇转速等详细传感器 |

!!! question "正文里偶尔冒出来的其他英文怎么办？"
    像 GPU-Z 里的 **Bus Interface（总线接口）**、**Render Test（渲染测试）** 这类只在特定步骤出现的词，会在它第一次出现的位置直接加括号翻译，不占用你的记忆负担。

# 空间音频、全景声与声场

「杜比全景声」「空间音频」「3D 环绕」「声场」这些词经常被混着用。这一篇按一条清晰的线讲：声音是怎么从**一个声道**走到**在三维空间里定位**的、为什么只有两只单元的耳机也能听出上下前后、以及这些效果到底需要什么内容和设备才能真的放出来。

## 从单声道到环绕声：声道的演进

- **单声道（Mono）**：所有声音混在一条轨、一个点发声，没有方位；
- **立体声（Stereo）**：左右两个声道，利用两耳听到的**电平差和时间差**制造声像左右移动和宽度，是音乐的绝对主流；
- **环绕声（基于声道，channel-based）**：在听者周围布置固定声道，声音在制作时就被「混」进这几条轨里：
    - **5.1**：前左、中置、前右 + 左环绕、右环绕 + **.1 低音声道（LFE）**；
    - **7.1**：再增加两个侧 / 后环绕；
    - **中置声道主要负责人声对白**，让人物说话始终锁定在屏幕中央；**LFE 是「低频效果」声道，不等于把所有低音都交给它**。

## 基于对象的音频：杜比全景声

传统环绕声里，混音师只能把声音分配给固定的几只音箱。**杜比全景声（Dolby Atmos，2012 年首先用于影院）改成了「基于对象（object-based）」**：一个声音（直升机、身后的脚步、头顶的雨）不再被写死在某条声道里，而是作为一个**对象**，附带它在三维空间中的**位置元数据（含高度）**；回放时，由渲染器根据你**实际拥有的音箱布局**，实时计算每只音箱该发什么。

- 影院里它由「床声（bed，固定声道基底）+ 最多上百个同时存在的声音对象」组成；
- 家庭用 **x.y.z** 标注布局，如 **5.1.2 / 5.1.4 / 7.1.4**：前两个数是地面环绕，**最后一个数是天空声道数量**；
- **天空声道**可以是装在天花板的顶置音箱，也可以是**向上发声、靠天花板反射**的反射式音箱；
- 同一份全景声母带能自适应缩放到从一副耳机到几十只音箱的任意系统。**DTS:X** 是同类的竞争标准，原理也是把声音作为空间对象处理。

!!! note "对象音频和传统环绕的本质区别"
    传统 5.1 / 7.1 是「这路声音固定从这只音箱出」；对象音频是「这个声音此刻在空间的这个坐标，<span class="hl-key">你有几只箱子、放在哪，渲染器就现场算给你听</span>」。前者换一套音箱就得重新适配，后者自带布局无关的描述。

## 耳机上的空间音频：双耳渲染与 HRTF

耳机只有左右两只单元，却能让人听出声音从背后、头顶传来；实现这一效果的是**双耳渲染（Binaural Rendering）**和 **HRTF（头相关传输函数）**。

现实中，一个来自特定方向的声音到达两耳时会产生：

- **时间差（ITD）**：离得远的那只耳朵晚一点点听到；
- **响度差（ILD）**：头的遮挡让远侧耳朵声音更轻；
- **方向染色**：耳廓、头、肩膀对不同方向、不同频率的反射和遮挡各不相同。

HRTF 就是描述这套「方向指纹」的函数。把多声道 / 对象信号用 HRTF 处理（卷积）后混进左右两轨，大脑就能仅凭两只耳机判断声音的上下前后。各家的叫法不同但内核一致：**杜比全景声的耳机渲染、苹果的空间音频（Spatial Audio）、索尼 360 Reality Audio、Windows 空间音效、游戏里的 HRTF 选项**，都是这件事。

- **头部追踪（Head Tracking）**：部分方案带陀螺仪，转头时让声场固定在「屏幕 / 房间」而不是跟着脑袋转，模拟人坐在固定空间里的感觉；纯音乐则常提供「固定声场」和「随头追踪」两种模式；
- **个性化 HRTF**：每个人的头型、耳廓不同，通用 HRTF 未必准，所以有些方案支持拍照 / 扫耳生成个人 HRTF，定位会更贴合。

## 虚拟环绕与真实多声道

- 耳机上的空间音频，是把多声道 / 对象用算法**渲染**成两轨，效果取决于 HRTF 是否贴合和内容是否原生；
- 回音壁、耳机上的「虚拟环绕 / 3D 音效」，很多是用心理声学给普通立体声加混响、加串扰来模拟包围感，<span class="hl-key">两声道无法凭空还原出离散的真实多声道</span>；
- **内容必须本来就是多声道 / 对象制作才有意义**：把一首两声道老歌硬「空间化」，只是加了一层混响和拉伸，不会变成真全景声；
- 实体多声道的包围感来自物理位置不同的音箱和房间反射；回音壁靠墙面、天花板反射模拟环绕和天空，效果受房间形状、层高、天花板软硬材质影响很大，不是放哪都一样。

## 声场与结像

- **声场（Soundstage）**：重放出来的声音在空间中形成的「舞台」有多宽、多深、多高；**结像（Imaging）**：能否把一件乐器、一个人声定位成空间中一个具体的点；
- 立体声主要靠左右声道的电平差 / 时间差（pan）给出左右位置，而深度、高度更多依赖混响、频响和房间；
- **耳机的声场常在「头内」**：因为耳机直接贴耳、缺少听音箱时那种「左耳也能听到右箱、且带自然延迟衰减」的交叉串音。耳机的声场感主要由频响（尤其是与耳廓相关的高频）和模拟串音（**crossfeed 交叉馈送**）决定，开放式、平板等设计往往显得声场更大；
- **音箱的声场在你前方的真实空间成形**，结像通常更自然，但强烈依赖房间和摆位——这部分在《[音源、数字音频与房间声学](音源数字音频与房间声学.md)》和《[桌面音箱](../外设/音箱.md)》里展开。

## 怎么把全景声真正放出来

享受对象音频需要**片源 + 整条回放链路都支持**，任何一环降级都会退回 5.1 甚至立体声：

1. **片源**：流媒体的全景声档位、UHD 蓝光、支持 Atmos / 空间音频的游戏或音乐；
2. **三种回放形态**：
    - **实体多声道**：AV 功放或环绕功放 + 地面音箱 + 天空 / 反射音箱，让功放解码，或让播放机**源码直通（bitstream / passthrough）**给功放；
    - **回音壁（Soundbar）**：单机用反射和多单元模拟天空与环绕，受房间条件影响；
    - **耳机**：由主机 / 手机 / 电脑或 App 用 HRTF 实时双耳渲染，不需要多只音箱；
3. **链路接口**：电视把音频回传给功放 / 回音壁主要靠 **HDMI ARC / eARC**（eARC 才能无损回传全景声），流媒体盒子、电视、功放三者都要打开对应直通设置；
4. **游戏与影视不同**：影视是预制好的对象母带；游戏里引擎是<span class="hl-key">根据画面实时把声音对象渲染到你的耳机 / 音箱</span>，属于交互式空间音频，用于听声辨位。

!!! tip "打游戏的听声辨位怎么开最准"
    竞技游戏里定位靠的是游戏引擎的 **HRTF / 空间音频**渲染 + 一副立体声耳机，开启游戏内 HRTF（详见《[监听与功能挑选](监听与功能挑选.md)》）通常比叠加各种第三方「虚拟环绕」更准；<span class="hl-key">不要同时开多层虚拟环绕</span>，重复处理会模糊定位。

!!! note "空间音频一定更好吗"
    它是一种**需要内容和设备配合的重放方式**，不是音质增强开关。影视、游戏的方位感收益明显；而大量优秀的立体声音乐本身就是按两声道精雕细琢的，硬转空间音频反而可能改变混音师的意图，值不值得看个人口味。

# 音源、数字音频与房间声学

这一篇补两块「链路之外但影响巨大」的知识：前面讲**数字音频到底是什么、无损和高解析有没有意义**；后面讲**房间和摆位为什么对音箱影响极大**。耳机几乎不受房间影响，玩音箱则绕不开房间。

## 数字音频基础：采样率与位深

声音是一条连续变化的模拟波形，数字音频在两个维度上把它「离散」地记录下来：

- **采样率（Sample Rate，Hz/kHz）**：在**时间轴**上每秒对波形采多少次样。根据**奈奎斯特定理**，采样率达到目标最高频率的两倍才能完整还原；人耳可听上限约 20kHz，所以 **44.1kHz 的还原上限约 22.05kHz**，理论上已包住人耳可听范围并留出保护带；
- **位深（Bit Depth）**：每次采样用多少个二进制位来描述音量大小，决定**动态范围**（最响和最静之间能分多少档）以及本底量化噪声。16bit 理论动态范围约 96dB，24bit 约 144dB。

常见规格一览：

| 规格 | 采样率 | 位深 | 主要用途 |
| --- | --- | --- | --- |
| CD / 无损流媒体 | 44.1kHz | 16bit | 音乐发行的基准 |
| 影视 / 视频 / 游戏 | 48kHz | 16/24bit | DVD、蓝光、视频平台、游戏音频 |
| Hi-Res 高解析 | 88.2 / 96 / 176.4 / 192kHz | 24bit | 发烧下载、专业录音母带 |
| 专业录音 / DAW | 96 / 192，少数 384kHz | 24/32bit 浮点 | 录音、混音、后期 |
| DSD（另一套体制） | 2.8224MHz 起步（1bit） | 1bit | SACD 与发烧下载，见下节 |

### 44.1kHz 与 48kHz 的由来

这两个数字不是随便定的，而是两条历史血脉：

- **44.1kHz**：1980 年索尼与飞利浦制定 CD 标准时选定。44100 = 22050×2，奈奎斯特频率 22.05kHz，刚好覆盖 20kHz 人耳上限并给抗混叠滤波留出余量；具体数值还和当时用录像带存储数字音频的设备兼容。它因此成为**音乐发行和流媒体的默认值**；
- **48kHz**：DVD、蓝光、广播、影视和游戏音频的标准，因为它能被 24 / 25 / 30fps 等常见帧率整除，音画同步处理更方便。视频平台、游戏引擎基本都用 48kHz；
- **88.2 / 176.4 是 44.1 的整数倍，96 / 192 是 48 的整数倍**——整数倍之间降采样最简单、损耗最小，所以高解析也分成这两个系列，分别对应「音乐」和「影视」。

!!! note "44.1 和 48 听起来有区别吗"
    两者都完整覆盖了人耳可听频段，<span class="hl-key">最终重放时没有可闻差异</span>。但**采样率转换（SRC）不是无损运算**：把 48k 的素材硬转到 44.1k，劣质算法会引入轻微失真。正确做法是在制作一开始就固定采样率（做音乐用 44.1 或 48、做影视配音用 48），而不是反复转来转去。

### 更高采样率（96 / 192 / 384 / 768kHz）的实际作用

要把**制作端**和**重放端**分开看，结论完全不同。

**在录音、混音、后期（制作端），高采样率确实有用：**

- 抗混叠滤波器可以设计得更宽松，把陡峭的滤波过渡带放到人耳听不到的超声区，可听频段内的相位和瞬态更干净；
- EQ、降噪、音高 / 变速、多次效果器串联会累积处理误差，更高采样率和位深留足了运算余量；
- 完整保留了高频泛音和超声成分，给后期和未来重制留空间。

**在最终听歌（重放端），收益对绝大多数人、绝大多数设备非常有限：**

- 成年人耳蜗对 20kHz 以上基本无法直接感知，多数人在 15～17kHz 以上就已明显衰减；
- 在控制良好的 ABX 盲听里，普通设备、普通录音的「高解析 vs CD」<span class="hl-key">无法被稳定区分</span>；
- 所谓高解析更有「空气感、空间感、更通透」，客观上通常来自三件事，而不是「听到了超声」：① 高解析文件**往往配套了不同的、有时更好的母带**；② 极少数高端系统在带外响应、瞬态和数字滤波上的差异**间接**影响了可听频段；③ 心理预期。即便用上万元的耳机 + 耳放 + 原生高解析录音，差异也极微弱，且无法在盲听中稳定复现。

!!! tip "怎样理性看待 Hi-Res"
    高解析不是骗局——它在专业制作链里是真材实料；但<span class="hl-key">「文件标了 96/192」不等于「你能听到更多」</span>。决定听感的优先级始终是：母带质量 ＞ 耳机 / 音箱与调音 ＞ 房间和摆位 ＞ 前端，采样率排在很后。一份糟糕母带的「高解析」不会比优质母带的 CD 更好听。

### 位深与动态范围

- 16bit 提供约 96dB 动态范围，24bit 约 144dB。现实里，安静房间本底噪声约 25～35dB SPL、很响的音乐峰值约 105～115dB SPL，需要的动态也就 80～90dB，**16bit 对最终重放已经够用**；
- 24bit 的价值同样主要在制作端：录音时不必把电平顶到最满也有充足的精度余量，后期推拉不易暴露量化噪声；
- **采样率管频率上限，位深管动态和底噪，是两个互不替代的维度**；
- 把高位深降到 16bit 时，工程上会加极微量的 **dither（抖动噪声）**来消除量化失真，这是正常且专业的做法，不必看到「噪声」就紧张。

## PCM 与 DSD：两套数字音频体制

<span class="kb-tag kb-tag-theory">原理</span>数字音频在记录波形时有两种**数据表示体制**：PCM 与 DSD。讲这两套体制之前，先明确三个处于不同层级、但经常被放在一起谈论的概念：

- **数据表示体制**：波形以什么形式被记录，分为 **PCM（脉冲编码调制）**与 **DSD（直接比特流数字）**；
- **容器 / 文件格式**：数据装在什么文件里，例如 **WAV、FLAC、MP4（M4A）、OGG**；
- **编码格式**：容器内的数据以什么方式编码，例如 **FLAC、ALAC、MP3、AAC**；同一种容器可以装不同编码，同一种编码也可以放进不同容器。

以一个 `.flac` 文件为例：它的容器是 FLAC、编码也是 FLAC，编码所记录的数据体制则是 PCM；一个 `.m4a` 文件的容器是 MP4，里面装的可能是 ALAC 编码、也可能是 AAC 编码，二者的数据体制同样是 PCM。

各层的具体含义如下：

- **PCM（脉冲编码调制）是一种数据表示体制**：每个采样点直接记录一个多位「幅度数值」，是最底层、未经压缩的原始数字音频形态；
- **WAV 是容器（文件格式）**：最常用来承载未压缩的 PCM 数据（理论上也能装别的），「WAV」本身并不是一种编码；
- **FLAC、ALAC 是无损压缩编码**：把 PCM 数据压缩、不丢信息，播放时再解码还原成 PCM；
- **MP3（以及 AAC / OGG）是有损感知编码**：利用心理声学模型丢弃部分信息，解码后同样得到 PCM，再送去播放。

!!! note "PCM、WAV、FLAC 不属于同一层概念"
    **PCM 是数据表示体制，不是文件格式**；**WAV 是容器，不是编码**；FLAC、ALAC、MP3 等是编码格式，压缩处理的对象是 PCM 数据、解码还原出的也是 PCM。因此严格来说，FLAC / WAV / ALAC / MP3 都不应被直接叫做「PCM」。

### PCM 体制

PCM 体制下，每个采样点记录一个多位「幅度数值」（如 16/24/32bit × 44.1～384kHz），像用很密的台阶去描波形。它通用、便于后期处理（EQ、调音量、降噪都直接在 PCM 上做），是 CD、流媒体和绝大多数音频在处理与播放时的底层形态。

### DSD 体制

DSD（直接比特流数字，源自 SACD）的每个采样只有 **1bit**（只有 0 / 1 两种状态），但采样率极高，用脉冲的**疏密**来表示波形，并靠**噪声整形**把量化噪声推到人耳听不到的超声频段：

| DSD 规格 | 采样率 | 相对 CD 倍率 |
| --- | --- | --- |
| DSD64（SACD 标准） | 2.8224MHz | 64× |
| DSD128 | 5.6448MHz | 128× |
| DSD256 | 11.2896MHz | 256× |
| DSD512 | 22.5792MHz | 512× |

DSD 在可听频段内的动态范围也能做到约 120dB。需要客观说明几点：

- DSD 体制上几乎不能直接做 EQ、调音量等处理，很多操作得先转回 PCM，因此**原生 DSD 录音和母带数量很少**；
- 播放分**原生 DSD**（DAC 硬件支持）和 **DoP（DSD over PCM，把 DSD 数据装进 PCM 数据包传输，本身不转码、不丢信息）**；电脑 / 小尾巴若不支持，会把 DSD 实时转成 PCM 再播；
- 有人觉得 DSD 高频更「柔滑」，这与它的噪声整形和滤波方式有关，但<span class="hl-key">PCM 高规格与 DSD 之间没有公认的、可稳定盲听的高下</span>，差异更多取决于具体母带和设备；
- **把普通 PCM 转换成 DSD 不会增加任何信息，不会因此变好听**，只是换了一种封装；同理，低规格转高规格也是如此。

## 母带、重采样与「假高解析」

- 一首音乐的诞生链是：**录音（多轨）→ 混音（把多轨合成）→ 母带（mastering，对成品做最终的 EQ、动态和响度统调）**。你最终听到的是某个「母带版本」；
- 同一首歌可能有 CD 母带、流媒体母带、黑胶转录、SACD / Hi-Res 母带等多个版本，<span class="hl-key">它们之间的差别主要来自母带和响度处理，而不是文件容器或采样率标签</span>；
- 流媒体平台会按档位对音频做重采样和编码（普通有损、无损 CD 级、高解析），是否真有高解析母带、要不要额外设备 / 订阅，各平台差异很大，认准**实际播放时显示的规格**，而不是广告上的 Hi-Res 角标；
- **「假高解析」**：把 44.1/48 的母带用软件上采样到 96/192，或从有损 / CD 转制后贴上 Hi-Res 标签——信息不会凭空增加。进阶玩家可用频谱分析辨别：真正的高采样录音在 20kHz 以上仍有连续泛音能量，而上采样文件常在某个频率出现整齐的硬截止；
- **响度战争（Loudness War）**：不同版本响度不同，而人耳天然觉得「更响 = 更好听」。比较两个文件 / 两副耳机时，应先把音量对齐（最好相差 0.5dB 以内），否则结论很容易被响度欺骗。

!!! warning "格式与标签不决定音质"
    「DSD 一定比 PCM 高级」「采样率越高越发烧」「文件越大越好」都是营销话术。<span class="hl-key">真正稀缺的是高质量的录音与母带，以及能把它还原好的换能环节（耳机 / 音箱 / 房间）</span>，格式只是承载这些的容器。

## 无损、有损与流媒体

- **无损压缩**：FLAC、ALAC 等，压缩但不丢信息，解码后和原文件逐位一致，体积约为未压缩 PCM 的一半；
- **有损压缩**：MP3、AAC、OGG 等，利用心理声学模型丢弃「不容易被听到」的部分换体积，码率越低丢得越多；高码率有损（约 256~320kbps 级）在多数设备和场景下已不易盲听分辨；
- **流媒体档位**：普通档多为有损（一两百 kbps 级），「无损」档约为 16bit/44.1kHz（约 1Mbps 上下），「高解析」档才到 24bit/96 或 192；不同平台曲库是否真有高解析母带、是否需要额外订阅 / 设备，差异很大，<span class="hl-key">认准实际播放规格而不是广告里的「Hi-Res」标</span>；
- 蓝牙传输时这些还要再经过蓝牙编码，见《[蓝牙编码与无线音频](蓝牙编码与无线音频.md)》。

## 数字界面、Jitter 与线材

- **USB / 光纤 / 同轴 / HDMI / 蓝牙**在 DAC 之前传的都是数字信号，理想情况下「传对了就是同样的 0 和 1」，<span class="hl-key">合格稳定的数字线不会让声音「更暖 / 更甜」</span>；
- **Jitter（时钟抖动）**指数字采样时钟不稳，理论上可能影响转换；但现代 DAC 普遍用**缓冲 + 本地高精度时钟（异步方案）**重组数据，前端抖动的影响被大幅隔离，这也是「发烧数字线」收益常被夸大的原因；
- 真正有意义的是：连接稳定不掉包、电气隔离和供电干净（这影响的是**模拟输出底噪**，属于解码 / 耳放和屏蔽问题，而不是数字线的「音色」）。升级顺序见文末。

## 房间声学：音箱是和房间一起发声的

耳机的声场在头两侧，几乎不受房间影响；音箱发出的声音却会在墙壁、地面、天花板之间反射，<span class="hl-key">你听到的是「直达声 + 大量反射声 + 房间共振」的混合，房间常常比音箱本身更决定最终声音</span>。

### 几个主要的房间问题

- **驻波 / 房间模式（Standing Waves / Room Modes）**：低频波长长（几十到几百厘米），在平行墙面之间来回叠加，导致某些频率在特定位置被放大（轰头）、某些位置被抵消（没低音）。这是小房间低频不均的主因，靠换音箱很难解决；
- **第一反射点（Early Reflections）**：声音经侧墙、天花板、地面、后墙第一次反射到耳朵的位置，强反射会干扰定位、让声像和频响变浑；
- **混响（Reverb）**：硬墙、瓷砖、玻璃、空房间让声音反复反射、拖尾变长，人声和低频浑浊；
- **桌面反射**：近场场景下，桌面就是一块大反射面，会在中低频形成干涉（梳状滤波）。

### 摆位（免费且收益最大）

- **等边三角形**：两箱间距 ≈ 箱到听音位距离，箱体内凹（toe-in）使高音轴线指向耳朵，详见《[音箱 · 近场摆位](../外设/音箱.md)》；
- **高音单元与耳同高**，必要时垫箱架 / 减震垫；
- **离墙、对称**：低音倒相孔 / 单元离后墙、侧墙留出距离并左右对称，避免单侧贴墙造成低频和声像偏；
- **短边摆放**：音箱通常沿房间**短边**摆放（你面向短墙、音箱离后墙有距离），让左右侧墙更对称、轴向驻波更均匀；
- **38% 规则（进阶）**：在条件允许、以听音乐为主的房间，把音箱沿房间长度方向放在约 38% 的位置，可减少与前后墙相关的轴向驻波；桌面近场受限于桌位，了解原理即可，不必教条；
- **低音炮**：低频方向性弱、位置相对自由，可用「把炮临时放听音位、在候选位置爬行试听 / 测量」找最干净的点，并调好与主箱的分频衔接。

### 声学处理（比盲目升级器材有效）

- **低频陷阱（Bass Trap）**：放在房间四角（墙角是低频能量堆积处）的吸音体，处理驻波最有效，也是小房间最值得做的处理；
- **第一反射点吸音 / 扩散**：在侧墙、天花板的第一反射点挂吸音板或扩散体；后墙可在听音位后方做扩散；
- **增加软性家具**：厚窗帘、地毯、书架、沙发都能打散和吸收中高频反射，普通卧室往往不用专业装修就能明显改善混响；
- **别迷信「鸡蛋棉」**：那种波浪海绵主要吸中高频、对低频几乎无效，贴满墙也解决不了驻波，还可能让高频过吸发闷；真正的吸音要看材料厚度和密度，低频要靠厚实的角落陷阱；
- **测量与房间校正**：用测量麦克风 + 校正软件 / 功放自带的房间声学校正（Room EQ），能量化频响和驻波并做补偿；但<span class="hl-key">校正 EQ 修不了严重的物理缺陷（节点处根本没声），摆位和声学处理仍是根本</span>。

## 升级的边际收益顺序

!!! success "把钱花在刀刃上"
    对**音箱系统**，影响从大到小大致是：<span class="hl-key">房间与摆位 ＞ 音箱 / 耳机本身 ＞ 适配的功放 / 耳放 / 解码 ＞ 线材与小配件</span>。

    - 在驻波严重、摆位贴墙、桌面反射没处理时，换更贵的解码和线材基本是浪费；
    - 耳机系统里没有房间项，顺序变成：**耳机 ＞ 匹配的推力（耳放）＞ 解码 ＞ 线**；
    - 解码 / 耳放只有在「集成声卡有底噪、推力不够、缺接口」时才是真实瓶颈；
    - 数字线谈「音色」、给稳定数字连接加昂贵「发烧线」，是边际收益最低的花费之一。

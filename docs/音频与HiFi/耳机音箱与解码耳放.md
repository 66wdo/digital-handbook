# 耳机、音箱与解码耳放

音频最容易被参数和玄学带节奏。这一篇先把**信号链路**和**每一环在干什么**讲清，再讲耳机怎么分类、好不好推、频响怎么看，最后是解码（DAC）和耳放。先理解链路，再判断「我到底缺哪一环」，而不是听人说「换根线 / 加个耳放就一耳朵区别」。

- **解码（DAC）**管「数字转模拟转得准不准、干不干净」；
- **放大（耳放 / 功放）**管「有没有足够的电压和电流把单元控制住、推响推稳」；
- **耳机 / 音箱**管「电信号最终怎么变成声音」，是整条链里对音色影响最大、也最该先花钱的一环。

!!! tip "升级顺序的朴素原则"
    <span class="hl-key">短板永远在「换能」那一端：先把耳机 / 音箱选对、摆好，再谈前端。</span>在一副本身调音、素质有限的耳机后面堆昂贵解码耳放，收益极小；而同一台解码耳放换一副好耳机，区别往往立竿见影。

## 耳机怎么分类

### 按佩戴 / 结构

- **入耳式（IEM，耳塞）**：塞进耳道，靠耳塞套形成一定密封，隔音好、体积小、易驱动、便携；导管角度、耳塞套材质和大小会明显改变佩戴和低频；
- **头戴式（耳罩）**：分**封闭式**（隔音好、低频足，但声场偏闷、易有腔体共振）、**开放式**（背板透气，声场自然通透、不闷，但漏音、不隔音、低频偏柔，适合安静室内）、**半开放式**（折中）；
- **真无线（TWS）、颈挂、有线**：TWS 胜在便携和降噪，音质和续航受体积、电池、蓝牙编码限制；有线是音质和稳定性的上限形态；
- **骨传导 / 开放式（不入耳）**：挂耳、不堵耳道，运动和需要听环境音时安全舒适，但漏音、低频和解析弱，定位是「开放聆听」而非高音质。

### 按发声单元

| 单元 | 原理（大白话） | 声音倾向 | 代价 / 特点 |
| --- | --- | --- | --- |
| **动圈（Dynamic）** | 音圈通电带动一张锥 / 球顶振膜，最经典 | 低频自然、宽松、氛围感好 | 最常见、价格带宽，做好难、做差也多 |
| **动铁（BA）** | 小金属壳里一根平衡电枢在磁场里振动，靠导管出声 | 解析高、瞬态快、体积小 | 单只频宽窄，常多只 + 分频导管组合；低频自然度看调校 |
| **圈铁混合** | 动圈管低频、动铁管中高频，分频协同 | 兼顾氛围与解析 | 分频衔接做得不好会割裂 |
| **平板（Planar Magnetic）** | 整张极薄振膜印上导线，在两侧磁铁间整体受力 | 失真低、细节多、瞬态和动态好 | 通常**低阻但低敏、吃电流**，个头偏大偏重，多为头戴 |
| **静电（Electrostatic）** | 极薄振膜悬浮在高压静电场中被整体驱动 | 通透、细腻、瞬态极快 | 需要专用升压耳放，系统贵且娇贵 |

同一种单元里，调音和做工的差距远大于「单元类型」本身的差距——<span class="hl-key">没有「平板一定比动圈好听」这种事，只有具体型号的具体调音</span>。

## 关键概念：阻抗、灵敏度与「好不好推」

这一组参数很容易被误解。

- **阻抗（Ω，欧姆）**：耳机对交流电流的阻碍。入耳多为 16~32Ω（低阻），不少专业监听头戴是 250 / 300 / 600Ω（高阻）；
- **灵敏度（效率）**：给一定功率 / 电压时耳机能有多响，常见两种标法——**dB SPL/mW**（功率灵敏度）和 **dB SPL/Vrms**（电压灵敏度），<span class="hl-key">两种标法数值不能直接横比，先看单位</span>；
- **「好不好推」要同时看阻抗和灵敏度，而不是只看阻抗**：
    - **高阻动圈（如 250/300/600Ω）吃「电压摆幅」**：需要耳放能输出足够高的电压才推得响；
    - **低阻低敏平板吃「电流」**：阻抗不高但灵敏度低，需要耳放能持续输出大电流来控制振膜，这才是真正难推的一类；
    - **低阻高敏入耳**：手机 / 小尾巴就能推响，反而是最省心的。

**耳放的「推力」不是一个数字**，至少包含：

- **输出功率（在指定阻抗下的 mW，如 32Ω 下多少 mW、300Ω 下多少 mW）**：同一台耳放在不同阻抗下功率不同，比较要看同一阻抗口径；
- **电压摆幅**：决定高阻耳机的响度上限；
- **电流输出能力**：决定低阻平板的控制力和动态；
- **输出阻抗 / 阻尼**：耳放输出阻抗应**远低于**耳机阻抗（经验上低于耳机阻抗的 1/8 更稳），否则频响会被带偏、低频控制变松。

!!! warning "低阻高敏耳塞上大功率台机，反而出恶声"
    高增益、大功率台机推低阻高敏入耳时，<span class="hl-key">很容易听到明显底噪（hiss），还可能过推、发硬、失真</span>。这类耳塞应该用**低增益档**、甚至直接手机 / 小尾巴驱动。「推力越大越好」是错的——匹配才重要，就像用卡车拉自行车。

## 频响曲线与「调音风格」

- **频响曲线（Frequency Response）**：耳机对不同频率（低频到高频）声音的增益，横轴频率、纵轴响度（dB）。它是目前**最可测量、和听感相关性最高**的单一指标；
- **声音不是「越平越好」直接照搬**：耳机的理想目标曲线本身不是一条直线（受头相关传输、耳道和听音习惯影响）。业内被广泛采用的参考之一是**哈曼目标曲线（Harman target）**：它由研究团队基于大量听众的盲听偏好统计得出，模拟「一对调校准确的音箱在参考听音室里」的音色平衡，并且入耳式和头戴式是**不同版本**的曲线，还在随研究迭代；
- 研究同时发现，多数听众偏好在目标曲线基础上**再多一点低频**，且偏好随年龄、性别、听音经验略有差异。<span class="hl-key">目标曲线是「多数人偏好的统计参考」，不是唯一真理，更不是越贴合 100 分越好</span>；
- 测量需要**人工耳 / 耳模拟器**（头戴和入耳用的耦合器不同），个人用标准化夹具 + 测量软件也能测出相对可靠的曲线。

**几个常听到的主观词，大致对应什么**：

- **声场**：声音「铺开的空间大小」，主要受频响、混响、左右通道串扰和开放程度影响；
- **结像 / 定位**：乐器 / 人声「站在哪个位置、轮廓清不清晰」；
- **分离度 / 解析**：复杂段落里各声部能不能分清，和高频响应、失真、瞬态有关；
- **冷暖 / 厚薄**：大致是频响倾斜的主观描述——中低频偏多偏暖厚，高频偏多偏亮偏冷。

这些词有意义但难精确量化，<span class="hl-key">看评测时优先找实测频响和失真数据，再用主观词补充风格</span>，而不是反过来只看形容词。

### EQ：用软件改调音，性价比极高

- **EQ（均衡器）**就是按频率调整增益。**参数 EQ（PEQ）**能指定中心频率、增益和 Q 值（影响宽窄），是主流；
- 像 AutoEQ 这类项目会基于实测曲线，生成一条「补偿到目标曲线」的 PEQ 参数，导入 Equalizer APO（Windows）、Peace、Wavelet（安卓）或播放器即可；
- EQ 能<span class="hl-key">显著修正过暗、过刺、低频过多 / 过少等调音问题，往往是最便宜的「升级」</span>；
- 但 EQ 不是万能：它补不回单元本身的高失真、糟糕瞬态、佩戴漏音；过度提升低频 / 高频还可能让单元失真、功放削波。合理范围内的数字 EQ 本身不损失音质，激进调节才有代价。

#### 动手实操：用免费 EQ 把耳机调向目标曲线

EQ 最划算的用法不是凭感觉拖滑块，而是**套用基于实测的参数**，把耳机曲线往目标曲线上靠。有两条路，绝大多数人走第一条就够：

- **路线一（零成本，推荐先做）：直接套用公开实测预设。** 社区测量项目 **AutoEQ** 汇总了数千款耳机的专业测量，并为每款生成补偿到目标曲线的参数 EQ 文件，照着导入即可，不需要自己买测量设备；
- **路线二（进阶）：自己测量。** 需要测量麦克风和耳模 / 测量夹具，再用 Room EQ Wizard 这类软件测出「你这只耳机 + 你的佩戴」下的曲线、自行生成 EQ，门槛高，但结果最贴合你自己的耳套和佩戴。

**Windows 上的具体步骤（用到的工具都免费）：**

1. 安装 **Equalizer APO**（开源的系统级 EQ 引擎），安装时勾选要作用的耳机 / 声卡输出，按提示重启；
2. 安装 **Peace**（给 Equalizer APO 配的图形界面，免费）；也可以直接用它自带的 Configuration Editor；
3. 到 AutoEQ 项目里按品牌、型号搜到自己的耳机，下载它的 **ParametricEQ.txt**（一串参数 EQ 频点）；
4. 在 Peace 里选「导入 / Import」载入这个文件（或把网页上的 PEQ 参数逐段粘进去），启用；
5. 先把音量调低再试听，可用开关随时对比 EQ 前后，不满意一键关闭。

其他平台：安卓可用 **Wavelet**（免费，内置 AutoEQ 预设，按型号选择即可）；iOS 不开放系统级 EQ，一般在支持 EQ 的播放器 App 内部设置。

!!! note "为什么「同款耳机、别人的预设」不一定完全适合你"
    公开测量是在**特定耳套、特定佩戴力度、标准测量夹具**下做的；你换了耳套（海绵 / 硅胶、不同尺寸）、插入深浅不同，密封和频响就变了，最优 EQ 也跟着变。所以预设的价值是「快速把八九成的明显偏差拉正」，而不是为你的耳朵量身定做；要完全贴合，才需要路线二自测。

!!! warning "EQ 的几条客观边界"
    - **优先「衰减」而不是大幅「提升」**：把过量的峰拉低很安全；大幅抬升低谷会额外吃掉推力和动态余量，还可能让功放**削波（Clipping，破音）**，单次提升一般控制在几 dB 内；
    - EQ 改的是频响，**补不回单元本身的高失真、差瞬态和佩戴漏音**——它能修正调音，不能把廉价单元变成旗舰；
    - 目标曲线不止一种（如 Harman、IEF），口味不同、没有唯一正确答案，选自己听着自然、久听不疲劳的；
    - EQ 会改变整体响度，调完重新设定音量，别被「EQ 后更响 = 更好听」的**响度错觉**带偏。

## 解码 DAC

**DAC（数模转换器）**把数字的 0/1 变成连续模拟信号。任何能出声的数字设备里都有 DAC，区别在素质和供电 / 屏蔽环境。

常见指标（知道在看什么即可，不必背数字）：

- **SNR（信噪比）/ DR（动态范围）**：有用信号相对底噪能高出多少，dB 越高背景越黑；
- **THD+N（总谐波失真 + 噪声）**：失真和噪声占比，用负 dB 表示，**越负越好**（如 −110dB 比 −90dB 干净）；
- **输出电平**：线路输出常见标准约 **2Vrms**（非平衡），电平匹配才能接功放 / 有源箱；
- **位深 / 采样率**：CD 是 **16bit / 44.1kHz**，常见高解析为 24bit / 96、192kHz，另有 DSD；这些数字的实际意义见《[音源、数字音频与房间声学](音源数字音频与房间声学.md)》，日常 16/44.1 以上、指标合格的 DAC 差异远小于耳机本身。

**形态怎么分**：

- **小尾巴（便携 DAC 线）**：手机 / 电脑 USB 口取电、即插即用，绕开集成声卡，驱动低阻高敏耳塞和易推头戴足够；
- **桌面解码 / 解码耳放一体机**：供电和模拟电路更宽裕，输出功率和接口（平衡、RCA、光纤、蓝牙）更全；
- **随身播放器（DAP）**：自带电池、系统和存储，便携且电路独立；
- **纯解码 + 独立耳放**：分体，给后续升级留空间。

!!! note "「集成声卡不够用」什么时候成立"
    主板 / 手机集成声卡放视频、开会、听流行**通常完全够用**。它真正的短板往往是<span class="hl-key">模拟输出在机箱内受电磁干扰带来的底噪、以及驱动力不足</span>。一个 USB DAC / 小尾巴最大的可闻收益，常常是「绕开机箱干扰、底噪没了」和「推得动更难推的耳机」，而不是玄学上的「一耳朵变好听」。听不出区别、也没有底噪和推力问题，就不必硬上。

## 耳放 / 功放

- **耳放**驱动耳机，**功放**驱动无源音箱；有源音箱已内置功放；
- 作用是提供足够且受控的电压 / 电流，并保持低输出阻抗（好阻尼）；
- **增益档（Gain）**：高增益放大倍数大、用于高阻 / 低敏耳机；低增益用于易推耳塞，底噪更低。<span class="hl-key">原则是「能在低增益把音量开到合适区间，就别上高增益」</span>；
- 平衡输出（4.4mm、XLR 等）通过独立放大通路提升声道分离和共模抑制，但**平衡不是「音质必然更好」的开关**，做工差的平衡不如做得好的单端。

## 音箱

音箱部分（有源 / 无源、单元分频、连接、近场等边三角摆位、桌面声学）已在《[音箱（桌面 / 多媒体）](../外设/音箱.md)》专门讲；房间声学、低频处理和摆位的系统原理见《[音源、数字音频与房间声学](音源数字音频与房间声学.md)》。一句话：<span class="hl-key">对音箱而言，房间和摆位的影响常常大于换器材</span>。

## 常见误区

!!! warning "先把这些放下"
    - **只看堆料（几个单元、什么振膜、多大电容）不看实测频响和失真**：调音是系统工程，料好不等于好听；
    - **「推力越大越好」「阻抗越高越难推」**：难推要看阻抗 + 灵敏度，还要分清吃电压还是吃电流；低阻高敏塞子反而怕大推力；
    - **在差耳机 / 差摆位上先升级线材和前端**：换能端和房间才是大头；
    - **把频响目标曲线当唯一标准答案**：它是偏好统计参考，个人口味和佩戴也重要；
    - **迷信「煲机」带来质变**：单元老化可能带来轻微、有限的变化，但不存在「煲几百小时脱胎换骨」，多数可闻差异来自心理预期和搭配；
    - **数字线也谈「发烧音色」**：只要是合格、稳定传输的数字连接（USB / 光纤 / HDMI），传对了就是 0 和 1，不存在一根数字线让声音「更暖」。

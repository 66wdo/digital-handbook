# 音频与 HiFi

音频设备的挑选容易陷入参数玄学和品牌崇拜。本分类坚持一条主线：<span class="hl-key">先搞清信号链路与功能差异，再谈风格与听感；只讲技术原理，不夸任何品牌</span>。

## 信号链路先理清

```text
数字音源(手机/电脑/播放器/流媒体)
   │  USB / 光纤 / 同轴 / 蓝牙(编码压缩)
   ▼
解码 DAC（数字 → 模拟）
   │
   ▼
耳放 / 功放（放大模拟信号，提供电压与电流驱动）
   │
   ▼
耳机 / 音箱（电信号 → 振膜振动 → 声音）
```

耳机是和耳朵直接耦合的系统，几乎不受房间影响；音箱则是和**房间一起发声**，摆位和声学处理的影响常常大于换器材。

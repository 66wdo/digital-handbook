# 音频与 HiFi

音频设备的挑选容易陷入参数玄学和品牌崇拜。本分区坚持一条主线：<span class="hl-key">先分清功能差异、再谈风格与听感；只讲技术原理，不夸任何品牌</span>。

声音从音源到耳朵，大体要经过「音源 → 解码（DAC）→ 放大（耳放/功放）→ 耳机/音箱」几个环节：数字信号要先解码成模拟波形，再被放大、最后驱动单元发声。耳机几乎不受房间影响，音箱则是和**房间一起发声**，摆位和声学的影响常常大于换器材。每个环节具体怎么看，都在下面各篇里展开。

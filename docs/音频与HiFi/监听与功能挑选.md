# 监听与功能挑选

这一篇解决「按用途选」：什么叫监听、打游戏要什么、通勤降噪怎么挑、语音录音怎么配。耳机 / 解码耳放的底层原理在《[耳机、音箱与解码耳放](耳机音箱与解码耳放.md)》，这里只讲场景和功能。

## 「监听」到底是什么意思

**监听（Monitor）= 以还原、准确为目标，让你听到「信号本来的样子」，而不是讨好耳朵。** 它是给「做声音的人」用来判断和决策的工具：

- **录音 / 混音监听耳机**：频响尽量平直、少音染、隔离环境，让混音师判断各轨比例、瑕疵和频响问题；封闭监听常用于跟踪（防止耳机声漏进麦），开放监听常用于长时间混音；
- **监听音箱（近场）**：在声学处理过或近场的环境里给出平直平衡，靠左右对箱和房间建立正确的立体声 / 低频判断；
- 「**监听味**」常被觉得干、素、不甜，因为它不刻意加低频和泛音去讨好；但<span class="hl-key">监听和 HiFi 不是对立关系</span>——好的监听也可以很好听，很多「HiFi 调音」也在追求准确，只是侧重点不同。

!!! note "普通人有没有必要买监听设备"
    如果你要**录音、剪辑、混音、做播客 / 视频配音**，需要一套相对准确的回放来做判断，监听取向有价值；如果只是欣赏音乐、打游戏、通勤，按自己口味选好听、舒服的即可，不必为了「专业」硬上素淡的监听。要警惕的是反过来：用一条低频轰头的耳机做混音，做出来的东西在别的设备上会偏。

## 按功能场景选音频设备

=== "游戏（听声辨位）"

    - FPS 里「听脚步方位」靠的是**定位准确**，而不是声道数量：
        - **双声道 + HRTF（头部相关传输函数）**：游戏引擎把三维空间的声音，按人脑判断方位的规律（耳廓 / 头部造成的频率和时间差）渲染成两声道，戴耳机就能分辨上下前后，这是当代游戏音频（如各类对象 / 基于环绕的渲染）的核心；
        - **「虚拟 7.1 环绕」耳机**：本质也是把多声道用 HRTF  down-mix 成两声道，做得好有帮助，做得差只是加混响、糊定位；<span class="hl-key">真正决定定位的是 HRTF 算法和频响 / 串扰，而不是耳机上印几声道</span>；
        - 游戏内的「耳机 / HRTF」音频模式通常比耳机驱动里一刀切的虚拟环绕更准，优先开游戏内选项。
    - **延迟**：竞技优先有线或低延迟 2.4G 接收器；普通蓝牙（尤其 SBC / AAC）延迟可能让音画不同步，看编码和游戏模式，详见《[蓝牙编码与无线音频](蓝牙编码与无线音频.md)》；
    - **佩戴和麦克风**：长时间戴要轻、不夹头；开黑语音的麦清晰比耳机多两个喇叭重要，麦的选择见《[麦克风](../外设/麦克风.md)》；
    - 封闭耳机隔音利于沉浸和听清细节，开放耳机声场自然但会漏音、也收环境声，按使用环境选。

=== "语音 / 直播 / 录音"

    - 核心是「被清晰地听见」，麦和环境比耳机更重要：电容 / 动圈、指向、48V、增益、底噪、防喷、噪声门，全部在《[麦克风](../外设/麦克风.md)》讲透；
    - 监听方面需要**零 / 低延迟返听**：录音时要能实时听到自己，专业声卡走 ASIO / CoreAudio 或硬件直返，避免回声；
    - 一副封闭监听耳机能在直播 / 录音时避免声音漏进麦克风。

=== "音乐欣赏"

    - 走《[耳机、音箱与解码耳放](耳机音箱与解码耳放.md)》的完整链路：先按口味和佩戴选耳机 / 音箱，再看推力和前端；
    - 安静室内、不吵别人：开放头戴声场最自然；通勤 / 办公室：封闭或入耳；
    - 想要「准确」参考选监听取向，想要放松好听按口味调音，没有高下。

=== "通勤 / 运动 / 通话（TWS）"

    - **佩戴稳固与舒适**是第一位：入耳靠耳塞套密封（也决定低频和降噪效果），半入耳（不堵耳道）舒适但密封和低频弱，骨传导 / 耳挂适合运动开放聆听；
    - **主动降噪强度、通透模式、抗风噪、通话拾音**按通勤场景重点看；
    - **蓝牙编码**：苹果生态 AAC 体验统一，安卓中高端看是否支持 LDAC / aptX 系列 / LHDC，但编码只是链路一环，详见蓝牙篇；
    - 续航、充电盒、多点连接（同时连手机电脑）、防水等级（运动看 IPX）按需求；
    - TWS 受体积、电池和无线编码限制，<span class="hl-key">同价位有线大耳机在绝对音质上通常更有优势</span>，为便携和降噪付的钱是另一笔账。

## 主动降噪（ANC）与通透

### 降噪的两种思路

- **被动隔音（物理）**：靠耳塞套密封、封闭式耳罩 physically 挡住外界声，对中高频效果好、零副作用、不耗电，是降噪的基础——<span class="hl-key">入耳式耳塞套没戴好、密封漏了，ANC 再好也打折</span>；
- **主动降噪（ANC，Active Noise Cancellation）**：麦克风采集外界噪声，电路生成**反相声波**把它抵消，对规律性的低频噪声（飞机引擎、空调、地铁轰鸣）最有效。

按麦克风位置分三种：

| 方案 | 麦克风位置 | 特点 |
| --- | --- | --- |
| **前馈（Feedforward）** | 耳机外侧，先听到噪声 | 降噪频段宽、不易啸叫，但对靠近耳道的残余噪声处理有限 |
| **后馈（Feedback）** | 耳罩 / 导管内侧，监测实际听到的声 | 对低频抵消准，但带宽窄、调不好易啸叫 |
| **混合（Hybrid）** | 外侧 + 内侧各一颗（或多颗） | 兼顾两者，是当下中高端主流，成本和调校要求更高 |

### ANC 的代价与相关功能

- **耳压 / 闷胀感**：反相声波对低频的抵消会让部分人产生「压耳朵、像坐飞机」的感觉，强弱因人而异，强降噪不等于舒服；
- **底噪与音质**：降噪电路和麦克风可能引入轻微底噪；为降噪做的调音、加上无线编码，可能影响音质，部分耳机提供高音质 / 纯有线模式；
- **通透 / 环境音模式（Transparency）**：让外界声经麦和处理后自然地「透」进来，不摘耳机也能对话、听报站；好的通透自然、无明显自声放大（自己说话闷响），差的像隔着电话；
- **抗风噪**：风打在外侧麦克风上是低频乱流，强降噪反而把风噪放大，靠防风网结构、专门风噪算法或切到防风模式缓解，骑车 / 户外重点看；
- **自适应降噪 / 智能通透**：按环境和佩戴自动切换档位，属于锦上添花，核心还是看基础降噪和通透的自然度。

!!! warning "降噪相关的几个误区"
    - **「降噪越强越值得买」**：过强的低频降噪可能耳压难受，通勤够用、戴着舒服更重要；
    - **ANC 能挡人声**：主动降噪主要压低频规律噪声，中高频人声主要靠被动隔音和通透关闭，别指望地铁里人声完全消失；
    - **开着降噪睡觉 / 长时间不摘**：注意耳道卫生和音量安全，环境安全需要感知时（过马路、骑车）用通透或单耳；
    - **半入耳也谈强降噪**：没有密封，被动和主动降噪都受限，预期要放低。

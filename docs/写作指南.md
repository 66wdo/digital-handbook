# 写作指南（怎么往网站里加内容）

本页说明如何给本站新增/修改文章。所有文章都是 **Markdown 文件**，放在 `docs/` 目录里。

## 新增一篇文章的完整流程

1. 在 `docs/` 下找到对应分类文件夹，新建一个 `.md` 文件（中文名即可）；
2. 用任意编辑器（推荐 VS Code）写正文；
3. 打开根目录的 `mkdocs.yml`，在 `nav:` 对应分类下登记一行，例如：

    ```yaml
    - 音频与 HiFi:
      - 音频与HiFi/index.md
      - 新文章标题: 音频与HiFi/新文章.md
    ```

4. 保存。若 `启动本地预览.bat` 正在运行，网页会自动刷新。

## 本站支持的常用排版

### 提示框（Admonition）

```markdown
!!! note "标题可选"
    这是一条普通说明。

!!! tip "小技巧"
!!! warning "避坑警告"
!!! danger "严重问题"
!!! question "常见疑问"
```

效果：

!!! note "标题可选"
    这是一条普通说明。

!!! tip "小技巧"
    折叠/展开块用 `???` 代替 `!!!`，例如 `??? question "点击展开"`。

### 标签页（适合分情况对比）

```markdown
=== "需求 A：只刷视频聊天"

    内容 A

=== "需求 B：重度游戏"

    内容 B
```

=== "需求 A：只刷视频聊天"

    这类需求不需要高端芯片。

=== "需求 B：重度游戏"

    优先看芯片性能、散热和屏幕触控采样。

### 表格

```markdown
| 维度 | 重要性 | 说明 |
| --- | --- | --- |
| 处理器 | 高 | 决定流畅上限 |
| 后盖材质 | 低 | 戴壳后无感知 |
```

### 任务清单

```markdown
- [x] 明确预算
- [ ] 确定核心需求
- [ ] 圈定 2~3 款备选
```

- [x] 明确预算
- [ ] 确定核心需求
- [ ] 圈定 2~3 款备选

### 按键/快捷键、代码、高亮

- 按键：按 ++ctrl+c++ 复制（写法 `++ctrl+c++`）
- 行内代码：`mkdocs serve`
- 高亮文字：==重点结论==（写法 `==重点结论==`）

````markdown
```bash
mkdocs serve
```
````

### 图片

把图片放进 `docs/assets/images/`（没有就新建），文章里这样引用：

```markdown
![示意图](../assets/images/xxx.png)
```

## 写作模板建议（经验类文章）

```markdown
# 标题

## 一句话结论
## 适用场景 / 不适用场景
## 判断框架（按维度拆解）
## 分档建议（不同预算/需求）
## 常见误区与避坑
## 备注与参考
```

!!! question "文章写一半怎么办？"
    在开头加一行 `!!! todo "待补充：xxx"` 即可，后续慢慢完善，不影响网站构建。
